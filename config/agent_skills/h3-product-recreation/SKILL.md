# H3 商品替换与参考原片再生成

适用于用户用参考视频和新商品图重新生成视频，替换指定物品并按需替换口播名称。若用户要求其余像素或原声音频完全不变，说明这是精确编辑任务，本 skill 不能承诺；不静默改成重新生成。仅指导 Chat 分析和提示词编写，不提交媒体生成、不调用不存在的工具、不改变模型参数或路由。

## 先绑定素材与替换对象

依据本轮真实附件类型及编号建立映射：例如 @1 视频对应 <Video 1>，@2 商品图对应 <Picture 1>；各媒体类型独立编号。商品图只提供外观，不自动作为首帧。多张同款图可共同定义一个商品，不把不同款式合并；多商品按旧对象 → 新图 → 新名称分别绑定。目标不明确时只问需要区分的对象。

先检查实际能读到的画面、时长和声音。未收到视频内容、只有缩略图、抽帧或文字描述时，不声称看完视频、听到台词或知道精确切点。抽帧不能证明整段动作或音频内容。仅凭文件名、URL、商品图不猜原口播。缺少关键视频、新商品图或新名称时简短索取；其余已明确信息不重复询问。

默认沿用可确认的原片时长、画幅、镜头结构、人物、场景、动作和运镜，仅修改指定商品及用户授权的名称。原片信息无法读取时询问或标为待确认，不自定时长、切点或广告剧情。不要求用户已提供的素材再次上传。

## 按原片动作规划替换

内部逐镜整理：原商品出现区间、位置与朝向、人物哪只手握持、接触点、遮挡、移动路径、旋转、出入画以及镜头切点。正式提示词写明动作的起态、方向、速度变化和终态；运镜与商品运动分别描述，不能用“高级、完美复刻”代替动作。

新商品从图片提取可见的轮廓、比例、材质、配色、盖体、标签和可辨识文字。未知背面、容量、功能及品牌文字不能编造。保持同一商品跨镜连续，反射、阴影、景深和运动模糊随原场景变化；不要把静态商品照片作为贴纸覆盖画面。被手或其他物体遮挡的部分保持遮挡，出画再入画仍为同一商品。只替换指定对象，其他同类物品不连带更换。

若新商品结构与原动作冲突，例如喷瓶换成罐装而原片按压喷头，指出冲突并提出最小动作调整，不能让新商品凭空长出喷头。不要擅改场景、人物或增加产品特写、卖点及广告结尾。画面字幕、包装文字与声音名称分别处理；用户只要求改口播时，不顺带改其他文字。

## 口播名称替换与声音参考

先确认实际可访问的音轨或用户提供的准确台词。对每处要替换的称呼记录原词 → 新词、所在语句、说话人和可确认的时间段；听不清写 [unclear]，必要时请用户补充，不猜品牌名称。仅替换指定名称，不借机改写其余台词、语言、语气或产品功效。新产品不具备的原卖点应提出核实，而非当成新产品事实。

本流程重新生成声音：实际音轨可作为音色、语速、情绪、背景声音与节奏参考，属于 audio reference，保留策略为 reference。不能写 audio reuse、fully_copy 或 partially_copy，也不能声称逐字拼接了原音轨。视频文件带声音不等于 Chat 已收到可听的声音；只有实际提供并可读取的同步音轨或音频附件才定义 <Audio N>。仅有台词文本时用它指定新对白，不虚构音色参考。

原文语言的完整目标语句写为 <d>[Chinese] 今天介绍新商品名。</d>；英文或其他语言用对应标签。按实际发声顺序分配稳定 (S1)、(S2)，跨镜不更换编号。说话人出镜时描述口型与新台词同步；旁白不要求人物张嘴。新名称变长时优先利用可用停顿和自然语速，无法适配原时间窗口则询问最小调整，不截断名称或擅自延长影片。无口播原片不新增口播；无声要求不新增音乐。

FFmpeg 可在具备执行工具的工作流中提取音轨、抽帧和检查媒体时长，但它不完成语音识别或内容理解。本 skill 不因服务器安装了 FFmpeg 就声称 Chat 已调用它；需要转录或预处理时明确指出缺少的输入或能力。

## H3 输出契约（自包含）

信息足够时给一份可复制的六字段提示词，不额外叠加通用导演模板。正文英文，台词和可见文字保留原语言；用户明确要求中文时遵从。字段顺序：

1. subject_definitions：定义新商品 <Subject N> 的真实图片来源；定义需要保留的原片主体，以及 <Video N> 的动作、运镜、节奏来源。只在实际音轨可用时定义 <Audio N> 及其用途。用真实附件编号建立来源映射，不输出签名 URL。
2. summary：使用 [reference generation]；实际参考音轨时为 [reference generation + audio reference]。明确生成一条以原片为结构参考的新视频，不使用 video editing 或“原片已被修改”。
3. retention_analysis：按来源职责说明保留与改变。新商品外观为 fully_preserved 的目标，原动作迁移可用 attribute_transfer，原片结构按实际保留程度说明；音频使用 reference。标签表示生成目标，不代表已经验收成功。
4. detailed_description：按原片播放顺序描述替换后的可见画面、具体动作、相机路径、接触遮挡和新台词；保留原镜头数量，不把动作阶段拆成新镜头。[Shot 1] 不附切点，后续实际切镜使用 [Shot N] At MM:SS.mmm；只用可确认时间，最后覆盖完整片长。
5. overall_soundscape：描述参考的环境音、动作声及其与动作的同步，不承诺原音频信号保留。
6. non_diegetic_music：按要求参考原配乐特征或写明无配乐 N/A；不得凭空添加。无对白不等于无配乐。

只要求提示词时直接给正文；要求方案时先给简短替换映射及待确认项。缺关键信息时不输出伪装成完整成稿的占位词。收到后续商品名、时长或台词补充时沿用用户确认的素材映射，不继承助手擅加内容。

## 检查边界

提示词交付前核对：目标商品映射、未授权变化、跨镜商品一致性、具体动作、旧名称是否仍残留在目标对白、发声者与口型、总时长和切点。成片测试另检查商品是否全程替换、遮挡与手持关系、原片节奏、名称读音与剩余台词。未生成或未观看成片时，只能报告提示词检查结果，不能称商品与声音替换已成功。
