# 人物层级与群演连续性

本 Skill 用于资产提取、角色设计和分镜设计。人物层级表示制作投入和跨镜识别需求，不决定剧情身份，也不自动赋予长相。先记录剧本中的每次出场和来源，再提出层级、资产粒度与镜头引用；提案经用户确认后才成为稳定资产。

## 分级判断

- 主演：持续承担主要行动、关系或情绪线，需要稳定身份、可兼容的造型变体和高优先级参考图。
- 配角：有独立对白、关键行动或跨场状态，按独立人物管理；不因戏份少而降为匿名群体。
- 固定群演：观众需要再次认出、脸在近景可读，或承担可追踪的动作/道具交接时，建立稳定 ID 和最小识别锚点。没有来源的五官由角色设计提出待确认方案。
- 群体模板：只要求人数、服装族、轮廓差异和行进规则的中远景人群；不声称每个模板实例是同一张脸。不可辨识远景可以只有密度、区域和运动规则。

台词、关键交接或跨镜复现要求出现时，提出将某个匿名实例升级为独立人物；保留已有来源和镜头关联，不通过改名或换 ID 假装一直是已确认身份。层级可随剧情改变，已确认的身份 ID 不因此变化。不要固定生成 5–10 或 10–20 人；候选数量由剧本覆盖、景别和重复出场决定。

## 群演组与变体

群演资产同时记录群演组、可识别实例和视觉变体：

```text
group_id      = 阵营或人群模板，例如 流民匪寇、玄宸阁探子、青溪镇市井百姓
extra_id      = 需要跨镜认出的固定群演实例
variant_id    = 已保存的服装、体态、发型、道具或状态变体
```

- `variant_id` 是视觉资产变体，不自动代表新的剧情人物。
- 固定群演沿用同一 `extra_id`；换装、尘土、伤势或状态变化才建立新的变体。
- 匿名群体可以使用 `group_id + variant_id`，例如“流民匪寇-v1/v2/v3”，不声称每个变体有固定脸。
- 同一分镜可以选择多个群体变体，制造服装、体型和轮廓差异；相邻镜头默认沿用已选择的变体集合。
- 需要观众辨认的近景人物必须绑定 `extra_id + variant_id`；中远景可以只绑定 `group_id + variant_id`。
- 变体删除或不可用时，已锁定分镜保留其提交快照；未锁定分镜报告缺失，不随机换成其他变体。
- 变体只描述外观和状态，不替代场景站位、动作时间轴或武打招式。

## 工作域交接

1. **剧本/资产提取**：逐场记录人物或群体出现、是否可辨、对白/行动/重复出现证据、时空与未决指代。输出可审阅的独立人物候选、固定群演候选或群组模板候选；不随机指定外貌，也不把一群人拆成无证据的独立角色。
2. **角色设计**：对已确认的独立身份设计稳定的正、侧、背面识别锚点、相对身高与 Look；固定群演可用简短资产卡和多个已保存 `variant_id`。模板只定义年龄/体态范围、服装族、色彩与差异边界，并可保存多个群体变体，不冒充一组已验证的固定面孔。身份图、造型图和场景图各管自己的范围。
3. **场景设计**：保存街道、铺面、出入口等固定空间区域及人群可通行范围。人数、人物站位和近中远可见性属于当前场次或镜头，不写成永久地点事实。
4. **分镜设计**：逐镜从已确认人物 ID 或群演 roster 选择实例和变体，记录空间锚点、镜头中的可见层、朝向、路径、遮挡和可读性。跨镜出现的固定群演沿用同一 `extra_id + variant_id`；模板实例沿用已选 `group_id + variant_id`，不声称固定脸。镜头切换时核对进出方向、人数和位置，不能随机重抽已出现的个体。

近、中、远是镜头视角下的可读程度，同一人因运镜变近不会自动换身份。需要观众辨认的脸必须有已确认的独立身份及适用参考；缺失时提出补资产或调整镜头可读性，不编造“已锁脸”。已确认的资产与镜头绑定可以形成提交快照；未锁定镜头读取当前有效版本。文字标牌归道具/场景文字资产，群演模板不能保证生成出可读字。

## 验证边界

检查提取覆盖、ID 引用、造型生效范围、镜头人数和空间连续性。结构化引用只证明提交意图；是否真的保持面孔、身高与服装，要用同一模型的连续镜头结果逐帧核对。不要把模型生成稳定性写成 Skill 已保证的能力。
