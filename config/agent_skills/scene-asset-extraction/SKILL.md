# 场景资产提取

将输入拆成可跨镜头复用的地点基线与仅属于当前镜头的内容。先识别地点身份，再记录可确认的固定结构、地标、材质、环境、默认时间与世界光影。参考图仅能证明其中可见的内容；未给出的背面、内部结构和光源不要补成事实。

## 输出边界

- `asset_baseline`：地点身份、类型、固定结构、固定地标、材质、环境纵深、默认时间、世界光影、可复用构图倾向和场景约束。
- `shot_only_content`：当前事件、人物和道具引用、人数、前中后景分配、临时站位、动作、受力、镜头、局部光影、声音。
- `visual_notes`：从基线生成的简短展示摘要，不引入新的事实。
- `uncertainties`：无法从输入证实、但会影响资产设计的歧义。

每项依据标为 `observed`、`inferred` 或 `authored`。用户明确指定的内容优先；推断和设计补充不能伪装为剧本或参考图事实。场景中出现的可移动物件只有在被指定为地点长期布置时才作为固定地标。

## 地点覆盖与区分

先列出剧本中每个有独立空间身份的地点及该处出现的人物，再判断两处提及是否指向同一物理空间。合并时逐项核对地标与固定结构、明确的空间指代、人物是否重复出现、人物移动路径及时间连续性；人物交集只是线索，不能单独证明同址，人物不重合也不能单独证明异址。同属一条街、同叫“街角”或共享时间与光影，不足以证明是同一地点；用户明确区分的地点必须分别保留。没有同址证据时保留独立地点，并在 `uncertainties` 标明待确认关系，不为了减少场景数量吞掉另一处地点。人物的出场和动作属于对应地点的 `shot_only_content`；缺乏固定地标时不编造建筑或摊位。

例如“苏砚在梧桐树街角观察粮铺；另一处街角的江灼惩戒欺凌卖艺少女的打手”：提取“青溪镇梧桐树街角”与“青溪镇另一处街角”两个地点。梧桐树只属于前者；江灼、卖艺少女和打斗只进入后者的当前镜头内容。江灼随后走入长街与苏砚交手，引用长街资产，不再按角色姓名新建地点。

若原文先写有固定地标的街角，后写“方才街角另有一伙”及另一组人物和事件，却没有明确同址或人物移动证据，应为后者保留独立地点候选；不要只把“另一处街角发生的事件”塞进整条长街的 `shot_only_content`，同时在 `uncertainties` 里问它是否与前一街角重合。用户已确认两处不同时，直接按两处地点输出，不再把重合列为待核对。

## 跨地点空间关系

从剧本或用户确认中提取稳定的相邻、连通和可见关系，分别写入相关地点 `asset_baseline.environment`。例如用户确认“街边阁楼屋檐能看到粮铺门前的交手区域”：阁楼基线记录从屋檐可望见粮铺门前；粮铺基线对应记录从粮铺门前朝阁楼方向可见屋檐。两处资产共享这条空间视线，但是否在具体分镜中拍到对方，仍由机位、景别和遮挡决定；需要时可在粮铺镜头构图中为阁楼预留位置。视线成立不等于已知距离、高度、精确朝向或遮挡细节，这些仍列为待核对。阁楼中有人潜伏、粮铺被人围堵只属于当前镜头事件，不得写成地点身份。

## 复用检查

问：同一地点在另一场戏、没有当前人物和事件时，这段描述是否仍然成立？不成立的内容移入 `shot_only_content`。例如“青溪镇长街中段粮铺、木柜台、粮袋和竹筐”可留在基线；“流民匪寇劫掠、百姓退让、近景三人”属于当前分镜。已确认的街道光影可成为本地点的默认光影；具体镜头仍可覆盖它。

生成参考图时只编译基线和本次明确选择的镜头覆盖。分镜提示词引用场景基线，不继承 `shot_only_content` 中与当前分镜无关的事件。
