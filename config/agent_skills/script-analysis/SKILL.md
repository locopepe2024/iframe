# 剧本分析

以原文和用户已确认决定为依据，先识别事件、出场人物、剧情时段及每个物理地点候选，再为资产和导演阶段提供可审阅的事实与未决关系。叙事场次与物理地点分开：同一地点可以跨场重现，两个同名地点不能仅凭名称合并。

## 地点与关系

- 覆盖原文中每次地点出现，包括非相邻场次；记录该处的人物、事件、地标、移动路径和时间线索，用来判断是否同一物理地点。人物交集只是证据线索，不单独证明同址或异址。
- 合并地点须有明确空间指代、固定地标或连续移动等证据。缺少证据时保留独立候选并标注待核对；用户明确确认不同地点时不得再次合并。
- 从剧本或用户确认中提取相邻、连通、跨地点视线和遮挡关系。视线关系记录观察端和被观察端；若用户确认双方可见，则在两个地点候选中分别表达。不要由单向观察自行推断反向观察，也不要由可见推断精确距离、高度或朝向。
- 判例仅在当前剧本或用户确认包含相应事实时使用：若苏砚所在的梧桐树街角与江灼、卖艺少女所在的街角已确认不同，保留两处；若阁楼屋檐与粮铺门前已确认互相可见，分别记录从阁楼望见粮铺门前及从粮铺门前朝阁楼方向可见屋檐。不得把判例中的人物、地点或视线带入其他剧本。具体分镜是否拍到对方由机位决定。

## 交接

人物与群体出现记录遵循 [人物层级与群演连续性](../performer-tier-continuity/SKILL.md)：先识别出场证据及是否需要个体连续性，再提出主演、配角、固定群演或群体模板。层级是待审阅的制作判断，不由称谓或出现次数自动定案。

当原文出现“路人、百姓、围观者、行人、商贩、江湖人物、士兵”等背景群体时，必须在实体提取结果的 `crowd_groups` 中提出群体模板候选。群体合并必须同时满足社会身份、服装体系、典型道具、行为目的和视觉功能相近；任一维度形成明确身份差异时就建立独立主组。例如普通百姓、普通行人、围观者和沿街商贩可归入“青溪镇市井百姓”并写入 `role_tags`，但士兵与百姓、江湖人物与百姓、流民匪寇与普通路人必须分组，即使同处一个地点也不能合并。不要仅凭同一地点或“人群”这个泛称合并群体。候选不进入 `characters`，也不把每个匿名路人拆成独立角色。候选只描述群体外观范围和可复用视觉锚点，是否采用由资产库/群演资产环节决定。

实体提取时，每个地点候选须有独立 `scenes` 条目；来源支持的可复用地点事实交给场景资产基线，当前人物、劫掠、打斗和镜头站位留在事件或 `shot_only_content`。导演理解时，逐场核对 `scene_summaries` 的地点与时段，在 `continuity_constraints` 写有依据的跨场/跨地点关系，在 `unresolved_questions` 写影响设计的未知项。不要把推断或导演补充伪装成原文事实；模型草稿须经用户审阅才成为已采用结果。

本 Skill 不决定角色长相、场景材质和灯光设计、道具外观、构图、镜头数量或动作招式。已确认的资产素材和设计版本只能作为约束读取，不反向改写剧本事实。
