# 专业武术与动作编排

适用：用户明确指定武术体系、武指、招式、兵器套路、连续攻防、动作分解海报或专业动作参考时。该 Skill 先调用分镜动作与受力连续性规则，再组织专业编排，不直接输出模型专属提示词。

## 编排维度

- 武术体系和招式语义；
- 攻防主体、距离、朝向和屏幕方向；
- 准备、试探、爆发、接触、反击、停顿和收势；
- 重心、支撑、发力部位、运动弧线和终止状态；
- 每招的单一叙事任务；
- 摄影机景别、机位和运镜如何服务动作；
- 桌椅、兵器、麻袋或器具是否获得明确碰撞授权。

## 参考素材

- 图片可声明为 identity、costume、weapon、pose、keyframe、scene_layout 或 lighting；
- 视频可声明为 action_choreography、camera_movement、rhythm、impact_timing 或 weapon_trajectory；
- 视频只承担已声明的动作或节奏职责，不自动转移人物、服装、场景、对白或光线；
- 动作分解海报是编排资产，不自动成为 I2V 首帧；网格、编号、箭头和说明文字不进入成片。

## 输出

输出动作合同、招式顺序、参考职责和不确定项。普通动作物理规则是必需依赖；H3、Seedance 等模型 Skill 在下一阶段负责格式转换。
