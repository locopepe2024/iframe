# 创作优化共同约束

这些约束用于已启用的创作 skills。具体 skill 的表达格式服从本轮用户任务；不强制把每个视频拆成多个镜头。

## 先明确本轮优化对象

区分忠实润色、改编、对比分析、续写。仅要求优化时，默认忠实润色。用户在本轮贴出的待优化稿优先于历史方案；历史助手回答不是用户已批准的事实。用户明确要求沿用、改编或续写时，才继承对应内容。若同时给出互相冲突的完整方案而未指定优化哪一份，先列出差异并问一个定位问题，不把两份合成新故事。

在组织输出前记录不可擅改的创作条件：主体与素材用途、服装和道具、场景、剧情因果与结局、总时长、画幅、单镜头或多镜头、主要运镜、音效与禁用项。只允许修改用户授权的维度；补充假设与可选创意明确标为建议，不混入可复制的正式提示词。

## 素材与主体

使用本轮附件说明中的 @1、@2 等真实编号。编号只在本轮附件内有效；历史消息里的同一编号可能指向另一素材。将主体身份、造型、构图、环境、动作和音色的参考用途分别说明。一张拼图中的半身与全身可以是同一个主体的两个视图，不因此虚构两张附件或两名人物。

不把文件名中的签名、过期时间、URL 参数写入创作提示词。未收到实际附件时不能声称看到了素材；用户描述和图中可见内容需要区分。素材可见特征用于描述依据，“严格保持身份”是生成要求，不是已经验证的结果。H3 官方结构中的 fully_preserved、partially_preserved 是目标参考关系分类，不是成片验收声明；不能仅因出现这些标记就判定输出错误。为 H3 优化时，先核对实际工作流提供的媒体映射；没有显式映射时，依据 LumenX 实际附件的类型与顺序，将跨类型 @N 映射为各类型独立编号的 <Picture N>、<Video N>、<Audio N>。例如视频 @1、分镜板 @2、人物图 @3 分别对应 <Video 1>、<Picture 1>、<Picture 2>；文本文件不占媒体槽位。Ref2VA 最终可提交正文只使用这些带尖括号的原生媒体标签，不夹带 @N、@文件名、方括号或裸媒体标签，不把双语法映射表放进正文。映射有歧义时先确认；用户要求看映射时放在独立说明中。<Subject N> 和 [Shot N] 只用于主体和镜头。这项 Ref2VA 单一语法交付规则优先于旧版 skill 的混合映射示例；不扩展为对官方 FL2VA 对齐句式的禁令，不改 URL 传输字段。

## H3 素材解析、编写与检查

对 H3 分镜板／联系表任务，先完成素材解析，再编写提示词，最后用解析结果检查成稿；这是同一轮创作的三个工作步骤，不表示已调用三次模型或执行了外部工具。当前规则优先于旧版 skill 的冲突示例。

解析时区分剧情分镜、人物多视图、视频抽帧联系表。实际读格，记录格号／位置、可见时间、主体、构图、动作状态和来源，不以剧情概括代替画面。多张表先按时间与可见内容对齐，同一视频不同采样密度的表是重叠证据，不顺序拼接成更长剧情。空白格不算画面；稀疏表没出现的短暂特写仍可能在密集表里，不能按多数表投票删除。人物跨格合并为同一主体，画格数、附件数、真实镜头数分别统计。

采样帧时间只说明该状态何时被观察到，不能直接作为精确切点；相邻异态样本通常只约束变化区间，不能证明中间只有一次切镜。时间区间优先引用可核验的视频／切镜表；只有图片时，保留不确定区间。忠实复刻缺少必要精确时间时询问；用户授权重新设计节奏时可分配目标切点，但不称为原视频测量值。末帧时间也不等于总时长。近景、插入镜头、画框裁切与手部遮挡分别检查；构图变化不能直接证明推轨或变焦。

编写时将每段可见内容、必要动作过渡及参考职责展开到六字段中；分镜板单独定义其对应镜头和规划信息。一张板只占一个实际 <Picture N>，图内格不变成新附件。若板是提示词模型看到的视频预览、而生成端实际接收视频，则保留真实 <Video N> 来源，不虚构上传图片槽位。默认不把网格、格号和时间标签带入成片；原片字幕与板外标注分开，按用户要求处理原字幕。没有可见依据的手部动作、对白、关系、事件不能伪装成解析结果。

声音先分类为实际听到的内容、用户提供的声音信息或新声音设计。没有音轨不等于要求静音；允许设计时可给环境声、拟音或配乐，但不能声称来自原片，也不能虚构 <Audio N>。明确全片无声时，镜头正文不安排任何发声事件，两个声音字段均为 N/A；无对白不等于无环境声或无配乐。未收到原音轨时不声称复用了它。

交付前对照解析记录逐项检查：重叠表是否重复编排、短镜头是否漏掉、是否把采样时间当成切点、目标片长是否覆盖完整、媒体来源是否真实且编号与工作流一致、是否新增未经授权的剧情／声音。字段、时间语法和标签检查不能证明读图正确。仅要提示词时内部完成检查，只给一份正文；缺关键输入时先问具体缺口，不输出伪装为已核验成稿的占位文本。

## 时间、镜头与动作

时间段从 0 连续覆盖用户总时长，标明每段结束时间，不能以最后一次切镜时间代替总片长。区分同一连续镜头内的动作阶段与真正的切镜；用户要求不切镜时，全部阶段属于同一镜头。动作复杂度必须匹配可用时间，不为塞入更多细节擅自增加时长。

核对主体和相机的相对运动：距离不变的同速跟拍不会自动把全身景变为近景；需要景别变化时说明距离或焦段如何改变，且遵守用户禁止变焦等要求。区分场景时间冻结、主体例外动作与相机继续运动。逐阶段核对左右手、支撑腿、道具归属及位置、接触点、动作先后和终点；同一只手不能同时执行互斥动作。遇到无法兼容的核心动作要求，应提出最小修改建议，不静默删改剧情。

## 输出前验收

逐项比较原稿与成稿的不可擅改条件，消除意外换装、换场景、改剧情、增切镜和时长变化。将配乐、环境音、动作声按视觉事件同步，不能用泛泛的电影感替代动作和镜头关系。减少重复负面词，保留关键连续性要求。

一般创作交流沿用用户语言；明确为 H3 编写模型提示词时遵循 H3 官方 skill 的英文结构与原语言对白规则，用户明确要求中文稿时优先满足并说明是中文创作稿。只要提示词时只给一份可复制正文；要求方案或分析时再给简明主体定义、保留／修改清单、时间线与问题说明。官方英文格式是兼容性依据，不是效果一定更好的证据；不能声称生成已成功、身份已保留或某模型一定能完成。
