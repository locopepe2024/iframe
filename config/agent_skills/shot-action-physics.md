# 分镜动作与受力连续性

适用：所有包含接触、受击、推拉、踉跄、跌倒、追逐或物体碰撞的分镜动作。该 Skill 属于分镜时间动效，只输出模型无关的动作合同，不设计首帧构图或输出 H3、Seedance 等模型的专用格式。

## 必须明确

1. 施力者与受力者；
2. 接触部位；
3. 受力方向和身体位移方向；
4. 受力者的面向关系与画面位置；
5. 支撑脚、重心和失衡过程；
6. 可观察的动作时序与终止状态；
7. 道具是否发生碰撞。
8. 面部或眼睛可见时的视线目标及其转移时机。

默认按以下顺序组织：

```text
起始状态 → 施力/接触 → 受力反应 → 支撑变化 → 位移/失衡 → 终止状态
```

## 硬约束

- “门侧”“柜台旁”“墙边”等空间名词不代表人物会转身或朝向该物体移动；
- 未明确指定时，受击者保持原有面向和左右画面位置；
- 未提供方向证据时标记不确定，不猜测；
- 运镜与人物运动分开描述；
- 道具默认保持原位，不自动增加翻桌、撞墙、碎裂、飞散或特效；
- 用户明确指定桌面、墙面、柜台或其他障碍物发生碰撞时，该物体必须进入受力链，写出碰撞先后、接触点和可见结果；
- “猛然、快速、立即、接触瞬间”等词默认按实时速度表现，不改写成慢动作、长时间悬停或逐渐倒下；
- 一个接触事件只发生一次，不在后续阶段重新接触或重新命中。
- 面部或眼睛可见时，不默认让角色盯镜头；视线应指向当前对手、主动接触部位、移动道具或其他已确认的画内目标，并随动作阶段更新。没有可确认目标时，写明视线朝向或画外方向，不编造具体注视对象。

明确的障碍物碰撞应按以下顺序写：受击 → 踉跄/失衡 → 撞到障碍物 → 手或身体扫落物品 → 倒地终止。没有明确授权时，不补充碰撞对象。

## 输出要求

输出动作合同，至少包含 `source`、`target`、`contact`、`force_direction`、`reaction_sequence`、`screen_position_lock`、`prop_interactions` 和 `uncertainties`；面部或眼睛可见时增加 `gaze_target_sequence`。模型专属 Skill 负责将合同编译成最终提示词。
