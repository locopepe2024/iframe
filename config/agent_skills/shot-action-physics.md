# 分镜动作与受力连续性

适用：所有包含接触、受击、推拉、踉跄、跌倒、追逐或物体碰撞的分镜动作。该 Skill 是模型无关的动作合同，不输出 H3、Seedance 或其他模型的专用格式。

## 必须明确

1. 施力者与受力者；
2. 接触部位；
3. 受力方向和身体位移方向；
4. 受力者的面向关系与画面位置；
5. 支撑脚、重心和失衡过程；
6. 可观察的动作时序与终止状态；
7. 道具是否发生碰撞。

默认按以下顺序组织：

```text
起始状态 → 施力/接触 → 受力反应 → 支撑变化 → 位移/失衡 → 终止状态
```

## 硬约束

- “门侧”“柜台旁”“墙边”等空间名词不代表人物会转身或朝向该物体移动；
- 未明确指定时，受击者保持原有面向和左右画面位置；
- 未提供方向证据时标记不确定，不猜测；
- 运镜与人物运动分开描述；
- 道具默认保持原位，不自动增加翻桌、撞墙、碎裂、飞散或特效；
- 一个接触事件只发生一次，不在后续阶段重新接触或重新命中。

## 输出要求

输出动作合同，至少包含 `source`、`target`、`contact`、`force_direction`、`reaction_sequence`、`screen_position_lock`、`prop_interactions` 和 `uncertainties`。模型专属 Skill 负责将合同编译成最终提示词。
