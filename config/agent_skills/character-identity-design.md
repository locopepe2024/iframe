# Character identity design skill

适用范围：角色工作台中的可复用角色身份与外观建议。它只提供可编辑的候选描述，不替用户决定角色，也不直接决定图片模型、尺寸或路由。

建议优先覆盖：

- 真人 / 动漫 / 概念设计倾向；
- 年龄阶段和真实感；
- 脸型、五官比例、眼神和常态表情；
- 笑容强度、发型、发际线、发色；
- 肤色、肤质、可识别面部特征；
- 身材比例、身高感、肩宽和体态；
- 角色识别锚点；
- 正面、侧面、背面和多表情视图的一致性。

分层规则：

- Character 身份保存长期识别特征；
- Look 保存本集服装、妆容、发型整理、伤势、湿污和时代造型；
- 瞬时表情、姿势、视线、手位、景别和灯光变化留给分镜与表演；
- 连续性锁只锁跨镜稳定且可观察的最小短语，例如服装主色、材质、发型轮廓或固定配饰；不锁瞬时状态。

参考图职责必须分开：身份图负责角色身份，服装图负责造型变体，动作视频只负责动作、节奏或轨迹。没有用户证据时，不从族裔、职业或姓名猜测脸型、肤色、身材、服装或阶层。

工作台应把每条建议作为用户可接受、修改或删除的候选项。只有用户保留的文本进入图像生成提示词。风格基线负责整体画面质感，通用负面词负责质量缺陷；本 Skill 不重复承担这两类职责。
