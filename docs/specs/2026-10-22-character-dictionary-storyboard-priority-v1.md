## 顺序与验收边界

### 1. 角色面板与词典

建立稳定字段注册表，明确字段 ID、语义域、部位、描述维度、唯一写入 owner、可用词条类别与应用动作。面板是编辑入口，词条是字段候选，Prompt 模板是任务起稿；同名但不同部位或维度的词条并列保留。组合面板引用局部字段定义，不建立第二份选项真值。先解决面容/肤色肤质、首饰/新旧，再处理整套穿搭/鞋履/配饰。旧面板 ID 与已保存配置快照继续可读。

验收：按顺序应用组合面板和局部面板后，结构化字段、预览文字与最终提交无意外重复或静默覆盖；“嘴唇形状”和“嘴唇表现”能共存；只改表情时稳定身份/造型字段不变；同名不同部位搜索结果显示归属。后端/前端保存与重载行为均需核对。

### 2. 分镜结构化一致性

每镜保存自身的场景、光照、风格、画幅和连续性状态快照，并显示各字段来源：已确认场景设计、所选场景图片变体、当前分镜覆盖、同连续性组来源镜头或用户直接输入。选择参考图时明确选择“仅图”“仅结构化参数”或“两者”；参数应用后复制为当前镜头快照，不实时跟随来源变化。无明确地点/时间连续性 ID 时不推断。

继承边界：同时间换地点只建议世界光；同地点同时间才建议空间/机位/站位。前镜动作、对白、角色描述和临时表情不能进入继承的视觉一致性字段。用户在可见预览中逐项勾选或编辑，最终请求只含已确认的文字和媒体；旧来源修订后提示过期，不静默重写当前镜头。

验收：清溪镇长街到粮店、同一长街相邻镜头、缺少连续性 ID 三组行为样例，覆盖来源选择、预览、保存/刷新、AI 优化及实际提交请求；对前镜动作/对白/角色描述设负例测试。

### 3. 分镜风格、运镜、机位

按 owner 分离世界/场景风格基线与镜头局部风格覆盖；区分静态首帧字段（景别、机位、构图、画幅）和视频执行字段（运镜方向、速度、轨迹、时长）。运镜词典只写当前镜头运动字段，不能改场景空间或角色身份。选中视频参考时先显示其运镜与机位快照，再由用户选择复制哪些字段；来源不自动绑定到请求。

验收：字段编辑后，可见正文、保存快照、刷新结果与首帧/视频请求一致；风格/光线覆盖冲突可见；不同机位共享同一场景空间与基准光；视频运镜不污染静态首帧；镜头 A 修改不会改镜头 B 或来源预设。

### 4. 图片编辑与蒙板（暂缓）

前三阶段通过后，才按 `2026-10-22-character-shot-reference-image-design-v1.md` 接入角色工作台“图片编辑”入口、独立蒙板与标注、局部生成候选和审核。该阶段不作为前三阶段的依赖，也不以提示词“保持不变”代替真实局部编辑。
