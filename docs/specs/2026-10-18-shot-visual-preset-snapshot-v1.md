# 分镜结构化视觉预设快照 V1

## 目标

允许用户把某个分镜中已经确认的结构化视觉参数保存为可复用预设，并在另一个分镜中作为起始模板。预设应用后必须复制为当前分镜自己的快照，不能建立实时继承关系。

## 复用模式

- `parameters_only`：只复制结构化风格、光影、镜头和人物呈现参数。
- `parameters_with_reference`：复制参数，并明确绑定来源分镜的首帧变体。

参考图绑定是显式选择，不能因为选择了预设而自动附加。

## 数据边界

预设保存：

- 所属项目与场景
- 来源分镜和来源变体
- 来源场景设计 revision
- 结构化参数快照
- 编译后的可见提示词

当前分镜应用后保存：

- 当前分镜自己的结构化参数
- 来源预设 ID
- 来源变体 ID（仅 `parameters_with_reference`）
- 应用模式和应用时的来源 revision

预设更新不会修改已应用的分镜；场景基线更新也不会静默重写预设或分镜快照。

## 用户流程

```text
确认第一帧结构化参数
→ 保存为视觉预设
→ 第二分镜选择预设
→ 选择仅参数 / 参数+参考图
→ 查看来源和完整编译提示词
→ 当前分镜微调
→ 应用到当前分镜
→ AI 优化
→ 用户确认并生成
```

## 验收

- 预设可跨同一项目的分镜查询。
- 应用预设后，当前分镜拥有独立快照。
- 删除来源变体不会使参数预设失效；带参考图模式应显示缺失并要求重新选择。
- 提交前显示来源预设、来源变体、场景 revision 和完整提示词。
