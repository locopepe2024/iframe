# 配音试听、放置与超长处理

## 代码事实

- 当前配音生成成功后会立即加入对白轨，用户无法先听生成结果。
- 通用音频添加从时间线 0 开始，并将长度限制到成片范围；对白长于剩余成片时长会静默裁掉尾部。
- 独立剪辑保存端要求视频片段连续覆盖 `target_duration_ms`，渲染输出时长也必须等于该目标，因此不能仅靠延长配音片段来延长成片。

## 行为

- 生成配音后先显示原生音频播放器和生成素材时长，不自动修改剪辑计划。
- 用户可以用秒为单位指定对白在成片中的起点，默认从 0 秒开始；不能放在成片范围以外。
- 若音频完整落在剩余成片范围内，用户试听后可加入对白轨，保留完整源区间。
- 若音频超过剩余时长，显示可用时长与将裁掉的尾部时长；未明确勾选裁切确认时禁止加入。确认后只裁尾，不改源素材，保存计划仍符合服务端范围约束。
- 修改台词、音色、语速或放置位置时，旧试听结果不得误用于新参数；生成素材继续作为用户素材保留。
- 取消对话框不会修改计划。放置成功后关闭对话框，并将生成音频作为本地计划的对白片段，仍需显式保存。

## 边界

- 不延长视频序列或成片时长，不静默加速配音，不自动切分文本或合成多段。
- 不对 TTS 服务、用户密钥或费用做真实调用验收；以模拟返回素材的 UI 行为测试为准。

## 验收

- 生成后可播放/暂停并查看时长；生成本身不改变 dirty 状态或时间线。
- 可指定起点并验证保存计划的时间线与源区间。
- 超出剩余时长时未确认不能添加；确认后精确裁尾，且保存结果仍在 target 范围内。
- 修改生成参数后要求重新生成；失败保持可恢复表单状态。
- 运行配音/EditingPage UI 测试、编辑合同测试、TypeScript 检查和生产构建。

## 当前状态

已实现试听、放置起点、超长裁尾确认及参数变更后清除旧试听。页面级测试验证生成不会改变剪辑草稿，普通放置和确认裁尾后的保存计划均符合成片边界。没有进行线上浏览器验收或真实 TTS 调用。
