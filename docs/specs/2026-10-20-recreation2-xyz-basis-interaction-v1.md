# recreation2 XYZ 尺度 × rig 旋转基底交互 v1

目的：在固定 root、yaw、镜头、骨盆关闭、IK关闭和源XYZ不变的条件下，比较两个因素：

1. 方向输入的 Y 是否乘 `792/1394`；
2. 子骨骼是否使用自身静止骨基底（对照为现有父/自身混合基底）。

四组均重算全部子骨骼，不能复用旧四元数。raw_mixed 必须逐值复现 no_pelvis_root 基线；其余组只允许改变声明的方向尺度/基底因素。检查 28 个独立源样本、29 个 PTS key、48 个输出帧和固定鞋底 patch。统计必须同时报告全段分位数、源 1/17/23/29/41/55、踝点、输出步长和 patch 速度。

结果不能直接提升为主链路修复。前四帧任一恶化即不称为前段通过；全段中位数改善不能覆盖事件帧、脚接触或相机/深度未验收。
