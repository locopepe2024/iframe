# 导演计划到分镜的直接应用 V1

状态：前端交互收口。日期：2026-10-23。

## Observed

按导演计划生成时，后端 `preview_storyboard_analysis()` 使用 `materialize_plan()` 逐镜转换已确认计划，不调用分镜设计模型；随后 `/storyboard-analysis/apply` 复核来源版本并保存分镜。此前前端在两步之间弹出“分镜分析草稿”页，重复展示已在导演拍摄计划确认过的镜头。独立的“从剧本设计分镜”模式会运行分镜分析，草稿仍需审核。

## 边界与验收

- 计划模式的按钮明确写“采用导演计划”；若已有分镜，显示替换数量。点击后沿用现有转换、版本校验、应用和缺项初始化，不显示草稿页。
- 转换结果必须声明 `storyboard_mode=plan`；若返回其他模式，则停止应用并报错。
- 剧本模式仍显示可修订草稿，用户审核后才应用。两种模式的结果仍在分镜工作台逐镜编辑。
- 验证计划与剧本模式的按钮及替换提示、相关后端转换测试、前端构建和类型检查。真实项目数据替换与画面质量需在线联调确认。
