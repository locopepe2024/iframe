# 分镜结构化一致性表 V1

状态：设计规格，尚未实现。日期：2026-10-22。

## Observed

- 拍摄计划已有 `shot_id`、`scene_id`、`place_continuity_id`、`time_continuity_id`、场景光线基线、景别、机位、构图和运镜；分镜帧另有光影、站位和局部覆盖。
- 场景确认设计有修订版本。生成的场景图片变体可保存当次提交的 `visual_design` 与 `design_revision_at_submission`。
- 已有显式参考投影：用户选择来源图后可查看光影、空间、镜头和连续性状态；默认仅带图，勾选字段才进入目标镜头。详见 [参考投影规格](2026-10-22-storyboard-visual-continuity-projection-v1.md)。
- 项目画幅来自模型设置。当前没有一张统一的、可按镜头核对并诊断冲突的结构化一致性表。本规格不把上述字段的存在误认为已实现跨镜校验。

## 目标

为每个分镜帧生成一行**可追溯的当前视觉状态**，供创作者检查同一时空内的光影、场景空间、风格、画幅和机位关系。用户选参考图时，表中显示来源变体对应的历史结构化版本及其可带入字段，由用户最终勾选确认。

一致性表是检查和审阅面，不是跨镜自动继承器。诊断结果不能静默修改镜头、参考选择或提交给模型的提示词。

## 行模型

每行以稳定的 `frame_id` 为主键，保存或投影以下字段；空值必须显示为“未确认”，不能靠镜头顺序、名称相似度或提示词推测：

| 组 | 字段 | 来源与优先级 |
| --- | --- | --- |
| 身份 | `frame_id`、`shot_id`、`scene_id`、拍摄计划 revision/hash | 当前分镜和已确认拍摄计划；编号仅用于排序，不用于推断连续性 |
| 时空 | `place_continuity_id`、`time_continuity_id`、地点、叙事时间、天气 | 已确认计划与当前场景绑定；ID 缺失时状态为 unresolved |
| 世界光 | 日光阶段、天气、阴影方向、叙事时间 | 当前镜头显式值优先，其次当前场景基线；参考来源仅填用户确认且目标为空的字段 |
| 局部光 | 主光来源/方向、环境光、色调、对比及局部覆盖 | 当前镜头优先，其次当前场景基线；不同地点不能从参考镜头带入局部光 |
| 空间 | 场景资产及设计 revision、材质/空间锚点、参考视角/取景 | 当前场景确认设计与当前镜头覆盖；仅同地点同时间允许候选参考字段 |
| 镜头 | 景别、机位、构图、运镜、站位/相机关系 | 当前分镜；参考字段仅同地点同时间可勾选，且不覆盖目标显式值 |
| 风格 | 集级风格配置标识及 revision、本镜风格覆盖 | 项目/集级设置及分镜显式覆盖；引用标识与版本，不通过匹配自由文本判断相同 |
| 输出 | 画幅、目标模型/能力配置 | 本次有效生成设置；分辨率和帧率只在相应生成阶段有明确设置时记录，不捏造默认值 |
| 参考 | 来源资产/帧/变体/media ID、提交时视觉设计 revision、勾选字段、确认 revision | 用户选定的图片及其不可变提交快照；与当前场景设计修订分别展示 |

每个可比较值还要带 `value`、`source_kind`、`source_id`、`source_revision`、`status`（confirmed / explicit_override / unresolved）。同一字段有多个来源时展示最终值和被覆盖来源，不能只显示拼接后的文字。行应支持查看本次实际生成使用的冻结快照，而不是用后来变动的当前设计回填历史结果。

## 参考选择与勾选

1. 用户显式选择图片变体或分镜参考后，显示该**图片生成时对应的结构化版本**、来源标签和与目标行的差异；图片和结构化字段分开呈现。没有提交快照的旧图标为“结构化版本未知”。
2. 默认仅带参考图，所有结构化字段未勾选。用户可在允许的字段内逐项勾选光影、空间、机位和连续性状态，并查看最终提示词及图片列表。
3. 同时间不同地点只提供世界光；同地点同时间才提供空间、局部光、机位和站位；明确不同时间只用图。缺少连续性 ID 时展示字段及“不确定”的原因，只有用户明确选择才允许相应类别，不推断同地同时间。
4. 来源的完整提示词、人物描述、动作、表演、对白和音频永不作为可勾选字段。目标镜头的显式值优先；无法判定覆盖关系时阻止该字段自动合并，并要求用户处理冲突。
5. 确认保存来源变体/media ID、来源结构化快照哈希、目标 revision、所选字段和值。来源图片或其快照改变时要求重新预览和确认；来源场景后来产生新设计 revision，不改变旧变体的历史版本。

## 诊断规则

诊断只比较有明确来源和可比作用域的字段，结果含受影响镜头、字段、两侧值、版本及建议审阅动作。

| 范围 | 检查 | 结果 |
| --- | --- | --- |
| 同 `place_continuity_id` + `time_continuity_id` | 世界光、局部光和场景空间锚点是否冲突 | 标记需审阅；明确的分镜局部光覆盖可解释冲突，但必须展示原因 |
| 同 `time_continuity_id`、不同地点 | 世界光是否冲突 | 只比较世界光，不要求局部光或机位相同 |
| 同一输出序列 | 画幅及明确配置的帧率是否一致 | 标记配置差异；允许有意的输出段落边界 |
| 同一风格作用域 | 风格配置标识/revision 是否一致 | 标记版本差异；镜头显式覆盖单独显示，不直接判错 |
| 参考确认快照 | 图片身份、结构化版本及勾选值是否仍对应 | 不一致时阻止沿用旧预览；保留已生成结果的历史记录 |
| ID 缺失或多重映射 | 是否可确定比较作用域 | 标记“无法判断”，不产生“保持一致”或“冲突”结论 |

机位和站位不要求跨镜逐项相等；只检查明确声明的连续关系或用户选定参考中的空间约束。不能仅凭相邻镜头就要求相同远景、机位、角色动作或对白。

## 界面与提交边界

- 分镜列表提供紧凑的一致性状态入口；表格可按场景、时空 ID、状态筛选，展开行查看字段来源、版本和冲突详情。
- 参考选择面显示“来源值 / 当前目标值 / 将带入值”，勾选控件由用户操作；不预勾选、不因诊断结果自动添加参考图。
- 提交预览显示最终文本、图片变体身份、模型和画幅。预览 token 绑定目标行、参考快照、勾选集与有效生成设置；正式生成及候选生成提交同一冻结内容。
- 诊断状态与生成状态分开：存在提示级差异仍可由用户继续；来源身份或预览失效属于提交错误，必须重新确认。

## 验收边界

- 每镜有可追溯结构化行；缺失字段明确显示，绝不伪造统一值。
- 选择旧场景图片变体时显示该变体生成时的视觉设计和 revision，而非场景最新设计。
- 不选择参考时没有跨镜来源字段；选择后仍默认只带图；只提交用户勾选且符合时空边界的字段。
- 同时间不同地点的案例只可带世界光；同地点同时间可审阅空间/机位/站位；缺 ID 不猜。
- 来源动作、对白、角色描述及完整提示词不会进入目标提示词。
- 对比表能分别标出真实冲突、显式覆盖和无法判断；镜头顺序不产生关系。
- 候选与正式生成的实际请求和审核预览一致；来源快照或目标设置变化使旧预览失效。

## Not yet proven

- 结构化一致性检查能否提高最终画面的视觉一致性，需要同一组镜头的生成样本和人工审阅；代码与表格只能证明输入及版本一致。
- 不同模型对参考图和各结构化字段的遵从程度尚未验证，不能把勾选视为输出保证。

## 实施切片与验证

1. 投影只读行和字段来源；用含缺失 ID、显式覆盖、旧变体快照的测试核对投影，不更改生成请求。
2. 加入按作用域比较的诊断；测试同地同时间、同时间异地、不同时间及 unresolved，不依赖场景名称匹配。
3. 把表格与现有参考勾选面连接；用请求捕获测试验证预览、候选、正式提交及过期拒绝，再做小样本实际生成审阅。
