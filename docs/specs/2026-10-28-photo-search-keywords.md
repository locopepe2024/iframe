# 照片文字与语音共用检索

文字与语音识别后的请求均使用 photo.album.list。Agent 将明确的时间转为 year/date_prefix，将人物、地点、场景、光影或故事关键词用空格分隔传入 query。每个词都必须在同一照片的最新用户资料、讲述或已核对描述中出现，允许跨来源匹配。单词仍为字面子串，不提供向量或同义词检索。

例如“找2025年女儿在海边的照片”传 year=2025, query="女儿 海边"。不得从姓名猜亲属，不明确的相对日期须依据会话日期或澄清，不自行改成上传时间。缺少范围的整理请求先问一个问题；明确搜索零结果时如实报告，可让用户减少条件，不自动展示全库。

原始 AI 观察仍不纳入搜索；需用户核对描述或保存资料。搜索命中来源/版本保持可追踪；所有筛选在分页前执行，排除其他用户、删除照片与历史版本。结构化资料仅搜索字段值，不匹配 JSON 字段名。

影响路径：photos/workflow.py、companion_runtime/tools.py、照片搜索及工具桥接测试。验收：组合词跨来源、日期组合、错误关键词不命中、最新版本优先、分页完整、权限隔离。真实语音识别和上游模型提取准确率需部署后另测。
