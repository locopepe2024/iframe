# Companion 移动端布局检查（2026-10-30）

范围：聊天输入区、相册搜索、全图查看、日记月历、设置页。只调整布局，不改变模型路由、工具调用和语音流程。

## 已验证的问题与修复

本地 Chrome 布局复现：放大根字号时，聊天的语音/发送按钮被挤出视口；320px 窄屏下月历与全图查看控件溢出。

修复：窄屏图标按钮使用固定触控宽度，工具栏必要时换行；日历采用可收缩的七列，日期字号按窄屏约束；全图查看控件可以换行；横向安全区补充至聊天、设置与素材查看器。长消息和筛选文字允许断行。

日历七列在最窄屏上无法同时保证每列44px且不溢出，因此保留48px高度，允许列宽缩小；较大设备仍按可用宽度分配。

## 验证

- `node frontend/scripts/companion-mobile-layout-smoke.mjs`：90组布局检查通过。视口320×568、360×800、390×844、430×932、844×390、390×400；根字号16/24/32px；五类界面。
- 脚本直接加载实际CSS，使用与组件结构对应的本地HTML测试内容，检查横向溢出和操作控件是否被挤出视口。不是完整React端到端测试。
- `npm run typecheck`：通过。
- 日历、相册、全图查看器、输入区组件测试：27项通过。
