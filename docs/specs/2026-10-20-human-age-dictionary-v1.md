# 人类角色性别与年龄词典 v1

当前仅人类；不实施动物/物种筛选或参考图。本次新增性别、年龄选择与稳定 identity.features.gender / age 字段，复用现有结构化设计、AI 优化、保存和出图路径。

性别提供男性、女性两个快捷选项，支持结构化字段自由编辑，不指定时不加限制、不从外貌推断。

年龄阶段独立于脸型、肤质、体态。提供婴儿、幼儿、儿童、少年、青年、成年、中年、老年，不自动附带皱纹、弯腰、服装、妆容或性别。默认不指定，不默认成年。精确年龄由用户在年龄设计字段自由编辑，例如“约六个月”或“约72岁”；不按阶段擅自补充岁数范围。

性别入口：基础面板“基础特征 → 性别”、词典“身体 → 性别”、/性别、[性别] 槽位。

年龄入口：基础面板“基础特征 → 年龄”、词典“身体 → 年龄阶段”、/年龄，以及 [年龄]/[年龄阶段] 槽位。配置写入 identity.features.age；同一字段更换阶段时覆盖原值。兼容旧 age_stage，旧数据仍可读取，本次不批量迁移。已有完整模板中的明确成人身份不自动改写；用户组合不同描述时应检查冲突，后续适用性筛选另做。

验证：词典阶段和槽位、默认空、结构化年龄应用/保存/恢复/出图、AI 结构化输入优先于模型推测、后端字段校验；相关逻辑/UI/后端测试、类型检查和生产构建。不自动请求付费生成或部署。

用户进一步确认：性别、年龄、身高合并为一个“基础特征”面板并优先展示，原有单独身高面板由该面板替代。三个字段各自不指定、独立修改、独立存储；/性别、/年龄、/身高均定位此面板。

## 实施结果

已接入基础特征面板、性别/年龄词条及 [] 槽位，新增 identity.features.gender/age，前后端字段校验与 AI 用户输入优先规则同步。设计面板将三字段独立成组，宽屏一行三项、窄屏纵向排列。新 age 有值时，不再拼入旧 age_stage 描述。

本地验证：前端逻辑 20 项、词典/工作台 UI 96 项、后端设计保存与 Agent 51 项通过；类型检查及生产构建通过。未进行真实付费生成、未部署。
