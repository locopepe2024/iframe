# 分镜 Skill 两阶段归属清单 V1

状态：设计核对，尚未更改运行时加载。日期：2026-10-23。

## Observed

- 代码事实：当前单镜润色复选框同时列出 `minimax-h3-director`、`seedance-prompt`、`seedance-camera`、`sequence-continuity`、`director-style`。它们作为整段指导文本进入模型提示词，不返回逐字段分镜设计候选。前端按 H3/Seedance 筛选，后端也校验目标模型兼容；H3 默认选 H3 导演，Seedance 默认选 Seedance 提示词。MiniMax Context-IR 入口不加载这些复选项。
- 代码事实：`director-tasks.json` 的四张 `storyboard-*` 方法卡属于从剧本生成镜头草稿。`micro-expression-timing` 已在 Skill 目录中，输出限定为角色表情时序 JSON；它不在普通视频润色复选框中。
- 代码事实：当前 `seedance-camera` 的规则包含起始景别、机位、路径、速度、主体关系和落幅，但其输出要求仍是一条可复制运镜提示词。`seedance-prompt` 的输出是一份 Seedance 可复制提示词。H3 指令包同时含素材解析、镜头设计建议、三段/六段编译和提交校验。

## 目标顺序

1. **分镜提示词优化，模型无关。** 读取当前镜头任务、已确认剧情和设计字段、参考图用途与快照、连续性 ID、项目画幅和用户约束。按作用域产出可审核的字段候选，而不是先写完整的 H3 或 Seedance 正文。用户逐项采纳后保存新的分镜设计版本。
2. **分镜模型提示词优化，模型有关。** 读取同一份已采纳的分镜设计版本和当前媒体集合，按目标模型的输入模式、语法和能力编译最终正文。只整理表达、映射媒体和校验；不新定剧情、机位、表演、时空关系或参考用途。用户预览的文本与提交文本绑定同一版本。

切换 H3/Seedance 时保留已采纳的模型无关字段，仅重跑第二阶段。模型能力不支持的字段标为不可表达或需用户调整，不静默删改第一阶段的决定。未采纳的候选不得进入第二阶段。

## 名称与 ID 规范

- **模型无关方法**：用户可见名称采用“分镜 + 设计对象 + 动作”，如“分镜摄影设计”“分镜微表情时序”“分镜连续性审阅”。名称和新 ID 都不含 `H3`、`Seedance` 或提供方名称；目标模型列表用于兼容性元数据，不写进名称。输出必须是可审核的设计字段或诊断。
- **模型相关适配**：名称采用“模型名 + 提示词适配”，如“H3 提示词适配”“Seedance 提示词适配”。明确它编译已确认设计，不暗示重新导演镜头。模型模式、媒体语法及能力校验放在这一层。
- **专门模型工作流**：只有任务本身依赖特定模型能力时才在名称保留模型名，如 H3 原片再生成；不因方法来源于 Seedance 项目就把 Seedance 写进通用摄影方法名称。
- **迁移规则**：不能仅删除旧名称中的模型词就宣称跨模型通用。先建立新的模型无关 ID、字段输出合同和行为验证，再在第一阶段显示新名称；原 ID 继续代表旧语义，供现有保存值与调用兼容。若未来废弃旧条目，需单独处理已保存选择和目录安装状态。

| 阶段 | 推荐用户可见名称 | 新 ID 或旧条目处置 |
| --- | --- | --- |
| 模型无关摄影 | 分镜摄影设计 | 新 ID `shot-camera-design`；从 `seedance-camera` 提炼方法，不复用旧 ID |
| 模型无关表演 | 分镜微表情时序 | 现有 `micro-expression-timing` 可保留 ID，用户可见名称按阶段统一 |
| 模型无关连续性 | 分镜连续性审阅 | 新 ID `shot-continuity-review`；不改变 `sequence-continuity` 的旧输出合同 |
| 模型无关视觉意图 | 分镜视觉风格建议 | 新 ID `shot-visual-style-design`；不改变 `director-style` 的旧输出合同 |
| H3 编译 | H3 提示词适配 | 新 ID `h3-prompt-adapter`；从 `minimax-h3-director` 拆出编译，旧 ID 保留迁移期兼容 |
| Seedance 编译 | Seedance 提示词适配 | 新 ID `seedance-prompt-adapter`；读取已确认设计，旧 `seedance-prompt` 保留原语义 |
| 旧 Seedance 运镜全文 | Seedance 运镜提示词（旧版） | `seedance-camera` 暂时只表示 Seedance 专用整句输出；不显示在新的模型无关方法组 |

界面用“分镜设计”与“模型提示词”分组展示，不在同一复选框列表混排两种阶段。来源与许可继续在详情中保留，不把来源项目名误当成能力范围。

## 现有 Skill 归属

| 现有条目 | 现状与实际能力 | 目标归属 | 迁移决定 |
| --- | --- | --- | --- |
| `storyboard-suspense`、`storyboard-action`、`storyboard-emotion`、`storyboard-dialogue` | 从剧本拆镜的方法卡，产出镜头草稿；`storyboard-emotion` 不设计镜内微表情时序 | 上游镜头草稿，第一阶段的已确认输入 | 保留原入口；不加入单镜优化或模型编译 |
| `seedance-camera` | 有通用摄影判断方法，但声明目标 Seedance，输出可复制运镜句 | 第一阶段的摄影字段提案 | 提炼为新的模型无关摄影设计 Skill，输出景别、机位/轴线、构图、主运动、路径、速度、起落幅及理由；旧 ID 不直接改名或跨模型复用 |
| `micro-expression-timing` | 指定角色的 trigger/change/hold/release JSON，禁止改身份、服装、场景和摄影 | 第一阶段的表演字段提案 | 保留独立作用域；首帧仅取起始可见状态，视频读取完整时序 |
| `sequence-continuity` | 规划多镜头并输出分镜表和当前镜完整提示词；现处单镜润色复选框 | 第一阶段的跨镜审阅 | 收窄为显式连续性 ID 范围内的冲突/状态交接候选；不自动继承前镜动作、对白或人物描述，不写整段最终正文 |
| `director-style` | 把叙事意图映射到构图、光线、表演等，但也要求可复制全文 | 第一阶段的视觉意图及局部覆盖建议 | 只提有来源的字段建议和理由；已有项目/场景风格是约束，不以 Skill 覆盖。与摄影或表演项重叠时合并为一个字段候选 |
| `seedance-prompt` | Seedance 自然语言整理、压缩、引用保持 | 第二阶段的 Seedance 编译 | 保留 Seedance 专属；删冗词不得删除已采纳的动作起止、镜头关系、声音或参考用途 |
| `minimax-h3-director` | 混合 H3 媒体解析、通用动作/摄影建议、三段/六段格式及校验 | 第二阶段的 H3 编译，加独立的输入解析/硬合同 | 拆出可复用的镜头方法交第一阶段；媒体槽位、模式、字段顺序、对白和声音语法留在 H3；硬校验不得成为可关闭的创作选项 |
| `h3-product-recreation` | 原片参考视频与商品替换的专门工作流 | 复刻/商品工作流 | 不进入普通单镜优化 |
| 角色身份、角色题材、图片提示词和短片结构条目 | 分属角色工作台、图片设计或 Creative Agent | 各自原阶段 | 只把其已确认产物作为分镜输入，不加载原 Skill 全文 |

## 第一阶段字段合同

| 方法组 | 可提议字段 | 不可改变 |
| --- | --- | --- |
| 动作/表演 | 当前镜头动作起止、可见阶段、指定角色微表情、身体不变量 | 剧情事件、人物身份、台词、参考素材用途 |
| 摄影/时间 | 景别、机位/轴线、构图、主运镜、路径与速度、起落幅、镜内节奏、切点/转场建议 | 项目画幅、未授权增删镜头、场景结构 |
| 风格/光线 | 当前镜头有理由的局部覆盖及其有效来源 | 已确认项目风格、场景版本、世界光基线 |
| 连续性审阅 | 显式关联镜头之间的状态冲突、方向和衔接建议 | 缺连续性 ID 时猜测关联；借参考图带入前镜动作、对白或角色描述 |

候选至少包括 `field`、`before`、`proposed`、`reason`、`source_refs`、`scope`、`visibility` 和输入版本。多项 Skill 触及同一字段时只给一个待审差异并标注来源冲突。首帧、视频、尾帧分别消费起始状态、时间过程、已确认终点；不把时序全文写进首帧图。当前缺少通用动作/特效、镜内节奏、转场及首帧静态构图的专门字段提案合同，不能借已有完整提示词 Skill 充当这些能力。

## 第二阶段模型合同

| 模型 | 输入 | 输出与检查 |
| --- | --- | --- |
| H3 | 已采纳的分镜版本、实际附件、T2VA/I2VA/FL2VA/Ref2VA 等已选模式及能力 | 根据模式编译对应结构，保留真实参考用途与媒体映射，校验字段、时长、语言和声音/对白；官方 Context-IR 是独立优化器，不等同本地 H3 Skill |
| Seedance | 同一已采纳版本、实际附件、模式及能力 | 编译 Seedance 自然语言正文，压缩冗词但保持动作、镜头与参考语义；不套 H3 标题和媒体语法 |

`seedance-camera` 不直接和 H3 编译器叠加；它的通用方法应先形成第一阶段摄影字段。`seedance-prompt` 不直接用于 H3 全文优化。模型语法和请求能力是服务端硬合同，用户是否选择创作方法不能关闭它们。

## Not yet proven

- 目录声明和指导文本不能证明某 Skill 已输出可保存的字段决定；当前五项单镜复选框仍只加载文本。
- 相同分镜设计分别编译到 H3 与 Seedance 后，语义是否完整保留，需要比对真实预览/提交请求；生成画面是否更稳定，需要同镜头、同参考和受控参数的实际生成评估。
- 目前没有完整的第一阶段候选、版本与逐字段采纳合同；不能把现有最终润色按钮称为两阶段流程。

## 实施验收

1. 先拆分目录元数据：阶段、输入、输出 schema、可写字段、目标模型/模式、互斥关系和版本。旧 ID 保留兼容语义，新模型无关摄影方法使用新 ID；前端按阶段显示，后端独立校验。
2. 用单镜样例验证第一阶段只返回可审阅字段，拒绝未采纳项影响保存与生成；同字段冲突可见。H3/Seedance 切换不重跑该阶段。
3. 用同一已采纳版本生成两种模型预览，检查动作、景别、机位、光线、微表情、转场、参考用途和声音语义一致，格式各遵目标模型。变更分镜、Skill 或附件使旧预览失效。
