# 场景视觉基线作用域 V1

## 决策

导演理解中的视觉词是叙事和美术意图。资产设计负责把这些意图转换成当前场景可执行、可核对的结构化视觉基线。分镜和图片变体只能在该基线上进行显式局部覆盖。

## 三层作用域

### 集级基础设定

保存跨场景稳定的项目方向，例如真人古装武侠、Cinematic Realism、架空古装江湖和北宋市井质感参考。集级设定不直接规定每个场景的颜色或光线。

### 场景级视觉基线

保存到场景资产的确认设计版本，字段包括：

- 时间与天气
- 环境色和主色
- 主光方向与光线质量
- 阴影范围和阴影颜色
- 场景材质
- 基础视角和构图
- 局部光作用对象与效果

导演理解中的“残阳如血”必须在这里被边界化，例如：

> 低角度夕阳只在远处天际和受光边缘呈深暖红色；街面环境保持冷中性灰蓝；阴影不被整体染红。

### 分镜与图片变体覆盖

分镜可指定景别、机位、运镜、构图和镜头局部光。#172 的光影/镜头工具只编辑选中的场景图片变体，默认不修改场景基线，也不自动成为主图。

## 修改规则

- 仅某张图效果不满意：使用 #172 派生编辑。
- 当前场景的基础光影不满意：修改场景资产设计并创建新确认修订。
- 多个场景共享方向不满意：修改集级设定，再逐场景审核投影结果。
- 剧情事实、时间或地点错误：回到导演理解修正，不以图片参数掩盖事实错误。

任何从派生图片应用回场景基线的操作都必须是显式动作，并记录来源变体、来源工具参数、目标场景设计修订和确认时间。不能在调整滑块或生成候选时自动写入场景基线。

## 提示词投影

可见的最终提示词按以下顺序编译：

```text
场景事实与空间结构
→ 场景视觉基线
→ 分镜显式覆盖
→ 图片变体工具参数
→ 用户补充文本
```

导演原始意图、拍摄计划描述和历史候选不会在确认后隐藏追加。若同一字段存在多个来源，界面必须显示来源和优先级，用户确认后才可提交。

## 验收标准

- 场景设计能展示并编辑结构化视觉基线。
- 分镜能看到继承的场景基线和当前镜头覆盖。
- #172 生成的候选不会静默修改场景基线。
- 用户可以显式将候选应用为新的场景基线，并看到 revision 变化。
- “残阳如血”可被限制为局部夕阳效果，不扩散为整幅红色滤镜。
