# 剪辑保存期间的编辑锁定

代码事实：独立剪辑保存/合成期间，原生表单受 disabled fieldset 限制，但时间轴 section 快捷键、拖边 span 和拖放处理仍可提交编辑。随后保存响应替换计划并清空 dirty/历史，导致新增编辑丢失。

沿用当前异步期间禁用编辑的策略，不引入自动保存、草稿合并或新状态架构。

- 共享 AssemblyTracks 接受可选 disabled 状态，默认不锁定，兼容 Studio 现有调用。
- 独立剪辑把 busy 传入工作台；锁定原生编辑控件、自定义快捷键、拖边及视频拖放，计划提交处也检查锁定状态。
- 进入锁定或父计划替换时，取消当前未提交手势。解除锁定后不得补交旧手势。
- 保存成功只接受本次提交的版本；恢复编辑后允许分割、撤销及再次保存。
- 保存失败保持草稿和撤销历史，并恢复正常编辑/重试。

受影响路径：`AssemblyTracks.tsx`、`editing/EditingPage.tsx` 及对应测试。

验收：延迟保存/合成响应时快捷键不能变更计划；成功和失败均可恢复编辑；拖动中进入 busy、解锁后松手不提交旧手势；锁定期间拒绝新拖边与视频拖放。相关 UI、逻辑测试及 TypeScript、生产构建通过。未部署不得报告线上修复。

验证结果：修复前新增的两项保存回归均失败；修复后相关 UI/逻辑 85 项及编辑/渲染合同 5 项通过，TypeScript 检查通过。覆盖延迟保存与合成、失败后草稿/历史保留、再次保存、音频拖边中锁定、视频重排锁定及解除后的新手势。
