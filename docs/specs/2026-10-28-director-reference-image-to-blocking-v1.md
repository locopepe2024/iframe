# 3D 导演台：参考图驱动白模预演 v1

状态：实现中（第一切片）

## 目标

让用户把粮铺等场景参考图和分镜描述交给 3D 导演台，生成可编辑的白模场景、人物/道具占位、机位和 4–6 秒动作参考视频。参考图是二维构图证据；最终空间关系由用户在导演台中校正并保存到资产库。

## 已观察到的参考实现

open-ai-canvas 的 image-to-previs agent 要求模型读取真实图片，建立语义 3D 对象，并保存人物、道具、前后景、姿态、相机和无法确认的部分。其 PrevisScene 支持对象关键帧、运动路径、骨骼轨道、相机运动和 clay/depth/normal 输出。

## 用户流程

1. 上传或选择场景参考图。
2. 输入分镜/调度描述，例如粮铺冲突、群演分时避让和机位时长。
3. 导演台生成“参考图解析 + 白模设计提案”。
4. 用户预览、调整尺度/深度/遮挡/动作时间/接触候选。
5. 应用设计并录制 4–6 秒白模参考视频。
6. 显式保存为资产库中的 3D 布局参考资产。

## v1 输出契约

`referenceImage`（可选）+ 自然语言请求 → 现有 `design-proposal.v1` 操作，并增加可选来源信息：

- `referenceImageId` 或受控媒体 URL；
- `assumptions`：尺度、遮挡、前后景、时间和接触均可标注假设；
- `source`：`reference_image` / `prompt` / `user_adjustment`。

现有操作复用：`street_layout`、`add_box`、`arrange_group`、`place_entity`、`crowd_motion`、`frame_camera`、`camera_motion`、`set_pose`、`seat_actor`。

## 证据和不确定性边界

- 参考图不提供可证明的真实尺度、隐藏区域、绝对深度或真实接触。
- 模型必须把这些内容写入 assumptions，不得声称完成真实三维重建、物理接触或米制深度测量。
- 用户调整后的坐标、时间线和遮挡关系是导演台的可编辑事实。
- 深度图仍需通过现有 depth 工具提交；白模视频属于浏览器预演参考。

## 第一切片

先扩展自然语言设计请求，使后端能够接收一个受控参考图输入并以多模态消息发送给已配置的 LLM；没有参考图时保持现有行为不变。随后增加前端参考图选择和请求绑定，再接入解析结果到现有提案预览/应用链路。

## 成功标准

- 无参考图的现有设计测试全部保持通过。
- 带参考图请求能被严格校验并生成多模态模型消息。
- 参考图未提供或模型不支持图片时返回明确错误，不修改场景。
- 现有静态粮铺布局仍可与既有动画共存。
- 类型检查和 focused tests 通过。

## 暂不包含

真实建筑/角色资产自动建模、从单图推导真实米制深度、物理推搡与接触求解、自动资产库保存、无需用户确认的生成视频提交。
