# 视觉生产体系实施路线图 V1

## 总体目标

把 iFrame 从“提示词驱动的单点生成”升级为可初始化、可优化、可修改、可复用、可检索、可审核的视觉生产体系。所有阶段都遵循同一原则：结构化字段是设定源，提示词是可见投影，媒体和设计参数通过稳定身份与 revision 管理。

## 实施顺序

### 阶段 1：导入基础参考库

来源：open-ai-canvas 的已声明参考库，以及 iFrame 自有、已授权的基础条目。

首批类别：

- 风格
- 题材/类型
- 运镜
- 特效
- 角色库
- 场景母版
- 道具和武器
- 参考集、动作参考和视频参考

要求：

- 导入到 `platform_shared`，所有用户可读。
- 保留许可证、作者、来源 URL、NOTICE、源 revision、SHA-256 和导入时间。
- 未明确许可的内容只能作为 `reference_only`，不可下载或标记为可商用。
- 用户必须显式选择“引用”或“复制到项目/剧集/个人”。
- 共享资产更新生成新 revision，不覆盖既有项目快照。
- 正式平台参考资源必须经过 `source → import_job → candidate → review → promote`，不能直接把全局素材池当作平台资源。
- 平台资源、媒体变体和结构化提示词变体分开保存；运行时绑定具体 resource revision、variant 和 prompt variant。
- 导入前完成身份、结构、来源、引用和质量五道闸门。

验收：共享目录检索、预览、版权显示、复制、媒体续签、跨用户访问和导入幂等测试通过；未审核候选不会进入正式共享搜索结果。

### 阶段 2：角色工作台结构化设计

角色结构化字段：

- 身份与叙事定位
- 脸型、发型、肤色、年龄观感和身体比例
- 服装、配件、武器和可见识别锚点
- 角色状态和版本
- 风格参考、姿态参考和声音/音色引用
- 禁止变化项和验收条件

交互：

```text
用户描述
→ 保存描述
→ 开始结构化
→ 用户修改结构化字段
→ 生成可见编译提示词
→ 用户确认
→ 生成角色变体
→ 保存结构化快照与 revision
```

一致性边界：角色工作台可以继承剧集基础风格，但不能把场景光影、镜头或分镜约束写入角色身份；共享角色库只能显式引用或复制。

验收：修改结构化字段会使旧润色快照失效；生成结果可追溯到角色 revision、参考资产和完整提示词。

### 阶段 3：3D 导演台占位与深度设计

目标：为场景设计提供可复用的空间参考图，而不是直接生成最终场景图。

结构化内容：

- 场景空间边界和地标
- 相机位置、朝向、焦段和画幅
- 角色/道具占位
- 深度层级、遮挡关系和行走区域
- 白模版本与导出图片

边界：白模和深度是场景设计的参考输入；不自动修改场景的风格和光影基线。用户选择导入后，场景生成保存独立的参考来源和 revision。

验收：场景工作台可以选择白模参考图，生成提示词中显示来源、机位、占位和深度信息。

### 阶段 4：分镜交互与结构化设计

分镜结构化字段：

- 内容提示词
- 参考图、首帧、尾帧和视频参考
- 景别、机位、运镜、转场
- 风格、光影、角色、场景、道具引用
- 音色、对白、环境声和音乐层
- I2V、first/last frame、R2V、T2V 模式

连续性规则：

- 用户显式选择是否使用上一镜头尾帧。
- 只有上一镜头存在已选中的成片视频时，才显示“使用上一镜头尾帧”。
- 转场不由镜头编号自动推断；由用户决定当前镜头是否建立新的场景/光影基线。
- 应用场景或共享预设后，当前分镜复制为自己的结构化快照。

验收：批量生成、单帧渲染、预览和重新生成使用当前分镜自己的投影；首尾帧输入和模型模式一致，提交前所有来源可见。

### 阶段 5：3D 导演台运镜视频参考

目标：用白模和结构化相机参数生成低成本运镜视频，作为分镜的动态参考。

保存内容：

- 相机轨迹、机位、焦段、景别和画幅
- 角色/道具占位状态
- 光影和风格基线
- 视频参考稳定媒体身份
- 生成模型、提示词和 revision

边界：运镜视频是预生产参考，不是最终成片；分镜显式引用后复制动态参数快照，不建立实时继承。

### 阶段 6：剪辑与音色

剪辑结构化内容：

- 镜头顺序、时长和转场
- 首尾帧连续性
- 环境声、对白、音色和音乐层
- 音频资源稳定身份、版本和授权
- 混音、音量和导出设置

音色先作为可检索、可复用的角色/项目资产，再接入分镜对白和剪辑时间线。音色引用必须记录来源、版本和当前使用范围。

### 阶段 7：图片编辑器

图片编辑器作为独立设计工具底座，支持：

- 风格、光影、镜头和色彩参数化编辑
- 蒙版局部光和局部效果
- 白模/深度参考
- 变体派生和来源追踪
- 将设计包显式导入角色、场景、道具或分镜

图片编辑器默认不修改资产基线；用户确认导入后生成新的对象 revision。所有提交前参数和完整提示词必须可见。

## 跨阶段共用规则

1. 结构化字段优先于 AI 润色文本。
2. AI 润色是当前字段和已选择参考的快照，不是新的隐藏设定源。
3. 每个对象保存来源资产、来源 revision、应用模式和当前 revision。
4. 共享资产、项目资产、剧集资产和个人资产不能通过名称混用。
5. 未显式选择的参考图、视频、音色或共享参数不得进入模型请求。
6. 所有媒体 URL 通过统一稳定媒体身份实时签发，界面不持久化短期签名 URL。
7. 每阶段先补规范和失败测试，再实施代码；部署前进行跨入口端到端验证。

## 依赖关系

```text
共享参考库
  ↓
角色结构化设计 ─────┐
3D 占位/深度 ────────┼→ 分镜结构化设计 → 运镜视频参考 → 剪辑/音色
场景/道具结构化设计 ─┘                         ↓
                         图片编辑器 ←──────────┘
```

图片编辑器和 3D 导演台是独立工具底座；它们的输出经用户审核后进入共享、项目或剧集资产，不直接改写上游基线。
