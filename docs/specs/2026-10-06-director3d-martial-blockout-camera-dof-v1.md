# 3D 导演台武打预演、占位与景深 V1

## 范围

在浏览器导演台内完成白模武打动作选择、空间占位、机位构图和景深预览。全景生成、全景导入、Blender 渲染及最终视频生成不在本阶段。

## 现状与假设

- 现有白模、米制位置与旋转、场景物体、机位、时间轴、动作结构编译和本地草稿均可复用。
- 动作库是可编辑的示意分段，不宣称专业武术动作捕捉或物理正确性。
- 镜头焦点距离与光圈是创作参数；浏览器虚化用于预演，不能等同最终视频模型或 Blender 的光学结果。

## 交互与边界

1. 用户先在场景树选白模，在空间位置面板设置 X/Y/Z、朝向、地面吸附；也可在舞台拖动。当前站位成为动作片段根位移的起点。
2. 动作面板直接列出本地武打库。用户选择人物、动作、起点、时长与可选对手，查看分段后明确写入时间轴。片段提供关节关键帧、根位移和可选接触候选；触点、平衡和脚底仍需人工复核。
3. 镜头面板允许选择或新建机位，设置位置、旋转、画幅、FOV、主体及 look-at，并增加景深开关、焦点距离和光圈。镜头视图使用所选机位做虚化预览；导演和俯视视图保持清晰，便于占位。
4. 景深设置随机位、本地草稿和机位快照保存。旧草稿缺少景深字段时采用关闭的默认值。所有修改可撤销。

## 验收

- 至少四个可直接选择的武打分段结构；每个结构校验通过，写入可播放的人物姿势与根位置关键帧。
- 站位修改后应用动作，片段首帧从新站位开始；锁定白模不能写入动作。
- 镜头景深参数可编辑、撤销、保存并恢复；镜头视图启用时有虚化效果，关闭后恢复清晰。
- 构建、类型检查、聚焦 UI 与状态测试通过。真实 WebGL 画面和 Blender/视频模型一致性留给部署后验收。

## 本次实现与验证

- 新增直拳组合、侧闪反击、前踢回防，与原鹤形拳共同组成四项可选白模动作库；动作应用仍由用户确认后写入时间轴。
- 沿用现有场景占位、机位构图与动作轨道；机位新增景深开关、焦点距离和预演孔径。镜头视图启用时由 Three BokehPass 处理画面，其他视图使用常规渲染。
- 景深状态支持撤销、本地草稿和不可变机位快照；旧草稿缺少字段时默认关闭。
- `npm run typecheck`、导演台聚焦 UI 测试和 `npm run build` 通过。真实浏览器 WebGL 画面、不同 GPU 的虚化性能与最终视频效果仍需部署后目视验收。
