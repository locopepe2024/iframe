# 平台参考库发布者与创作台候选 V1

日期：2026-10-19。范围：创作台已完成的图片/视频及其结构化提示词，提交至平台参考库候选；管理员审核后激活。首批类别为角色设计。

## Observed

- 平台参考库已有 `candidate → active` 审核，审核者由主机配置的 API key 计算 `owner_profile_id`。目前只有管理员/部署脚本能写入候选 manifest，前端只有审核按钮。
- 创作台结果记录稳定的 `generation.id`、`output.id`、媒体类型、原始提示词、负向提示词、模型和参数；“保存到素材库”只保存私有素材，不是平台发布。
- 平台参考目录目前按 `kind` 与文本搜索，缺少工位、类别、可执行用途。现有角色 Skill 在设置 Skill 目录，角色快捷词条在前端，不能因共同出现在检索里就混为一种资产。

## Direct implication

发布权应允许账户**提交候选**，不等于管理员的审核/激活权。创作台请求必须引用当前账户拥有的 generation/output 稳定身份；服务端解析实际产物并冻结副本，不信任浏览器提交的媒体 URL 或可伪造的模型/参数。

## 权限与状态

1. 主机 `/opt/.iframe` key 对应的审核身份保持不变。审核者可按服务端计算的账户身份 ID 授予/撤销 `platform_candidate_submit`；grant 持久化在服务端输出目录，不保存原始 API key 或浏览器 key。
2. 当前账户可从只读接口取得自己的身份 ID 和发布权限，以便交给管理员授权。审核者也可提交候选，但提交不能绕过审核。
3. 授权者仅能提交、查看自己的候选；审核队列、批准、激活、下架仍是审核者权限。撤权立即阻止新提交，不改写历史来源。
4. V1 候选状态：`candidate → active`；拒绝/退回与激活后修订需要后续独立状态迁移，不能伪称已实现。重复提交同一 output+内容使用稳定去重键。

## 首批角色设计分类

`character/identity`（面容、皮肤、身材、发型、识别标记）、`character/look`（服装与配色）、`character/style`、`character/performance`、`character/reference`。每条记录另有 `kind = image | video | prompt_preset | skill`。类别回答“用于哪个设计步骤”，kind 回答“它是什么”；Skill 仍由设置/Skill 执行，仅在搜索层建立目录索引，不作为媒体发布。

场景和分镜后续沿相同模式扩展 `scene/content`、`scene/lighting`、`scene/camera`、`shot/camera_movement`、`shot/camera_position` 等类别。类别 ID 稳定，中文标签可调整；具体提交候选时只显示当前已支持类别。

## 创作台提交包

用户从已完成 output 的既有“录入资产库”入口打开表单，选择“共享资产库”或“平台参考库 · 提交审核”。平台分支选择类别、图片/视频连同提示词或仅提示词，并将本次实际生成提示词预填到可编辑的“描述”。服务端另存未经改写的 `prompt_used`、模型、参数和 generation/output 身份；用户修改后的描述存为 `structured_prompt.content`，不能伪称是模型原始输入。更细的主体、风格、光影、镜头等字段等类别完善后再分批增加。

提交前用户确认自身拥有内容发布权；服务端校验授权、当前账户所有权、完成状态、输出类型、路径在受管目录且文件存在。候选媒体复制到平台受管区并按 hash 固定，不把私有创作台 URL 当平台身份。封面按需派生 WebP 缓存，视频原件按内容 hash 保存。审核者可以预览，未激活资源不进入普通搜索或生成参考输入。

平台条目保存：`resource_id`、revision、kind、category ID、creator identity、source generation/output、`prompt_used`、结构化块、模型/参数、媒体 hash、来源/权利声明、内容 hash、提交与审核时间。激活后搜索卡可以展示并明确“查看提示词”“引用图片”“引用视频”的可用动作；能否作为生成模型输入仍由具体模型能力和版权状态决定。

## 实施与验收

1. **权限和类别底座：** 角色类别 registry、发布者 grant 管理、服务端授权和搜索过滤。验收：非授权账户提交被拒；发布者不能审核；未知类别被拒；角色 Skill 与图片类别不混同。
2. **候选提交：** 复用创作台“录入资产库”详情弹窗，预填提示词描述并显式选择目标；服务端从稳定产物身份复制并登记候选。验收：伪造/跨账户 output、任意 URL、失败任务和缺失媒体均被拒；原始 prompt 与可编辑描述可分别审查。
3. **审核与使用：** 管理员预览图/视频/完整提示词后批准；激活资源按类别可搜，工作台引用仍经用户确认。验收：候选不进入普通库，下架后历史引用不失效，新绑定被阻止。

## Not yet proven

- 原始提示词能否自动拆成可靠的结构化块；V1 由发布者编辑、审核者核对，不将规则解析结果称为事实。
- 已生成媒体是否可向所有 iFrame 用户再分发或用于模型输入；需发布者声明和审核者确认。
- 视频封面转换、存储成本与大文件上限需要运行时验证。
