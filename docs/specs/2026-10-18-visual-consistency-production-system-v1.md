# 视觉一致性生产系统 V1

## 目标

把剧本、场景资产、图片变体、白模、视频参考和分镜设计放进同一条可追溯的视觉生产链。提示词只是模型输入的可见投影，不能单独承担一致性保证。

## 一、五类规范

### 1. 剧本文字规范

剧本记录故事事实和叙事意图：

- 时间、地点、天气和事件
- 人物、道具和空间关系
- 人群状态、动作和剧情结果
- 导演理解中的风格意图，例如“残阳如血”“市井压迫感”

这些内容是事实和创作意图，不直接等同于图像参数。未经结构化转换，不得把叙事词当成全画面滤镜或镜头硬约束。

### 2. 场景结构化细节规范

场景设计把 Description 转换成当前场景可执行的细节基线：

- 场景内容与空间结构
- 风格（默认继承全局风格）
- 光影与色彩
- 镜头基础视角
- 占位与深度（白模参考）
- 可见人物数量和人物呈现方式
- 禁止的光线方向或画面效果

当前阶段先支持文字结构化光影和镜头；参数化灯光、遮罩局部光、风格参考图和白模深度导入分别按后续能力接入。

### 3. 图片变体细节规范

每个场景图片变体都必须保存生成时的结构化快照：

- 场景结构化设计 revision
- 风格参数
- 光影参数
- 占位／深度参数
- 镜头参数
- 内容提示词
- 完整编译提示词
- 参考图与派生来源

图片变体是可复用的视觉证据。用户可以检索变体、查看来源、复用结构化参数，并在当前分镜中复制为独立快照。

### 4. 视频参考规范

场景或资产可以生成视频参考作为预生产试验，用于验证：

- 光影表现
- 运镜方式
- 机位和景别
- 风格延续
- 人物或环境的动态关系

视频参考不是最终分镜成片。它保存：

- 参考视频稳定媒体身份
- 生成时的图片结构化快照
- 运镜、机位、景别、光影和风格参数
- 内容提示词和完整编译提示词
- 参考图片或白模来源

用户确认合适的参考视频后，分镜可以显式引用它作为参考输入。引用不会自动改变场景基线或其他分镜。

### 5. 分镜连续性规范

分镜使用：

- 已选择的场景图片变体
- 图片变体的结构化视觉快照
- 当前分镜自己的风格、光影、镜头和内容覆盖
- 可选的视频参考及其动态参数
- 首帧、尾帧和镜头连续性状态

当前分镜应用预设后，必须形成自己的快照。后续修改场景资产、图片变体或视频参考，不得静默重写已经确认的分镜。

## 二、结构化数据与提示词的关系

```text
剧本事实与叙事意图
→ 场景结构化细节基线
→ 图片变体结构化快照
→ 白模占位／深度约束
→ 视频参考动态参数
→ 当前分镜局部覆盖
→ 可见编译提示词
```

提示词必须显示来源和顺序。模型返回的润色文本不能在正文后隐藏追加约束，也不能替代结构化数据。

## 三、复用流程

```text
场景 Description
→ 开始结构化
→ 检查风格、光影、镜头、占位／深度
→ 生成场景图片变体
→ 自动保存结构化快照
→ 生成或选择视频参考
→ 在分镜中检索场景变体／视频参考
→ 选择仅参数或参数+参考媒体
→ 当前分镜微调
→ 显示来源与完整提示词
→ 用户确认后生成
```

## 四、所有权和版本规则

| 对象 | 设定源 | 可复用内容 | 修改影响范围 |
|---|---|---|---|
| 剧本 | 文字事实与叙事意图 | 事实、事件、人物关系 | 需要重新审核下游投影 |
| 场景设计 | 场景结构化基线 | 风格、光影、镜头、占位／深度 | 当前场景的新 revision |
| 图片变体 | 生成时结构化快照 | 视觉参数、编译提示词、参考来源 | 当前变体或派生变体 |
| 视频参考 | 动态参数快照 | 运镜、机位、景别、光影、风格 | 当前参考视频 |
| 分镜 | 当前镜头快照 | 局部覆盖、首尾帧、参考输入 | 当前分镜 |

复用是复制快照，不是建立实时继承。每次应用都记录来源对象、来源 revision、应用模式和当前对象 revision。

## 五、验收标准

- 场景资产的每个新图片变体都有结构化视觉快照。
- 图片编辑派生变体能保存更新后的结构化参数和来源变体。
- 白模参考图能保存占位与深度快照。
- 视频参考能保存动态参数，并可被分镜显式检索和引用。
- 分镜可以只复用参数，也可以显式附带参考图片或视频。
- 当前分镜的微调不会反向修改场景资产、原图片变体或视频参考。
- 提交前用户能看到所有来源、revision、结构化参数和完整提示词。
