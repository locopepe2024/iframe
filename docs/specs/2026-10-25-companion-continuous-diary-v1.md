# 持续语音日记测试版

目标：日历直接开始日记，或编辑已有日记；在独立编辑工作域听写追加原话，不调用聊天、意图路由、生成模型。日记区保持编辑状态直到明确停止/取消/保存。

交互边界：浏览器 SpeechRecognition continuous + final resultIndex 去重；浏览器正常结束后 300ms 重开，停顿不保存；错误暂停并保留草稿，不无限重试权限/网络错误。完整独立语句“停止/暂停/停止记录”停听，不保存；“保存/保存日记/停止并保存/停止保存”停听并保存。正文包含这些词不触发。清楚显示麦克风状态、浏览器识别授权；关闭卸载停止监听。未实现实时语音对讲，不增加 UniArt 音频请求。

存储边界：空 source_turn_id 明确表示用户直接写入的日记；非空仍验证属于当前身份的已完成文本结果。保持用户隔离、revision 与 operation_id 幂等；不需要新增表。手动草稿暂存于编辑器，不自动落盘；用户确认保存才写服务器。浏览器刷新会丢未保存草稿。本轮不承诺完整修改历史。

路径：agent/DiaryEditor.tsx、useDiaryDictation.ts、DiaryCard.tsx、DiaryCalendar.tsx；companion_runtime/api.py、diary_store.py；对应组件/后端测试。

验收：正常结束自动继续且不重复；明确停止不保存；保存包含最后一句；错误/卸载关闭麦克风；直接新建无模型来源可保存并按日期读取；越权来源/版本冲突仍拒绝。运行 test:ui 对应测试、pytest tests/test_companion_diary.py、静态构建；更新 demo 前后端，不推送。

验证完成：29 项前端测试、3 项后端测试通过；静态构建成功；类型检查仍只报既有 CharacterWorkbench.tsx:404/1275 两处错误。demo 后端容器已重启、前端已部署，公网 HTML 和 3240.badbdd4976a4db95.js 与本地构建逐字节一致。容器内验证新 DiarySave 接受显式空来源。未进行真实浏览器麦克风验收，正常 onend 重连在不同浏览器的间隙与识别准确度待实测。本轮入口为日历按钮或已有日记编辑按钮，不承诺聊天语音“开始记日记”已经导航接通。
