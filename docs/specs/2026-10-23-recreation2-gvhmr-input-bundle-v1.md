# GVHMR独立对照输入准备

在完整模型缺少硬件/资产时，先完成可复核输入边界，不伪造推理。对原视频308帧用ffprobe读取PTS；按源首PTS起算的30Hz时间格取最近源帧（相等取较早），保存每个模型帧对应源解码序号/PTS及偏移。与官方demo“原帧顺序全部写入30fps”的时间差分开记录，不能把重采样称时序无损。

生成实际30fps无损FFV1诊断视频、逐帧共享有效K、N×6恒等相机旋转占位数组及映射。恒等旋转仅标记静态假设，不是估计结果；未独立验相机前禁止作为验收结论。逐帧raw RGB哈希验证输出解码等于选定源帧，尺寸一致、帧数一致、时间格严格递增。保留目标黄衣身份要求，不自动最长轨迹。

模型不在本轮运行；记录官方公开权重目录只读可达性（不认证不整页归档）和当前环境/必要文件缺失。独立对照入口本轮限于可执行输入准备工具，不称完整推理器。工具docs/agents/tools/recreation2_gvhmr_input_bundle.py；raw/2026-10-23-gvhmr-input-bundle；同名deliverable及rolling summary。诊断视频仅private/tmp，repo保留哈希与映射。主链路不改，完成后原子提交。
