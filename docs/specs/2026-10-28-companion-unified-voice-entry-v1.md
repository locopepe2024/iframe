# 小安统一语音入口

顶部语音聊天和底部连续语音输入共用同一收音实例、会话、Agent 及 OpenTalking 播放队列。移除主页面对独立实时模型面板的引用，不再从此页面请求 realtimeTicket。

SenseVoice（测试站）/浏览器负责识别；小安 Agent 理解、查询与提议操作；OpenTalking /speak 渲染已生成回复，agent_enabled=false，避免第二次对话推理。不改识别协议与 WebRTC 协商。

顶部开始切换聊天模式并沿用识别授权弹窗；本轮请求语音回复，不修改用户保存的文字/语音偏好。停止收音并中断播放，已采集片段按原队列处理，本轮临时语音关闭，后续回复遵循原回复偏好。打断仅停止播放。新建会话取消旧收音及队列。文字发送许可沿用原设置。

语句入队绑定当前编辑焦点，排队时切换页面不改变语义；失败重试保持原请求及焦点。草稿不自动保存。照片资料字段和模型直接修改草稿不在本次范围。

验收：顶部两轮识别只请求现有 chat API，交给 OpenTalking 播放；底部共享收音状态；停止/新会话释放收音；原回复偏好保留；排队语句不受后续编辑器切换影响。执行 UI 测试、typecheck。自然语音与真实 WebRTC 需部署后验收。

验证结果：相关 61 项 UI 测试及 typecheck 通过。新增集成测试先复现顶部仍进入旧面板，再验证两轮语音共用现有会话、OpenTalking 播放、停止收音、取消说明后不启用播报及新会话清理。旧面板/hook 源码暂留，主聊天页已不引用，待真实语音验收后再移除。仅本地实现，未部署/推送。

## 播报生命周期收口

继续核对异步边界：每次 Agent 请求绑定播报代次；停止收音、新会话或切换仅文字使旧代次失效。迟到的回复仍进入消息流，不再因后来重新启用语音而播报。停止播报不会取消聊天或丢弃原话。播放队列取消后，各播放任务须在异步媒体准备结束时再次检查取消状态，避免旧任务发送 /speak 或清理新任务的 active 状态。用可控延迟的回归测试验证，不以真实音频设备效果代替代码证据。
