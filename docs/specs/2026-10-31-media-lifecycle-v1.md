# 素材生命周期与不可变编辑版本 v1

状态：只读盘点、素材收藏及收藏版本链、查询界面已实现；跨模块引用迁移和自动清理未启用。

## 已核实的代码事实

- PlaygroundOutput.saved_to_library 是历史归档标记。save_to_library 复制文件到 owner assets 目录，不创建语义资产库条目。
- ImageEditStore.save 创建新 editor_output 和独立文件，保存 source_reference、source_sha256；不覆盖原图。
- Playground history、image-edits SQLite、media registry 与编辑项目分别持久化。当前不存在覆盖这些存储的统一清理与引用合同。
- 生成记录 created_at 是请求创建时间，并非各批输出的完成时间，不能直接当成新的七天保留计时起点。

## 目标合同

| 操作 | 生命周期 | 写入语义 |
| --- | --- | --- |
| 模型生成成功 | temporary，完成后七天 | 新 media_id / version_id |
| 临时输入上传完成 | temporary，上传后七天 | 新不可变文件 |
| 临时图编辑保存 | temporary，副本保存成功后七天 | 新版本及来源关系，不覆盖父版本 |
| 保存到资产库 | permanent，用户删除前保留 | 原子创建资产条目与版本绑定；重复操作幂等 |
| 正式资产编辑 | permanent | 保存新版本，保留旧版；当前选择独立更新 |
| 素材加入已保存项目 | protected | 钉住准确版本；项目当前计划和保留的历史版本均保护 |

元数据必须包含 owner_profile_id、media_id、version_id、source_kind、created_at、available_at、retention_state、expires_at、asset_id（可空）、parent_version_id（可空）、sha256。路径和名称不能作为素材身份。

### 展示与命名

- 资产库设置“正式资产”和“临时素材”标签页。临时页统一显示模型结果、临时上传、编辑副本。
- 临时页按来源、类型、名称、日期筛选，支持预览、继续编辑、保存到资产库、删除及分页。
- 临时素材显示七天期限、明确的到期时间；被项目引用时显示“项目引用中，已保护”。
- 临时图编辑按钮为“保存临时副本”，另提供“保存到资产库”；正式资产编辑为“保存新版本”。不得把普通保存反馈成已永久收藏。
- 读取、预览、编辑父素材不延长父素材期限；新副本有独立期限。

### 引用与删除

- 项目必须先持久化精确版本引用，再报告保存成功。清理与新增引用必须通过同一锁/事务边界，避免检查后误删。
- 软删除项目和回收期内历史版本仍保护源素材。永久删除项目并完成保留期后才可释放引用。
- 正式资产删除进入回收状态；被当前项目、历史版本、运行中任务引用时禁止物理删除。
- 编辑副本记录来源，但只要求副本自身可独立解码，来源谱系不无限保护全部临时祖先。
- 清理保留可识别的已过期元数据，媒体读取返回 410，UI 提供过期说明；不能把过期伪装成网络加载失败。
- 物理文件只能在全部业务引用释放后删除，包括共享 storage_key、缩图与派生文件；保留审计记录。

### 历史迁移

- 未发现正式资产条目不能推断没有引用。旧归档标记、注册表记录和文件存在均不能单独证明可清理。
- 存量默认 legacy_review，未知时间/归属/引用一律阻止删除；不得上线后立即批量删除超过七天的历史文件。
- 先只读盘点，再把档案和引用对齐。切换日给可迁移的存量临时素材至少七天宽限期，并展示用户通知。
- 只有 complete 的引用扫描与明确到期时间才可产生清理候选；执行前重新核验，任务幂等，失败可重试。

## 分片与验收

1. 只读盘点 API：owner 隔离；合并历史输出、编辑副本和上传注册记录；显示候选期限但 cleanup_enabled=false，delete_eligible=false；无创建/改写数据库或文件副作用。
2. 持久化生命周期与版本元数据、正式资产提升 API：同一文件重复提升不重复创建；编辑新版本不改历史项目引用；补失败回滚验证。
3. 临时素材页与保存文案：端到端验证直接编辑未收藏结果、再编辑副本、收藏及项目固定引用。
4. 引用盘点与历史迁移：dry run 输出保护原因、候选数量与容量；核对各业务存储，损坏存储时停止清理。
5. 清理任务：覆盖过期边界、共享文件、运行中任务、软删项目、恢复版本与并发新增引用；通过 GreenA 隔离验收后再启用。

第一片受影响路径：src/apps/playground/media_inventory.py、api.py、tests/test_playground_media_inventory.py。验证：定向 pytest、compileall。其余分片未交付前不能声称七天自动清理或临时素材 UI 已生效。
