# 陪伴聊天首页卡片引导 V1

状态：Demo 交互验证

## 目标

验证老人首次进入首页后，能否看懂可以做什么，并能用一次点击开始一段有明确目的的聊天。首页仍沿用 iframe Companion 的会话、消息和确认架构；本片只增加移动端友好的引导层，不引入新的 Agent 协议。

## 用户界面

首页以“聊天”为主，顶部提供三个大卡片：

- **聊聊今天**：把一条自然问题填入聊天输入框，老人可以修改后发送。
- **讲讲一张照片**：进入生活相册，保留现有相册入口。
- **整理今天的回忆**：把请求填入聊天输入框，请 Agent 生成日记草稿；保存仍必须经过用户确认。

卡片是快捷入口，不替代自由输入。卡片内容固定在前端，后续可由 Agent 根据上下文生成，但动作类型必须由程序白名单约束。

## 交互约束

- 所有卡片使用原生按钮，触控区域至少 48px，支持键盘和屏幕阅读器。
- 点击文字类卡片只填充输入框，不自动发送、不产生外部模型请求。
- 点击相册卡片只导航到相册，不修改资料。
- 聊天输入使用浏览器听写；首次录入前说明浏览器语音服务的外发范围，结果先成为草稿，不自动发送。真实麦克风效果另行验证。
- 首次引导不使用强制弹窗，允许老人跳过并直接输入。

## 验证标准

- 375px 宽度下卡片纵向排列，没有横向滚动。
- 点击三张卡片均产生可理解的下一步反馈。
- 文字卡片填充后发送按钮仍遵守外发勾选和会话规则。
- 现有聊天、记忆确认、历史分页测试继续通过。

## 卡片底座与对话卡片流

功能导航统一使用卡片：聊天、相册、回忆、我的。底部导航保留为稳定返回路径，但不承载复杂功能入口。

聊天中的内容也使用卡片流呈现：

- 文本卡片：老人和陪伴助手的发言；
- 图片卡片：大图、来源和“讲讲这张照片”动作；
- 视频卡片：封面、播放按钮和“说说这段视频”动作；
- 回忆卡片：整理出的故事或日记草稿；
- 提问卡片：一次只提出一个容易回答的问题；
- 确认卡片：保存、修改、删除或提醒前的明确确认；
- 状态卡片：正在听、正在整理、已完成、需要重新确认。

卡片动作必须是白名单动作。展示媒体不等于修改资产；保存故事、修改日期、删除记忆和设置提醒都要经过明确确认。图片和视频可以在相册网格中浏览，但从聊天进入时使用对话卡片流作为主要阅读和操作方式。

## 照片卡片内讲述切片

直接在聊天的照片卡片内复用 PhotoStory：读取该照片已保存讲述，编辑/听写草稿，预览，按钮确认保存，读取修改历史。每张卡片由服务端 photo_id 绑定；不同卡片的编辑框使用独立 DOM ID，避免标签指向其他照片。首次点击展开，不提供丢弃草稿的自动折叠。

使用现有 story/saveStory 接口，不增加模型请求，不把照片、讲述或卡片自动写入聊天上下文或长期记忆。保存失败继续复用确认请求；本片不解决跨刷新草稿恢复。保存讲述不修改日期、人物或原图。

相册 list 当前按分页返回，不证明按拍摄/上传时间倒序；入口使用“看看相册照片”，不标“最近”。本片最多展示返回页前六张；完整浏览仍由生活相册提供。视频仍只有展示组件，尚无真实视频库接入。

成功标准：在卡片内读取/修改讲述，仅点击确认才写入；多张卡片的标签与照片 ID 独立；失败重试、取消和历史沿用既有行为。相关 UI 测试、类型检查和浏览器小屏布局验证分别记录，不用模拟 API 测试冒充线上数据验证。

验证记录（2026-10-23）：照片卡片、AgentChat、PhotoStory 和 PhotoAlbum 共 29 项 UI 测试通过；typecheck 和带 /companion-demo 前缀的静态构建通过。CLI 无头 Chrome 使用临时合成照片 HTTP 服务验证：卡片展开、草稿、预览与取消不写入、确认写入正确 photo_id；320px、375px/200% 字体和横屏未出现横向溢出，确认按钮可触达。未保存截图；这不证明线上服务、真实语音或 Qwen 往返已验证。本片尚未部署。

## 聊天流主屏修订

根据用户实测反馈，移除主屏技术说明、用户原话列表标题及手动刷新按钮；新建会话与记忆管理收进次级入口。消息区显示用户气泡与助手回复，照片按主动选择加入；底部为文字输入及发送。外发范围放在授权详情内，未授权不能发送。新增只读 conversation 分页接口，按当前 owner、actor 配对用户原话和已保存的文字回复；刷新可逐轮恢复文字对话。工具读取仍按当前有效记忆重读，不把已删除记忆复制进历史；不据 UI 布局宣称完整历史或流式模型传输已实现。视频数据尚未接通。


## 简洁版输入框与生成引导（2026-10-23）

范围：AgentChat 与其独立组件；不导入专业创作台的 store 或业务组件，不修改生产生成接口。

- 共享 globals.css 的 iframe 主题 token；提高文本对比度、字号和触控尺寸，图标使用 lucide。
- 输入区沿用“输入正文 → 底部类型/动作栏”。类型弹出菜单提供聊天、图片、视频。草稿和生成设置按类型分别保存于当前页面；切换不发请求，刷新不承诺恢复本地生成草稿。
- 图片/视频表示生成；“从相册添加”表示浏览现有照片，只有在参考图片卡片中明确选择才绑定生成配置。未接入真实视频资产库。
- 媒体描述提交后显示卡片：参考图片 → 比例/时长 → 完整设置预览。支持返回修改、用推荐设置及取消。参考图用现有鉴权图片组件，不自动外发。推荐比例/时长是交互 Demo 候选，尚未验证模型 capability，接入生成时必须由真实能力覆盖。
- 图片和视频的本地设置不调用文字聊天、生成或报价接口。确认设置只产生本页配置回执；明确显示尚未报价、尚未生成；生成按钮不可用。不得假造价格、零元承诺、生成进度或成品。
- 模型与分辨率收进更多设置；当前无 capability/quote，先说明待接入，不列假模型选项。
- 大麦克风保留“对话中”，录音时显示“停止”，结束识别时显示“正在整理语音”；发送使用 ArrowUp 图标和可访问名称。录音/处理时禁用发送与类型切换，避免结果进入错误类型；不自动发送听写。
- 文字外发授权只约束聊天，不阻止本地生成设置预演。待确认记忆、未决请求与重试继续锁定输入，避免错误写入。

验收：三种草稿独立；菜单键盘/触摸可用；推荐/返回不丢参考图片；确认不产生付费请求；真实照片可选且绑定 ID；原聊天记忆确认/重试回归；模拟语音只填草稿；typecheck、UI 测试、静态构建和浏览器窄屏检查。真实模型生成、费用报价和真实麦克风均不能用本地测试代替。
