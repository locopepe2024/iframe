# 角色工作台参考库与输入流程 V1

日期：2026-10-18。状态：待实施的交互方案；以前置的 `2026-10-18-character-asset-pack-structured-contract-v1.md` 为准。

## Observed

- 左侧九项结构化字段和两段视觉值同时展示。编辑视觉值会清空同组结构化字段；用户容易把候选摘要、自己的要求和最终设定视为三次必填输入。
- 角色设计参考图保存在 `character_design.reference_assets`，用于设计模型。右侧图片参考图是独立状态，只有右侧显式选中项进入生图请求。图片提交审核展示实际引用。
- 当前线上平台参考库没有已发布资源；工作台模板是文字任务模板，没有可选的脸型、发型或服装参考图。

## Proposed interaction after the asset-pack contract

项目角色工作台负责 `项目 → 角色 → 资产包`，编辑通用身份、锚点及四层规范资产；剧集角色工作台负责确认本集使用哪个包版本和媒体变体，仅在本集造型或状态发生变化时生成本集具体资产。两个入口显示不同的 owner、确认状态与生成结果，不能把包内候选缩图直接列为本集成品。分镜默认选择本集已确认的角色使用绑定；绑定直接采用项目包内图时要显式标注其项目来源，不重复生成或复制媒体。

1. 默认只展示角色档案、题材、年龄、两段可选视觉要求和一次参考图选择。九项结构化字段收在“逐项编辑”中；AI 生成草稿后自动展开，供用户逐项核对。空字段不是必填。
2. AI 草稿仍经“查看模型输入 → 用户修改并确认 → 生成候选 → 保存或确认设计”。确认设计后，用户显式应用到可见图片提示词；图片生成继续经过提交审核。这些确认点不能合并成静默模型调用或资产写入。
3. 左侧已选设计参考图可一键复制到当前全身出图参考图，并明确提示会替换该面板当前选择。复制是用户动作，不随设计确认自动发生；三视图和肖像继续各自选择其单张母版。
4. 平台库未来提供按字段检索的**文本设计片段**和**有许可的视觉参考**两个资源类型。文本片段可由用户选择、编辑后写入具体结构化字段；图片参考必须先导入当前项目可解析的资产变体，再由用户决定用于设计分析或图片生成。任务模板只决定流程，不自动提供参考图或隐含约束。
5. 每次采用平台资源记录 `resource_id + revision + 来源字段`；确认设计保存当前字段快照。后续平台资源更新不得静默改变已确认角色设计。

## 角色资产包参考对照

参考：[献丑AI《角色设计功能详解》](https://xianchou.com/blog/character-design-asset-pack)。页面描述“基准图 → 派生资产”的产品流程；其跨镜头一致性效果是该产品的主张，不能仅凭文章认定为已验证结果。

| 文章中的资产层级 | iFrame 当前对应 | 本方案采用方式 |
| --- | --- | --- |
| 正面全身锚点、转面三视图 | 全身／三视图变体 | 先确认可见身份与造型，再选定全身基准变体；三视图使用用户选定的单张母版 |
| 表情、姿态、口型 | 尚未形成统一角色资产包 | 后续按用途建立可选派生任务，不加入本次视觉字段表单 |
| 配色卡、服装拆解、道具独立图 | 配色和服装文字字段、独立道具资产 | 可作为未来可检索的结构化产物；图像派生需保存母版变体和提示词 revision |
| 定妆照、破损状态图 | 当前图片变体可承载，但缺少状态语义 | 后续增加状态与场景绑定，不能反向覆盖身份锚点 |

文章中的“自动包含锚点”适合表达资产依赖；iFrame 的模型请求仍须在审核窗口明确列出实际参考图和稳定变体 ID，用户确认后才能提交。平台库可以提供任务模板和素材候选，但不能因为选中模板就暗中附加参考图。

### 目标资产包依赖图

```text
正面全身锚点图（用户选定的角色母版变体）
├── 转面三视图
├── 三视图 + 脸部特写
├── 身高比例对照图
├── 表情表
├── 姿态 / 体态库
├── 口型辅音表
├── 配色规范卡
├── 服装拆解图
├── 妆造定妆照
└── 破损 / 状态变化图
道具独立图 → 独立道具资产；可记录与角色的持有关系
```

当前 `reference_sheet`／`full_body` 可作为母版候选，`three_view` 和 `headshot` 是现有派生类型。其余节点只是目标类型，尚无对应的稳定角色资产包类型或批量生成入口。新增节点应逐个定义输出形态、适用模型、画幅、母版引用、状态字段、变体选择和质量审核；不能把十项都塞入一个提示词。

目标数据关系为 `character_id + design_revision + anchor_variant_id → derivative_task → output_variant_id`。母版换选时，旧派生图保留原始来源，标记“基于旧母版”供用户决定重做；不自动删除或偷偷改写。单个派生任务提交前展示所选母版及其他参考，用户可以撤销或更换，并确认实际请求。

## Success criteria

- 初始页面不要求用户在九项字段和两段摘要中重复填写；AI 返回后仍能逐项校对。
- 设计参考图不自动进入图片请求；用户点击沿用后，图片审核展示相同的稳定变体身份，用户可以移除或替换。
- 平台库为空时不显示虚假的可选图样；新资源只有经过发布、授权和项目导入后才能作为参考图提交。
- 原有草稿、revision、`@` 引用及三视图单母版规则继续有效。
