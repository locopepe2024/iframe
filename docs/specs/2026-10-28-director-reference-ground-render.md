# 镜头参考画面：共面地面修复

## 证据与目标

线上粮铺群演视频出现道路黑色条带。隐藏默认地面后条带消失；代码确认默认平面和道路顶面同处 ground.heightM。修复默认平面与道路共面显示的冲突，并在设计预览及视频录制中隐藏编辑网格。

## 实现边界

仅给默认地面材质增加正向 polygonOffset，让共面道路优先显示；不偏移真实几何，不改变深度快照。满不透明度地面使用不透明材质。编辑模式保留网格，参考预览/录制隐藏网格。人物动作恢复属于复刻模块，本切片不改动作。

## 验证

前端类型检查、深度快照测试、参考录制及设计面板测试。合并部署后须在默认地面开启、道路顶面与之共面的粮铺场景重录，确认黑条消失、编辑网格仍可见、参考录制不含网格。当前仅本地代码验证，不能宣称线上画面已修复。
