# 剧本正文的场景与表演细节

## 目标与范围

将用户指定的 01、03、04、06、07 五个素材维度整理为普通剧情、非露骨描写规则，用于单集扩写、续写和选中片段改写。交付仍是中文剧本正文，包含场景标题、可见动作、角色和对白；细节用于推进事件、呈现人物与衔接状态，不输出绘图关键词列表。

这是正文写作能力，不是 Markdown 剧本文件上传，也不替代现有总纲解读、分集确认或集纲扩写方法。总纲解读继续只提取原稿事实及独立建议，不将素材库的建议当成已确认设定。

## 来源分析

参考仓库：[nsfw-prompt-templates-asian](https://github.com/wangsuizhi012-bot/nsfw-prompt-templates-asian/tree/4a37fa6593a17a77ad8c951492d560e829a0108a)。核对版本：`4a37fa6593a17a77ad8c951492d560e829a0108a`。

| 来源编号 | 可借鉴的组织方式 | 本地整理 | 不适用的组合与限制 |

| 01 | 场景分类、感官锚点 | 地点、时间、可见可听细节与人物行动 | 地点不自动决定人物关系；不能从职业推断冲突 |

上游是图像描述词库，包含不属于本次范围的内容，不能按整份文件或按标题自动导入。此变更仅参考上述分类维度，独立撰写中文规则和普通剧情例子，不复制上游模板或示例。上游 README 声明 MIT；核对的根目录未提供独立 LICENSE 文件，因此不将该声明当作已归档的许可证文本。

## 实现

- 五份规则位于 `src/apps/comic_gen/presets/script-writing/`，由正文写作模块的固定文件列表加载。运行时无需访问 GitHub，也无需用户安装 Agent 技能。
- 这些资源随已有 `src` 数据目录进入后端镜像与桌面打包；不加入通用创作 Agent、导演、图像或视频生成提示词。
- 单集扩写保留现有 Emma 集纲扩写技能；续写仅承接已有结尾；局部改写仅替换选区。三者共享普通剧情细节规则，但既有任务范围优先。
- 规则要求按剧情选用，不强制每场使用五个维度；不得新增关键道具、身份、关系、秘密、视角或未来事件以满足细节。
- 资源缺失或为空时明确报错，不静默跳过。文档和来源说明不送入模型。
- 沿用原有字数、模型选择、账户隔离、异步预览和人工采纳流程，不自动保存或替换正文。

## 验收

1. 在扩写、续写、局部改写的真实 LLM 调用入口，用替身模型检查五个维度均进入 system 消息；原稿与用户要求进入 user 消息。
2. 续写不获得仅供集纲扩写的技能；局部改写继续带只读前后文及选区边界，不发送整集或总纲。
3. 固定资源均非空，缺失或空文件产生明确异常；不扫描加载相邻任意 MD。
4. 已有写作、局部修改、总纲解读和制作交接测试通过。测试只验证接线与任务契约，不将提示词存在当成模型生成质量已获证明。
