# 照片描述核对

本版完成描述核对，不做声纹。AI 原始观察保持不变；用户确认的描述作为独立记录保存，不能确认 OCR、不确定项、日期、人物身份或亲属关系。描述版本从 0 开始，确认保存携带 expected_revision 和 operation_id；事务内校验 owner、原分析哈希、修订并追加历史。相同操作重试幂等，旧版本冲突返回 409。读取历史分页；本切片不提供恢复按钮，保留完整历史供后续恢复设计。

交互：不自动弹窗。描述正确/改一下进入核对卡，展示完整将保存文字，允许朗读，再点确认保存。以后再说仅关闭当前核对区，保留未确认状态。主动允许浏览器听写后点击说话确认，结果仅进入可编辑框；明确“描述正确/同意”等生成核对卡，其他话语默认不覆盖描述，用户可显式选择用这段话替换描述。最终必须点击确认保存；录音与识别原话不自动保存。照片切换停止语音；保存只作用当前照片和核对时版本。失败保持草稿，409 提示重新打开，不用陈旧状态自动重试。文字操作始终可用。

验证：真实 SQLite/API 保存/重读/历史、幂等/并发版本/owner/日期隔离；UI 保存前零写入、修改/取消/跳过/语音、历史；类型检查、静态构建及独立部署浏览器回归。既有照片不自动确认，不以测试替换其内容。

实施结果：102 项照片后端测试、20 项界面测试、类型检查、独立目录静态构建通过。公开测试入口的独立合成照片浏览器验证通过：预览/取消/跳过、模拟语音“同意”后仍需点击、修改保存、历史与刷新重读。使用 DOM 点击与模拟 SpeechRecognition，不代表真实麦克风或真机体验。

用户另授权 Desktop/资料库 的图片用于测试。选取服装图、密集图文海报、人物多视角图三张，生成不含 EXIF 的测试副本，原文件不改。隔离评测 owner 使用已授权个人渠道调用真实 qwen3.8-flash，结果通过字段校验；描述确认/重读/历史各成功，日期不变。该内部样本评测由运维脚本自动确认以验证存储，不能标作用户亲自认可的事实，也没有修改用户原上传照片的确认状态。

运行发现：海报首次 OCR 返回42项，超过30项契约，被拒绝保存；将数量/长度限制明确写入提示并升级 photo-observation-v2 后，三张均通过。没有放宽服务端校验。视觉人工对照仅支持主体/排版大体相符，未逐字校验OCR；人物多视角结果断言为同一人、问题可能预设用户参与拍摄，仍是内容质量待改善项，不属于身份确认。不得把这三张样本通过当作整体准确率或视频能力证明。
