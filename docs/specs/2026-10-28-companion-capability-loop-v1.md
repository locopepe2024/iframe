# Companion 既有能力闭环验收

## 本轮范围与完成标准
文字、持续语音与点击共用服务端工作流和持久化状态；小安负责交流与结果反馈，业务 Agent 负责工具调用。完成后部署 Demo，不推送分支。

1. 相册：范围询问 → 搜索/瀑布流 → 上传/选择 → 结构化分析 → 用户补充、修改 → 保存、刷新查询 → 删除确认 → 相册隐藏。成功或失败均返回真实回执。
2. 信息分层：模型观察包含画面人物、场景、光影、可见时间线索及不确定性；姓名、实际年龄、性别、地点/经纬度、拍摄日期由用户明确填写/确认。模型不得编造身份、亲属或精确日期。
3. 操作入口：点击和 Agent 提案调用同一领域方法；写入有版本检查与重试去重；删除先确认。聊天能知道当前照片和未完成操作。
4. 日记：当天会话事实/已确认照片信息 → 草稿 → 持续编辑 → 明确保存 → 月历读取。编辑过程中不路由到相册。无来源事实不得补写。
5. 情绪：SenseVoice 情绪标记作为暂时的表达建议，不作为心理事实；小安回复简短、不重复追问。
6. 记忆：显式保存、可查询和删除；用户纠错优先；照片观察不得自动变成个人记忆。
7. 知识：读取既有 owner-scoped 知识检索；文本与语音引用同一来源，不把检索失败说成没有资料。
