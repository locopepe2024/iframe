# 场景资产提取 Skill V1

## 状态

后端合同 V1 已实施，前端展示和历史数据迁移仍待后续切片。本 Skill 用于从剧本、场景描述和参考图中提取可复用场景基线，不负责当前分镜的人物调度或动作编排。

## 目标

将“长街中段粮铺”提取为可复用场景资产，并把当前镜头的劫掠事件、人物选择、站位、前中后景和镜头构图留在分镜层。

## 强制分层

### 场景资产层

- 场景身份与主题
- 固定空间结构
- 固定物体与地标
- 材质、环境和空间纵深
- 可确认的默认时间基线
- 可确认的世界光影基线
- 可复用构图倾向
- 场景级禁止项

### 分镜层

- 当前镜头事件和动作
- 当前镜头角色、群众和道具选择
- 人物具体站位、朝向和前中后景
- 当前镜头景别、机位、运镜和构图覆盖
- 当前镜头局部光影覆盖
- 当前镜头时长、节奏和声音

## 禁止写入场景资产

- “正在劫掠”“准备劈砍”等当前事件
- 具体角色 ID、附件引用或人物数量
- 近景/中景/远景中的临时人物分配
- 当前镜头的左三分、右三分或中心站位
- 当前动作、受力链、对白和临时道具状态

## 输出要求

场景提取结果必须返回结构化字段和可见摘要。当前后端合同为 `asset_baseline`、`shot_only_content`、`visual_notes` 和 `uncertainties`；`visual_notes` 只能作为兼容摘要，不能重新成为第二套权威值。无法确认的时间、光影或构图应标记为建议或未确认，不得从当前分镜事件推断为场景事实。

## 验收样例

输入包含“长街中段粮铺、门前劫掠、百姓退让、黄昏、人物近中远景分配”时：

- 场景资产只保留粮铺、长街、固定物件、黄昏基线和参考光影。
- 劫掠、百姓退让、人物引用和前中后景分配必须留在分镜结果。
- 生成场景资产的复用提示词不能要求固定出现这些临时人物。
