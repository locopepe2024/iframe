# 人物视频到可编辑白模：动作迁移流程 v2

## Objective and scope

目标：源视频到Blender的姿态、连续动作、机位和构图映射，保留人物、动作、场景、相机独立可编辑。优先动作对齐、正常比例、接触与遮挡、接近原片光影。不还原不必要的外貌。此版本只梳理人物；动物不在范围内。

本规范调整后续测试顺序，不代表生产管线已实现或全片通过。执行环境为media Blender 4.5.9。

## Observed

- code fact：已有incam/global人体输出、焦距敏感性测试和Blender诊断相机；此前不是完全没有考虑相机。缺口是背景相机验证、坐标语义与动作接触验收没有形成统一前置契约。
- runtime observation：原迁移候选使用incam动作+固定诊断相机；原camera-up为−Z，不能直接按+Z-up/min-Z验收地面。
- runtime observation：49–65源帧静态背景跟踪支持固定画面候选；37–45存在明显背景运动。只说明图像证据，未完成三维机位/焦距/尺度标定。
- user-provided sequence：右脚全掌支撑→左腿前踢→左脚落地→向前跑两步→切镜。此顺序作为参考，具体事件帧与切点待核准。
- user-provided framing：开头半身、约2–3帧后中景全身，随后焦距稳定。尚未独立判定这段变化是剪切、运镜、变焦还是裁剪。不能把它与37帧后的背景运动自动认作同一事件。

## Pipeline and contracts

| 阶段 | 核心任务 | 必须输出与验证 |
|---|---|---|
| 0 输入与时间轴 | 原视频解码、帧率/裁剪/尺寸、内容哈希 | 原始帧号与PTS；重采样映射；重复帧不当新证据 |
| 1 分镜与构图变化 | 区分切镜、镜内推拉摇移、变焦、裁剪；跟踪人物身份 | shot_id、边界候选与置信度；景别是观测，不直接指定焦距 |
| 2 背景相机分支 | 排除人物/动态区域；比较固定、二维运动、可辨识的三维运动 | 每镜头camera contract；参数来源/估计/未知；留出背景误差 |
| 3 人物资产分支 | 清晰全身帧估计源骨架比例与身份；审计目标rig | 源/目标骨长、rest轴、单位、蒙皮、脚底代理；比例不随侧身/景别跳变 |
| 4 人体时序恢复 | 同镜头下融合可见关节、轮廓、光流与上下文；联合估计姿态、根轨迹和动作阶段 | 连续旋转、根运动、可见性、不确定性；前踢/落地/跑步事件及左右脚接触状态 |
| 5 世界空间对齐 | 使用已验证或明确假设的相机、向上/地面和尺度约定 | camera/world变换、det=+1、重投影回放；不可观测量明确标记 |
| 6 动作迁移 | 按父空间/rest轴映射完整旋转，以固定目标骨长FK回放 | 局部旋转、目标根运动；比例、左右与端点回放检查 |
| 7 分阶段接触修正 | 仅对有效接触施加小幅IK；区分全掌/前掌/脚尖、滚动、换脚和腾空 | 不盲锁单一鞋底点；校正幅度、滑动/穿地、关节投影与动作保真 |
| 8 场景渲染与验收 | 同一三维场景输出白模与深度，调整光影、遮挡和机位 | .blend/动作/相机/场景manifest、版本哈希、源帧映射、分项验收 |

阶段2与3/4可并行提供初始估计；相机与人体可以受限交替优化。表中顺序是契约和验收依赖，不要求先唯一求出相机再识别人。关键是不让人体误差无约束地变成相机运动。

## Camera and shot rules

1. 每个镜头独立验证相机模型；同一镜头可包含短暂构图变化及稳定段，不等同于每段都切镜。
2. 固定焦距不等于固定机位；固定背景支持固定相机基准，但不能测出真实焦距/深度。
3. 固定机位用常量外参；运动镜头用连续外参曲线；只有证据支持才开放变焦曲线。未知裁剪/防抖与有效内参必须记录。
4. 无足够视差不能强行输出可信三维平移；保留固定/纯旋转/其他低复杂度候选及不可辨识状态。
5. 不跨切镜平滑相机、二维轨迹或推断世界根位置。同一角色资产可复用；连续场景的跨镜头世界对齐需要额外证据，不自动重置或强连。

## Action and contact rules

- 动作名称用于阶段组织，不能代替骨骼恢复。人体姿态、事件与接触可以联合推断，再互相检查。
- 侧身是身体朝向变化，不是骨长变化。可见关节用于观测，遮挡关节由骨架/时序推断并降低置信度；不强制用户标出不可见真值。
- 支撑侧标签不代表整脚固定；全掌、前掌、脚尖、抬跟、滚动、枢转、换脚、腾空独立表达。
- 仅在证据支持固定接触点的短区间内锁点；转换段使用软约束/接触权重过渡，权重与阶段来源可追溯。
- 第49/52/53帧的既有校正量不是实测姿态误差，也不是相邻帧位移；它取决于相机/坐标/接触点/锁点假设。
- 现有稀疏人工接触标签不向整区间直接传播；47帧及落地/跑步边界等冲突保留待核对，不覆盖原记录。

## Depth policy

当前只有单目漫画视频，估计深度是可选辅助，不能作为独立实测真值；衣物表面深度不等于骨骼深度。先建立RGB、时序、相机与接触基准，再在相同样本/留出帧上比较RGB-only与RGB+estimated-depth；仅当动作/接触改善且时序稳定才引入。不得把3D渲染深度反当源观测自证正确。

## Direct implication

应先修复镜头边界与相机契约、动作阶段和接触语义，再优化目标rig局部IK。清晰全身帧提供稳定结构；半身/侧身/模糊段利用同镜头上下文，不每帧重建一套身份比例。

## Not yet proven

未证明相机边界是所有误差的主因；姿态模型、卡通比例、遮挡、蒙皮代理与父空间映射仍有独立误差。未证明自动动作阶段/接触识别已实现，用户描述及人工整理只能作为参考基准。未完成全片或真实焦距验收。

## Next executable slices and success criteria

1. **全片镜头/构图审计**：核准开头半身→全身变化与前踢→落地→两步跑→切镜，输出候选边界和原帧联系表，不预填未验证帧号。已有37–65结果保留，不扩展声称全片固定。
2. **同镜头人物时间线**：复用稀疏关节、脚点和用户动作序列；独立标识动作阶段、支撑侧、鞋底接触类型、身体朝向与置信度；精确边界未验证则unknown。人工只处理冲突/关键事件。
3. **固定相机基准**：在背景支持的49–65段，比较固定相机与人体推断相机；相同骨架、相同代理、相同已标点/留出帧，分别报告背景残差、人体投影、根轨迹与接触指标。
4. **迁移与IK**：通过父空间/FK回放再做接触；位移预算沿用暂定5cm工程诊断门槛，超过回查恢复/接触定义，不直接抬高门槛。不跨切镜或换脚强锁。
5. **短片验收**：动作阶段/节奏、正常比例、脚掌动作、遮挡和光影分别检验；输出可编辑Blender和同场景深度。通过后扩大，不用少量帧低误差声称全片完成。
