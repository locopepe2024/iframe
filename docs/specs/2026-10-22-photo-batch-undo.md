# V1：撤销本批时间整理

当前每张照片仅属于一个批次，未实现同一照片跨批引用。因此本切片只在该现有归属模型内撤销自动日期结果，不能宣称已完成共享照片的按来源关系撤销。

提供只读预览，列出本批每张照片当前日期、revision、动作和恢复目标。仅撤销当前日期历史末尾连续的organize记录：恢复至这段自动整理之前的精确快照（不重新解析EXIF），追加undo新版本并同步年份投影。最新记录为correct/restore/undo/register时保留，绝不沿历史追溯删除用户明确操作。原图、EXIF、描述、讲述和历史均保留。已完成任务结果是历史执行回执，不篡改为“未执行”。

预览返回基于owner/batch/当前授权版本/全部照片revision及恢复目标计算的摘要token。POST /photos/batches/{id}/undo-time携带token与operation_id；BEGIN IMMEDIATE内重算并校验，陈旧预览409，全批无部分写入。确认同时撤回时间授权、取消尚未完成的旧任务，再追加每张日期undo记录与批次操作回执。即使已经撤权也可明确确认清理；不要求为撤销重新授权分析。重复同operation/token重试返回原回执，不再次撤权/追加日期。不同token复用operation拒绝。新上传、日期更改、授权变化会使预览失效。

GET /photos/batches/{id}/undo-time-preview只读；GET /photos/batches/{id}/undo-time/history可分页重读操作回执。回执记录actor、时间、被撤销日期修订与新增undo版本、保留数量、结果授权版本。新授权后可以再次整理，新撤销使用新预览与操作ID。undo仍为未整理/前序状态，不静默重建相册年份。

UI在批次任务面板提供“预览撤销本批时间整理”，展示撤销/保留数量、逐张前后日期和原图保留说明。只有点击“确认撤销本批时间整理”写入；可取消，失败保留预览/操作ID；409提示刷新预览。显示历史撤销记录，不把取消任务当撤销。文字操作，沿用现有大字/48px目标，无新语音确认。服务端事务、并发/幂等/历史/用户更正/跨批隔离、UI、构建及测试站合成数据验证后本地提交，不推送合并。
