# 结构化资产设计与独立工具边界 V1

## 目标

统一角色、场景、道具和分镜的结构化描述，同时把图片编辑和导演台定义为独立设计工具底座。工具可以产出可复用设计结果，再由用户显式导入共享资产或剧集资产。

系统不应把所有设计能力堆进 Assets 面板，也不能只保存一段提示词。

## 一、四类对象的 V1 结构

### 角色 Character

- 身份：名称、角色身份、年龄观感、性格
- 身体：体型、比例、身高关系、姿态特征
- 面部：脸型、眉眼、肤色、识别锚点
- 发型与妆容
- 服装：轮廓、材质、颜色、层次、配件
- 动作限制：适合的动作幅度、头发和服装响应
- 参考图与变体来源
- 确认 revision

### 场景 Scene

- 场景内容：空间、建筑、材质、时间、天气、人群和事件状态
- 风格：默认继承全局风格，可局部覆盖
- 光影：主色、环境色、主光方向、阴影范围、禁止方向
- 镜头：基础视角、机位、空间方向
- 占位与深度：白模参考图、空间锚点、前中远景关系
- 人物约束：可见人脸上限、次要人物呈现方式
- 图片变体结构化快照
- 视频参考动态快照
- 确认 revision

### 道具 Prop

- 身份与用途
- 形状、尺寸关系、材质和颜色
- 使用状态：持握、摆放、损坏、开合、沾染
- 结构锚点：柄、刃、扣件、纹理或其他识别部位
- 与角色和场景的空间关系
- 参考图与变体来源
- 确认 revision

### 分镜 Shot

- 当前场景、角色、道具引用
- 当前分镜内容与动作
- 风格和光影局部覆盖
- 景别、机位、运镜、构图、转场
- 首帧、尾帧和视频生成模式
- 图片结构化参考快照
- 视频参考动态参数
- 当前分镜独立 revision

## 二、设计工具边界

### 图片编辑工具

图片编辑是独立的视觉变体工具，负责：

- 光影实验
- 镜头和视角实验
- 蒙板局部处理
- 风格和材质实验
- 从已有图片派生新变体

它默认只生成派生变体，不直接修改角色、场景或道具基线。用户可以显式执行“应用为资产设计 revision”，并记录来源变体和工具参数。

### 导演台

导演台是独立的空间和动态设计工具，负责：

- 白模空间和深度
- 角色站位和占位
- 机位、镜头路径和运镜
- 动作预演和节奏
- 光影与风格试生产
- 视频参考生成

导演台输出的是可审计的设计包，包括结构化参数、参考媒体和编译提示词。它不直接改写剧集资产；用户确认后才可导入共享资产。

## 三、从工具到共享资产的导入

```text
独立设计工具
→ 设计包（参数、媒体、来源、revision）
→ 用户审核
→ 共享资产库
→ 剧集资产引用或复制
→ 分镜显式选择
```

导入共享资产时必须保留：

- 原设计工具和设计包 ID
- 来源媒体 ID／变体 ID
- 结构化参数快照
- 编译提示词
- 创建工具版本
- 用户确认时间

剧集资产可以引用共享资产，也可以复制为剧集专属 revision。复制后不建立实时同步。

## 四、提示词与结构化数据

提示词是结构化数据的可见编译结果：

```text
结构化字段
→ 来源合并与优先级
→ 可见编译提示词
→ 用户确认
→ 模型请求
```

模型润色结果不能成为隐藏的第二套事实源。任何模型补充内容都必须回写到可见正文或结构化字段，并显示来源。

## 五、资产管理要求

资产管理需要支持：

- 按角色、场景、道具和分镜类型检索
- 按结构化参数检索，例如侧面光、冷灰环境色、远景人群
- 按来源工具、revision、变体和设计包检索
- 查看派生关系和参考媒体
- 复制参数到当前对象
- 仅复用参数或参数加参考媒体
- 形成当前对象独立快照

## 六、V1 实施边界

V1 先完成：

1. 角色、场景、道具、分镜的结构化字段和 revision。
2. 场景每个图片变体保存结构化视觉快照。
3. 图片编辑和导演台输出设计包，不静默改资产基线。
4. 共享资产导入保留来源和结构化参数。
5. 分镜从资产变体或视频参考显式复用。

后续接入：

- 风格参考图
- 参数化光影
- 蒙板局部光
- 白模深度导入
- 视频参考检索和动态参数复用

## 验收标准

- 角色、场景、道具、分镜都能保存结构化描述和 revision。
- 设计工具可以独立运行并产出设计包。
- 设计包经过人工确认后才能进入共享资产。
- 共享资产和剧集资产能追溯来源并复用结构化参数。
- 任意复用都会生成当前对象自己的快照，不产生隐藏实时继承。
