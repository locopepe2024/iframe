# Companion 相册范围确认与选择

## 目标
“梳理相册”先问范围；不把全库照片铺进聊天。明确打开相册时直接打开分批加载的瀑布流。选中一张后，创建持久化整理任务，聊天只显示这一张。

## 边界
- 泛化整理指令由服务端返回 album_guide；无条件的模型相册列表/整理提案同样返回范围卡，不读取照片。
- 范围支持日期（年/月/日）、已保存的人物/故事备注、最近加入、主动打开全部相册。最近加入不等同于拍摄日期。
- 人物搜索只匹配用户保存的描述和讲述，不猜测亲属关系或从未确认的 AI 分析查找。
- 原生搜索 API 每页最多 20；选择仅进入整理任务，不分析、不修改、不计费。相册整理继续由既有工作流负责。
- 选择 ID 必须服务端验证归属；相册弹窗支持关闭及 Escape。

## 验收
1. 泛化指令即使被模型提案为单张或全库读取，也只返回范围卡；不创建整理任务。
2. 时间/备注筛选与分页不串条件，未选择时不改照片。
3. 选择一张后结果为 review_photo，刷新与后续语音仍能获得任务上下文。
4. 前后端行为测试、类型检查、Demo 构建及 API 实测通过；不推送。

companion_runtime/{intent,api,chat_store,tools,photo_tasks}.py；photos/{workflow,api}.py；Companion AgentChat/AlbumPicker 与新范围卡；photoApi/companionApi。
