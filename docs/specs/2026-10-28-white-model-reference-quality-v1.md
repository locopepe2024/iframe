# 白模参考动画质量与制作范围 v1

状态：用户确认的质量要求。适用于视频复刻生成的可编辑白模参考动画，包括当前Addams片段。本文规定目标，不代表当前产物已经达标。

## 核心原则

无需还原人物外貌。优先保证动作、比例、光影匹配原片，并保持运动轨迹稳定。分层制作，按交互和遮挡关系分配产能，尽量简化非关键元素。

## 分层制作范围

| 层级 | 纳入条件 | 制作要求 |
|---|---|---|
| 主角，最高优先级 | 目标主体 | 动作对齐、人物比例正常且对齐参考、光影贴合、轨迹稳定；不精细还原外貌 |
| 前景人物 | 从主角身前穿过、遮挡主角，或与主角交互 | 制作必要的人体代理与动作，保证比例、动作和遮挡关系；不精细还原外貌 |
| 背景路人 | 远景或后方，无交互 | 作为背景简化，不单独解算动作 |
| 配饰与衣物装饰 | 无手部触碰或调整 | 可不制作 |
| 配饰与道具 | 穿戴、调整或其他手部交互 | 制作交互必需的简化代理，保证接触位置、时序和运动关系 |
| 背景物体与动物 | 无交互 | 简化处理，保留基础氛围，无需精细建模解算 |
| 交互物体与动物 | 参与角色交互 | 按具体交互保留必需形体、位置与运动；避免超出交互需要的细节制作 |

## 验收硬性指标

1. 动作对齐：关键姿势、动作发生时间、运动轨迹、支撑/腾空/落地及交互时序与原片对齐；运动连续稳定，检查滑脚、穿透和突跳。不能以低平均关节误差掩盖关键动作错误。
2. 比例对齐：人物具有正常、连贯的人体结构；身高、肢段关系、画面占比以及必要人物/道具的相对尺度对齐参考。无需复刻外貌；卡通体型轮廓不能直接当成骨关节位置。正常比例与夸张参考发生冲突时，记录取舍，不用错误骨长追逐轮廓标注。
3. 光影接近原片：匹配主要光向、明暗层次、软硬程度和接触阴影，保持镜头内时序一致。白模材质允许简化；纹理和外貌不作为精细复刻目标。

逐镜头提供源片与白模同步对照，并抽查关键动作、遮挡和接触帧。三项分别记录通过/未通过/不可评及证据；没有证据不得报告已通过。不擅自添加尚未确认的数值阈值。

## 当前Addams片段的执行边界

- 复用已确认的关节、人物身份和接触事件，继续生成连续三维候选；模糊/缺测帧降低权重，不作为阻止整段候选生成的门槛。
- 第二人物按镜头内的实际交互、前后遮挡关系决定是否制作；不因被模型检出就自动纳入，也不因主角出画就删除必要前景交互人物。
- 保留支撑、越障、落地及身体接触所需的地面/物体代理；非交互背景采用简化几何或背景层，兼顾主角光影与遮挡验收。
- 相机、根节点与骨架分别可编辑；深度从同一三维场景输出。用于背景的图像层不自动具有可信几何深度，输出时说明几何覆盖范围。
- 不再以外貌精细还原或每帧自动检测成功作为完成条件；优先按动作、比例、光影三项验收决定补标和修正。
