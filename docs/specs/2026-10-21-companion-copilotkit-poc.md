# Companion CopilotKit 交互 PoC

日期：2026-10-21
状态：用户同意后实施的隔离试验；不替代照片 V1、现有 `/companion` 或正式授权后端。

## 目标与成功标准

新增 `/companion/copilot-trial`，保留原型默认入口。锁定 SDK 与 AG-UI 兼容版本，真实使用 CopilotKit V2 的 Provider、Agent、前端工具/人工确认和渲染机制。采用浏览器内确定性 AG-UI Agent，不运行模型、不提供 HTTP Runtime、无用户线程数据服务、不接 Intelligence、不发送照片。

仅两个交互：

1. 发送“字调大一点” → Agent 工具请求 → 大字确认卡 → 明确确认才调整；拒绝/取消不调整；可恢复普通字号。
2. 对单个合成照片批次请求按时间整理 → 卡片说明处理位置、批次、时间 scope → 明确授权才运行本机模拟任务 → 按真实样例日期/未知显示结果；拒绝不启动；撤回后不新增结果，可重置演示。

语音复用浏览器可选听写，先展示转写供核对，再由用户发送。模糊指令、带否定的表达不直接判作确认。一次只有一个当前问题，确认绑定工具调用 ID / 当前批次，不复用旧卡；重复点击只执行一次。字号设置在此页真实生效；照片整理只是合成记录模拟，页面明确展示区别。

## 隔离与状态

- 所有照片为代码内合成元数据/自有 SVG 示意，无真实上传或人脸模型。使用内存状态，刷新重置，不能宣称后端持久化、真实 owner 隔离或恢复已完成。
- 不挂载原有账号/配置初始化，不读取现有对话，不改模型目录。不把 API key 放浏览器。SDK 调试/Inspector/云配置明确关闭。
- UI 工具参数须解析校验；不接受任意字号/CSS、批次 ID、scope、处理位置或客户端自报权限。模拟服务对当前问题/批次/版本核验，重复请求幂等；未来替换为认证服务端 API，不以 UI respond 充当业务授权。
- SDK 与 AG-UI 持有对话/工具事件，本机模拟服务持有样例授权与任务事实；页面根据实际结果展示，不从模型文本取完成数。失败/取消有清楚恢复入口。
- 离页中止录音/朗读、Agent 运行和样例任务；不使用默认语音自动发送，不增加云数据采集。

## 受影响路径与验证

- `frontend/package.json` / lockfile：确切版本；不升级 React/Next 或无关依赖。
- `frontend/src/app/companion/copilot-trial/` 与 `frontend/src/components/companion/copilot-trial/`：独立入口、确定性 Agent、样例状态机、适老卡片和样式。
- `ApplicationBoundary`：只增加明确的试验路径隔离，常规业务路径仍保留原 Providers。
- 定向测试使用真实 SDK，不 mock 成普通 React 状态；验证工具调用 → 卡片 → 返回结果往返、拒绝、恢复、重复回传、错误/撤回、退出清理及无业务/模型网络请求。
- `frontend/scripts/companion-browser-smoke.mjs`：启动临时静态服务器和隔离的无头 Chrome profile，模拟 390px 视口并验证确认/取消/字号恢复/样例授权/撤回；清理服务、浏览器和 profile。只允许本地静态请求和 `fonts.googleapis.com` / `fonts.gstatic.com`，其他网络请求在浏览器侧拦截并使测试失败。
- `npm run typecheck`、定向 `npm run test:ui -- ...` / `npm run test -- --run ...`、`npm run build`。以构建记录 React 18 / 静态导出兼容证据，不将组件测试当手机实测。
- 浏览器验收命令：先 `npm run build`，再 `npm run test:companion:browser`；后者要求可用的 Chrome/Chromium，可通过 `CHROME_BIN` 指定。
- 记录 SDK/AG-UI 版本、试验初始包大小与 `/companion` 对照、已验证与未验证；不推送或部署。

后续才验证真实模型 tools 协议、认证/owner-thread 隔离、后端授权与任务恢复、真实设备和老人任务。该 PoC 的用户本机授权/任务结果不能用于正式照片处理。

## 浏览器烟测（2026-10-22）

- `npm run test:companion:browser` 直接加载静态导出页面，不依赖运行中的后端或长驻开发服务。脚本用临时端口、临时 Chrome profile 和 CDP 请求拦截，并在退出时清理资源。
- 页面全局样式会请求 Google Fonts；浏览器检查明确允许 `fonts.googleapis.com` 和 `fonts.gstatic.com`，所有其他非本地网络请求均被拦截并判失败。字体服务不可用时页面仍可使用系统字体，此烟测只保证请求范围，不把字体下载成功当作交互前置条件。
- 覆盖 390px 横向溢出、字号确认前不生效、取消、调整后恢复、拒绝照片授权不启动处理、同意后模拟处理、撤回并清除结果。此浏览器烟测不替代真实设备、语音服务或老人可用性测试。

## 当前确认卡朗读切片（2026-10-22）

目标：在既有两个工具确认交互中提供“读给我听 / 停止朗读”，长辈可以先听清当前问题，再通过按钮或核对后的听写回答。复用 `useCompanionVoice`，不增加自动播放、模型、上传或反馈采集。

- 只朗读当前有效确认卡的可见说明：字号变化及作用范围，或照片批次、时间范围、处理位置、刷新和撤回规则；不朗读其他聊天。使用慢速中文朗读，不把播放完成当作同意。
- 听写和朗读共享一个语音控制器；朗读前停止听写，开始听写停止朗读。确认、取消、发送、撤回及离页停止语音，旧的识别回调不能操作后续问题。
- 语音不支持时显示文字提示，按钮确认仍可用；不自动申请麦克风。听写“确认”仅进入输入框，发送后绑定当前可见工具问题。
- 路径：`TrialContent.tsx`、对应 UI 测试、浏览器烟测。测试覆盖朗读内容、停止/拒绝/离页、听写不自动确认及无语音支持；构建后执行浏览器触控烟测。合成 API 验证不能证明真机声音、识别准确率或长辈任务完成率。

实施验证：类型检查、46 项定向测试（包含原 `/companion` 回归）、生产静态构建通过。新增 3 项真实 SDK 组件测试，用合成浏览器语音对象验证当前卡片朗读、手动停止、取消/离页清理、听写与朗读互斥、转写核对后发送及不支持朗读的文字入口。浏览器烟测改用 CDP 触控事件并检查点击中心实际命中及最小 44px 目标，覆盖 390×844 完整流程；大字模式附加 320×568、375×812（根字号 200%）、844×390 布局检查，无横向溢出或内部裁切。此字号模拟不等于手机系统 Dynamic Type 实测。只采用设计 Skill 的可访问性、触控、焦点和减少动效建议，未采用其不适用的应用商店着陆页与拉丁字体推荐。未推送、部署或合并。

## 对话调整朗读速度切片（2026-10-22）

目标：复用既有工具确认链，增加 `confirm_speech_speed` 工具，仅接受 `slow / normal`。固定句式“说慢一点 / 恢复普通语速”提出确认，按钮或核对后发送的“确认 / 取消”只回答当前问题。默认沿用前一切片慢速（rate=0.7）；普通语速 rate=0.9，均为浏览器参数而非实际每分钟字数保证。

- 确认之前不改变当前速度；取消保持原值，恢复同样须确认。新设置用于下一次手动朗读，不自动播放。
- 只保存在当前试验页内存，刷新重置；页面展示当前速度及调整范围，不触发照片授权、反馈采集或存储。确认卡的朗读使用调整前的当前速度。
- 受影响路径：试验 `scenario.ts`、`agent.ts`、`TrialContent.tsx`、状态/协议/UI 测试与浏览器烟测；不改共享语音 hook 或原 `/companion`。
- 成功标准：取消/重复/过期问题、带否定的句式不误执行；真实 SDK 完成工具与结果往返；播放参数随确认变化并可恢复；照片授权独立；类型检查、定向测试、静态构建及 Chrome 触控烟测通过。真机语音效果仍待验证。

实施验证：类型检查、51 项定向测试和生产静态构建通过（49 项陪伴回归通过后补充并通过 2 项语速 AG-UI 协议测试）。新增测试覆盖确认前不改变速度、取消、旧问题重复回传不操作当前问题、否定请求不触发工具、普通/慢速参数、照片授权保持独立，以及工具结果后不重复发起。Chrome 触控烟测通过语速取消/确认/恢复，并继续通过 320px 小屏、375px 根字号 200% 和横屏大字布局检查；无未知网络请求。浏览器烟测验证设置状态，实际 rate 参数由合成语音对象测试验证，不宣称真机语音质量已通过。保持本地开发，未推送或合并。
