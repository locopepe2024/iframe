# Prompt 输入框词典与 Skill 入口 V3

用户确认：`/` 打开词典和 Skill 检索面板；`@` 打开资产检索面板。本文覆盖此前 V1/V2 将 Prompt 案例放到 `@` 的约定。

## 范围与边界

首个切片是角色工作台图片 Prompt 输入框。`/关键词` 直接搜索本地角色词条、已审核平台词条、固定版本组合、Prompt 案例和当前角色台实际可执行 Skill。按内容类型及面部／身体／造型／风格分类浏览，平台有表演词条时显示表演分类。词条、组合和案例先显示实际文字及来源，再替换光标处的 `/关键词`；不改其他草稿、已选图片和角色身份字段。路由词在自由 Prompt 中使用中文显示文字，不插内部路由 ID。

Skill 只暴露已接入的角色视觉设计双 Skill 流程，确认后进入已有输入审核，不直接调用模型。不把安装目录等同于当前可执行能力。

`@` 移除 Prompt 案例文本，只检索已有稳定资产／变体引用。平台图片当前缺少项目导入绑定能力，不伪装成可引用结果。侧栏结构化字段词典继续保留，属于显式字段编辑工具。

## 成功条件

### 分类浏览增量

用户确认 `/` 首屏先展示面部、身体、造型、风格分类，进入二级分类后才列出词条；不再默认展开全部词条。Skill 独立页签。直接输入 `/圆脸` 仍可命中原词条，同时给出“面部 › 脸型”的浏览入口，比较其他实际存在的脸型。分类导航不插入文字、不改 Prompt。组合与案例通过内容类型切换；只展示已发布内容，不按词语相似度伪造关联。

本地词条按稳定 ID／字段来源显式映射分类；平台词条按目录类别映射，宽泛面容类保留“面部综合”，不猜测更细的分类。眼周细节复用已有明确定义的词条，体态按已知姿态词 ID 与体型区分。没有数据的类别显示空状态，不补造词条。浏览候选和搜索属于两个模式：从搜索结果选择所属分类后浏览该分类全部候选，原 `/关键词` 在确认应用前不变。Esc 依次返回预览、上级分类、关闭；键盘可进入分类。

受影响路径：角色 Prompt 词典面板、新分类映射和组件测试。成功条件：`/` 首屏不显示任何具体词条；面部 → 脸型可比较圆脸／方脸；从 `/圆脸` 返回脸型浏览不改 Prompt；Skill 需切换页签；保留原纯文本插入和资产引用行为。

- 输入 `/发型` 直接命中相关词条，`/` 可浏览所有支持类型；支持方向键、Enter、Esc、中文输入法及点击按钮。
- 预览不修改 Prompt；确认后仅替换触发片段，保留前后文和已有资产 token；插入文本按纯文本处理。
- 组合失效成员不能应用，候选／下架资源不可选。平台读取失败仍可使用本地词条；可重试。
- `@` 不出现词条、Prompt 或 Skill；选中资产仍保持稳定引用。
- 删除独立的“@ 平台 Prompt”按钮，提供输入框旁 `/ 词典和 Skill` 按钮作为可发现入口。

## 受影响路径与验证

`ReferencePromptEditor.tsx` 增加可选 slash 回调；新角色词典面板；`CharacterWorkbench.tsx` 接入并移除旧 @ Prompt 分支；相关组件测试。运行角色台、共享编辑器、词典面板 UI 测试、前端 typecheck 和生产构建。线上用固定版本发布脚本 prepare/deploy 并核对版本与静态标记。真实平台素材应用仍需首批已审核案例。
