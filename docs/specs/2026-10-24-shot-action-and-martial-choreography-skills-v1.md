# 分镜动作物理与专业武术编排 Skill 规格 v1

## 目标

将动作镜头拆成两层：普通动作物理和专业武术编排。两层都先产出模型无关的动作合同，再由 H3、Seedance 等模型 Skill 转换为目标模型提示词。

## 分层

### `shot-action-physics`

适用于踢、打、推、撞、抓、受击、踉跄、跌倒、追逐和物体碰撞。必须明确：

- 施力者与受力者；
- 接触点；
- 受力方向；
- 身体朝向与画面位置；
- 支撑变化；
- 可见反应顺序；
- 终止状态；
- 道具是否发生碰撞。

动作顺序默认是：起始状态 → 接触/施力 → 受力反应 → 支撑变化 → 位移/失衡 → 终止状态。

未提供方向时标记不确定，不猜测；未明确指定时，道具保持原位，不自动增加翻桌、碎裂、飞散或特效。

### `shot-martial-choreography`

仅在用户明确指定武术体系、武指、招式、兵器套路、连续攻防、动作分解海报或专业动作参考时启用。它调用 `shot-action-physics`，增加：

- 武术体系与动作词汇；
- 攻防顺序；
- 重心、发力部位与动作弧线；
- 准备、爆发、停顿、反击和收势；
- 道具和环境互动的明确授权；
- 每个动作对应的景别和摄影意图。

专业动作分解海报是编排资产，不自动成为 I2V 首帧。

## 参考素材职责

图片和视频必须先进入本轮参考列表，再声明用途：

- 图片可承担 identity、costume、weapon、pose、keyframe、scene_layout、lighting；
- 视频可承担 action_choreography、camera_movement、rhythm、impact_timing、weapon_trajectory；
- 未声明的属性不得跨职责转移；
- 动作视频不自动带入人物身份、服装、场景或对白；
- 动作分解海报不自动带入网格、编号、箭头和说明文字。

## 产物边界

动作 Skill 只输出结构化动作合同、参考职责和不确定项；不输出 H3 六字段、Seedance 专用标签或完整模型提示词。模型专属 Skill 在后续阶段负责格式转换。

## 验收

至少覆盖：

1. 右侧踢击中央人物：受击者先后退再倒地，保持面向攻击者；
2. “门侧”不导致人物自动转身；
3. 未声明道具碰撞时，桌子和器具保持不动；
4. 明确撞到竹筐时，只产生一次竹筐倒地和谷粒散落；
5. 未提供受力方向时返回不确定项，不自行补方向；
6. 专业武术参考视频只转移动作和节奏时，不带入视频人物与场景。
