# 剧本编辑器管线入口

只保留两种行为，按当前分集的独立剧本文档 ID 查找本人名下的制作项目：

1. 项目不存在：先保存当前剧本，创建跳过分析的制作项目，复制正文和编辑文档，进入 `#/project/{id}`。
2. 项目存在：保存当前创作稿，直接进入对应制作项目，不覆盖制作阶段正文、实体或镜头。

关联使用已有的 `source_script_document_id`，切换集数、刷新后继续有效。已有历史关联也可直接使用。关联项目删除后允许重新创建。

服务端在持久化锁内查找并创建，重复点击、并发请求和失败重试复用同一项目。普通新建项目流程不变。当前服务使用进程内项目存储及锁，与原有持久化架构一致。

移除管线面板中未实现的进度和历史占位；显示创建或打开按钮及处理中状态。不增加操作向导，不自动触发实体提取、导演分析或分镜。实体和镜头为空不阻止创建；无正文时不可新建，但仍可打开已有项目。

验证：重复和并发创建返回同一项目；不同文档和所有者隔离；制作修改不被覆盖；保存或查询失败停留编辑器；切换集数不复用上一集关联。
