## 方案与不可混淆的状态

模型在独立 Demo 服务端 CPU 处理，不发送照片到外部分析服务；离线部署权重，运行时不自动下载，不使用 Qwen 猜身份。检测基于 EXIF 转正、最长边1024的既有无 EXIF WebP 缩略图；人脸框使用该缩略图归一化坐标，后续 UI 必须使用同一转正图。小脸/模糊/侧脸可漏检，空结果不是照片里没有人。

部署决策（用户已确认）：不建立单独 OpenCV HTTP 服务。新建人物整理 worker 容器，在构建时安装 `requirements-photos-faces.txt`，挂载校验过的模型及许可证目录只读，共用独立 Demo 照片数据库。前端、现有 API 和时间 worker 不安装 OpenCV；API通过持久化任务表交接工作。人物 worker 运行时禁网、不开监听端口，授权/任务/结果查询仍走照片API。本切片只在 `/private/tmp` 虚拟环境验证，并未部署该容器或启用照片页人物分析。

检测每张最多20个人脸，批次最多20张照片、400个人脸。超限拒绝该项，不截断伪装完整成功。保存特征的模型版本和权重哈希；不允许不同模型空间混算。相似度仅是候选依据，不称作身份概率。

候选算法：确定性、所有跨组人脸两两相似度都达阈值才合并（complete linkage）；同照片的两张脸默认不能自动并为同人，镜面/拼图例外留用户纠错。防止A像B、B像C就把A/C串起来。输出包含单人脸候选，全部标记待确认；使用暂定保守阈值0.5，仅供试验，需真实样本校准。人物称呼可空，模型不生成姓名或亲属关系。

## 全链路后续切片

1. **本切片**：独立可选模型依赖、固定权重校验、受限输入、人脸检测/特征提取与纯候选算法；测试异常/边界/链式误并/合照限制，并用用户已授权资料库样本做离线冒烟。仅开发工具直接调用，不对照片页面自动启用，不声明后台人物功能已完成。
2. **持久化授权与任务**：按owner/batch保存独立人物授权及问题版本、处理位置/模型指纹；时间授权不授予人物权限。UI先展示问题，最终按钮确认。任务快照照片ID/hash、授权版本，特征提取前检查，结果提交事务再次检查；模型推理不占SQLite写锁。独立人物worker无网络、有限租约/续约、worker token保证过期或撤权worker不能提交；失败逐项可重试、读接口不执行分析。按模型部署资源限制并发，不能复用时间worker的短事务执行假设。
3. **人物确认与浏览**：具体face_id关联photo_id/bbox，候选与已确认人物/成员关系分别保存；逐组展示代表照片和人脸定位，确认/以后再说、称呼可跳过。合照能关联多个已确认人物。更正、移出、拆分、合并必须带revision和operation_id并记录历史；模型重跑不得覆盖人工成员关系，先向用户展示冲突。
4. **停止与清理/撤销**：撤权立即增加版本并取消任务，事务门禁挡住在途提交；可选清理本授权范围的特征/自动候选，明确回执，历史仅留ID/操作摘要而非特征副本。已确认人物关系单独保留/撤销，不能默删其他批次关系。批次撤销按来源关系移除本批新增结果、保留原图和此前确认；共享照片来源关系仍需扩展现有单照片/单批次模型。
5. **UI和Agent**：文字确认卡先完成，再接语音草稿；Agent工具对接时同时纳入已约定个人记忆save/search/list/delete。未接入前不声称数字人能完成人物整理。

## 2026-10-23：人物任务后端切片

新增独立人物授权问题与按钮回答、授权版本事件；时间授权绝不隐式授权人物。问题15分钟有效，绑定批次/授权版本/固定模型指纹和服务端本地处理披露。先仅在内部store和显式CLI接通，不挂公开API或UI，不部署未完成的人物入口。

任务持久化本批真实上传照片的缩略图哈希、模型指纹及授权版本；最多20张。原子领取一个照片项，随机token、120秒租约，最多3次领取；续约需原token且尚未过期。过期项可重领，新token废止旧token；达到次数上限则明确失败。推理在写锁外，推理前及提交事务再验owner/批次/当前授权/租约/token/指纹/图像哈希。进程死亡依靠租约恢复，读请求不执行任务。单次推理应在租约内；显式续约方法可供后续较长执行使用，本轮串行worker不自动续约，超时结果会被拒绝并最终失败，不能宣称无限重试。

只保存逐人脸检测和特征，不保存姓名或已确认人物；检测结束有脸标记needs_review，表示尚需后续候选分组及人工确认，不能显示为整理完成。失败项通过新任务单独重试，幂等操作ID不重复写。撤权事务取消pending/running，清空token，选清理时删除本批人脸派生数据并将已检测项标cleared；保留原图/日期/讲述/授权摘要。SQLite逻辑删除不等于备份或物理存储安全擦除。跨批、跨owner不能清理。已确认人物关系尚不存在，本轮不宣称解决其撤销边界。

验收：真实SQLite覆盖授权独立性/过期问题/版本冲突、无锁推理、并发抢占、租约过期/重领/重启恢复、撤权竞态、重授权不复活旧token、幂等、失败重试、清理隔离及事务回滚。影响src/apps/photos/{people_schema,people_tasks,people_worker,date_store}.py及专用测试；基础初始化显式建新表，HTTP不自动迁移。

## 2026-10-23：授权卡、进度和首个人物确认闭环

新增仅独立照片Demo使用的owner受限API。默认不开人物入口；部署人物worker并显式配置 `IFRAME_PHOTOS_PEOPLE_ENABLED=1` 后才允许新授权/任务，状态返回真实配置，不把可选依赖存在当worker在线。界面明确后台是否等待，不假造在线状态。撤权、读取、清理与已确认相册查询不依赖开关，停服务仍可停止任务。授权请求只接受button；模型不能设置owner/actor。

worker在一项检测任务终止且仍有有效人物授权时，对成功检测项生成同任务内候选；失败项保留可重试。分组在写锁外，提交时比较检测全量摘要与当前授权版本，重复调用不新增分组。候选表与确认成员分开；GET只读，不执行聚类。全部候选保持待确认，包括单成员。不跨owner/任务/模型自动并人。重跑产生新候选，不自动修改旧确认；跨任务重复人物由用户后续合并，当前不宣称跨批自动人物识别。

确认表保存独立person_id、可空称呼，以及具体脸对应photo_id/框和来源任务/候选。单个合照可出现在多个人物相册。只有confirmed成员进入人物相册，候选/以后再说不进入。候选操作带expected_revision、consent_version、operation_id；确认先本地预览再按钮提交；拆分操作把多成员建议拆为单脸候选、原组记split，供逐个重新核对。以后再说可回到列表再次确认。追加操作摘要回执不保存特征。确认/拆分/跳过均防旧版本覆盖且幂等，不从模型推断称呼或关系。

撤权默认保留已确认人物成员；选择清理则删除本批人脸特征及未确认自动候选，同时阻止在途分组提交，保留已确认成员/原图/日期/讲述。明确告诉用户清理不会删除已确认人物相册。confirmed成员中的定位框作为用户确认关系的一部分保留；不保留对应embedding。全套成员移出/分组任意合并/部分拆分/已确认结果撤销还需后续切片，本轮仅候选拆为单脸，不以此宣称人物纠错全部完成。

页面入口先放上传批次下的独立折叠区，授权问题→按钮回答→显式建任务→真实进度→候选逐组核对。授权/任务/操作请求丢响应保留operation_id重试；切换批次清除未确认草稿。照片使用同一转正缩略图与归一化框；展示完整照片和文字说明，框仅定位，不作为唯一识别依据。首个相册以当前owner的已确认人物列表浏览其照片。暂不接语音确认、真实Agent或记忆工具。

## 2026-10-23：已确认人物纠错与批次撤销

本切片目标：按来源 task_id + face_id 精确选择已确认人脸，支持移出、部分拆成新人物、两个人物合并（保留目标称呼）及撤销本批新增且未经人工纠错的关系。均先只读影响预览，再显式按钮提交；原图、日期、讲述不变。不调用识别模型，撤回分析授权或清理特征后仍可手动管理已有关系。

预览返回影响成员/照片数、保留数和当前状态摘要token；摘要绑定owner、操作、选择、受影响人物完整成员快照和纠错事件序号，提交在单个写事务重算校验，防止旧预览、ABA和并发覆盖。operation_id按owner唯一，重复请求返回同一回执，改变请求报冲突。历史记录actor、操作、来源成员和前后人物状态，不保存特征。空人物保留历史记录但不进入相册；已确认候选只代表当时确认，纠错后标corrected，不能再当当前成员真相。

人工移出/拆分/合并涉及的成员记录独立保护标记（移出后也保留）。本批撤销仅移除来源任务属于本批且没有人工保护的现存关系，保留其他批次及后来纠错的关系；明确预览保留数。此操作不撤销分析权限、不停止任务、不删除候选或特征；界面须提示先停止后台分析以避免之后再确认新关系。撤销不是重置相册，不回滚其他用户修改。重新确认来源于新任务的脸是新关系，不宣称跨任务人脸去重。

受影响路径：photos/people_schema.py、people_review.py、新people_corrections.py、api.py、photoApi.ts、PeopleAlbums及批次入口、专用测试。数据库仅新增表，初始化仍显式进行。验证：后端photo全套；UI确认/取消、丢响应幂等重试、旧预览冲突、图片失败禁确认、320px/200%字体；隔离Demo浏览器回归。成功需证明撤权后可纠错、跨owner拒绝、跨批保留、事务失败无半写、并发仅一个提交、撤销保留人工纠错及原图/元数据不变。未完成项在报告明确列出。
