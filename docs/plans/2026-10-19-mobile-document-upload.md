# Mobile Chat document upload

Scope: shared responsive creation/Chat reference upload panel. Existing backend extracts PDF, DOCX and PPTX text, and uploaded documents render as text references in the Prompt tray. The existing reference “+” and its local-upload action use one mixed file picker for images, audio, video and documents. Add MIME types alongside filename extensions for native file providers; do not introduce a separate document-upload action or input. Generation-only references keep existing modality restrictions. Word means DOCX; legacy DOC is not enabled.

Acceptance: the existing reference picker accepts PDF/DOCX/PPTX with extension and MIME filters alongside multimedia, multiple selection, no camera capture. The single picker uses existing owner-scoped upload and append references without changing generation mode. Upload buttons provide 44px touch targets, wrap within narrow panels, disable during upload, and expose upload failure feedback. Copy names document formats and existing limits (10 MB each, PDF up to 100 pages, extracted text up to 50000 characters; scanned PDFs need OCR).

Verify file-picker click, mixed DOCX/PDF upload, input state, busy/error/retry behavior, reference tray rendering, existing backend extraction/Chat injection, typecheck and production build. Code and automated tests do not establish native iOS/Android picker behavior; physical-device acceptance remains separate. No browser/web MCP access or model invocation is required.
