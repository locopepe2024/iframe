# Mobile Chat document upload

Scope: shared responsive creation/Chat reference upload panel. Existing backend extracts PDF, DOCX and PPTX text, and uploaded documents render as text references in the Prompt tray. This change exposes an explicit document picker for Chat on mobile and desktop, retains the mixed media upload entry, and adds MIME types alongside filename extensions for native file providers. Generation-only references keep existing modality restrictions. Word means DOCX; legacy DOC is not enabled.

Acceptance: the reference panel offers a clearly named document action; its input accepts PDF/DOCX/PPTX with extension and MIME filters, multiple selection, no camera capture. Both pickers use existing owner-scoped upload and append references without changing generation mode. Upload buttons provide 44px touch targets, wrap within narrow panels, disable during upload, and expose upload failure feedback. Copy names document formats and existing limits (10 MB each, PDF up to 100 pages, extracted text up to 50000 characters; scanned PDFs need OCR).

Verify file-picker click, mixed DOCX/PDF upload, input state, busy/error/retry behavior, reference tray rendering, existing backend extraction/Chat injection, typecheck and production build. Code and automated tests do not establish native iOS/Android picker behavior; physical-device acceptance remains separate. No browser/web MCP access or model invocation is required.
