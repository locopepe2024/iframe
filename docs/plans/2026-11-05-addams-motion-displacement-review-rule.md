# 动作位移与补帧审核规范

## 适用范围

用于逐帧姿势提取、模糊区域补图和白模动作验收。审核对象是可理解的动作序列，不以单帧关节位移大小或原始模糊轮廓的点位误差单独判错。

## 强制锚点

### 全局语义池

每次图像参考分析均须取得当前审核版本中与目标镜头相关的全部文本语义：时间线边界、动作阶段、人物左右、场景、机位、运镜、焦距变化、接触描述及人工修订。记录语义的审核状态和适用帧区间。未经审核的 LLM 描述是候选解释；审核通过的文本是约束，但不能覆盖清晰源帧中的直接可见事实。相互冲突的语义须进入矛盾清单，不能静默选择其中一条。

### 镜头内局部密集关注

对每个待判断帧，检查同镜头内覆盖动作起势、变化和收势的相邻帧；在快速动作、遮挡和模糊附近提高采样密度。先描述关节与鞋的运动方向、动作相位和支撑转换，再判断位移是否可解释。跨切镜帧不得作为连续运动邻帧；光学拉远与机位移动须分别标注。模型上下文无法容纳全部帧时，可压缩远端证据，但不能省略相关的审核语义或局部相位帧。

### 连续片段取样与动作重建

F2C（Sun 等，arXiv:2510.02262）研究在固定视觉 token 预算下选择连续关键片段，报告了相对均匀抽帧的长视频理解收益。它支持“连续片段优于孤立关键帧”的输入组织原则；论文不提供人体姿势求解或插值算法。对本项目，片段取样是动作理解的上游输入，补帧和骨骼约束是后续独立步骤。

1. 按审核后的镜头边界和动作阶段建片段；每个片段保留起势、变化、收势的连续源帧及时间戳。第 48–50 帧应作为一个局部踢腿片段，不能拆成互不相邻的单帧问答。
2. 在快速运动、遮挡、模糊和接触转换处增加连续帧密度；在静止或重复段降低远端采样分辨率或密度。不得跨切镜拼成一个动作片段。
3. 每个片段连同全局审核语义池提交动作分析。输出动作阶段、身体和左右腿方向、支撑变化、证据帧及不确定性；人工修订须替换旧分析后再供下游使用。
4. 对缺损帧，先用同片段前后清晰帧生成图像候选，再以片段动作相位检查其合理性。将通过的候选作为 GVHMR 观测输入；VPoser 先验与外层时序、语义、接触约束共同参与拟合。
5. 白模按整段连续播放审核，并对关键相位逐帧检查。记录源帧、生成候选、二维检测、三维姿势、相机与重定向各层来源；不以单帧点位误差替代动作验收。

当前 `second_pass_frames.py` 已按确认镜头边界组织连续参考帧片段：短动作区间逐帧取样，长区间保留锚点与相邻动作边界，并向每项二轮分析提供同镜头语义池。人工修订文本替换旧候选文本。长动作区间仍是稀疏片段，尚无按动作速度自适应分配帧预算、冲突清单或跨项目语义池；因此不能把当前实现等同于论文中的完整 F2C 方法。二轮分析输出目前仍是逐候选结论，不直接产出可供 GVHMR/VPoser 使用的连续姿势约束。

## 证据路由（Causal Routing）

按以下有向关系传递信息，并在每一步保留来源、帧号、审核版本与推断标记：

`源帧 + 已审核语义 -> 局部动作解释 -> 补图候选 -> 二维检测 -> 三维姿势/相机求解 -> 白模渲染 -> 人工验收`

- 补图候选可改善检测输入，但生成像素不是源帧事实；候选自身的清晰度不能证明其姿势正确。
- 二维检测、GVHMR、VPoser 或白模输出不能反向充当补图错误的独立证据。若下游与上游不符，先定位检测、姿势、相机或重定向中的失败边界。
- 同一候选生成的图像、检测点和三维结果属于同一证据链，不能互相计作独立验证。独立依据来自未修改的源邻帧、人工审核语义和白模中的动作约束检查。
- 发现矛盾时记录两端证据及来源，提出可区分原因的下一项验证；不得因单项评分不利就把已解释的动作重新标为“不可信”。

这里的 Causal Routing 是本项目的证据来源与使用方向规则，不声称已经实现论文中的特定路由模型。

## 判定顺序

1. 先写明前后帧可见的动作阶段、身体转向、支撑脚、运动脚和镜头变化，并区分人物解剖学左右与画面左右。
2. 对目标帧提出动作相位解释。位移大只触发复核；若目标姿势符合前后动作阶段和运动方向，应暂定为合理。
3. 只有发现具体矛盾，才提出图像或姿势可能错误。记录矛盾对应的帧、关节或鞋部区域，以及前后帧证据；不能仅写“跳变过大”。
4. 对模糊区域，用前后帧生成候选并检查肢体连接、膝踝弯曲、鞋尖方向、遮挡关系和非目标物体保真。生成内容标记为推断，不能当作源帧事实。
5. 将通过视觉检查的候选送入姿势求解。再独立检查三维关节、身体转向、脚部接触、相机和白模重定向；不得把这些层的错误反推为补图错误。

## 证据门槛

| 结论 | 所需证据 |
| --- | --- |
| 大位移合理 | 前后帧构成可理解的动作阶段；位移方向与该动作一致；没有可见的肢体连接或遮挡矛盾。 |
| 图像可能错误 | 指出与前后帧冲突的具体形状、解剖关系、遮挡或物体保真问题，并保存对照帧。 |
| 姿势求解可能错误 | 图像候选可解释，但检测点、三维关节、相机或白模投影出现可定位的矛盾。 |
| 尚不能判定 | 证据不足以区分高速运动、遮挡、镜头影响和生成错误；记录缺少的证据与下一项验证。 |

## 第 48–49 帧示例

第 48 帧左膝抬起、小腿近垂直；第 49 帧左小腿向前踢出。左踝在画面中的大位移与该相位变化相容，不能据此怀疑补图。旧人工点位标在原始模糊帧，可用于定位差异，但不能单独否定由前后帧推断出的清晰腿部。下一步应检查补图的腿鞋连接与方向，以及求解后白模的动作连续性。

## 审核记录要求

每项疑点记录：帧范围、动作相位解释、可见事实、候选结论、支持或反驳证据、证据来源，以及下一项验证。将图像、二维检测、三维姿势、相机和重定向分别归因，不跨层推断根因。

每次验收另需记录：审核 revision、全局语义事件 ID、局部参考帧、是否跨切镜、候选图像与模型输入哈希、下游结果哈希，以及矛盾是否已有独立证据解除。第 49 帧的源帧点位评分只作差异定位；动作通过与否取决于相位可解释性、关节和鞋的连续运动、支撑关系及白模预览。
