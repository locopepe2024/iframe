状态：已部署，公网提交、查询、下载实测完成。当前受控容量为 V2 候选最多 1 个运行任务；精确成片时长仍有偏差。

## 契约与边界

- 创建 `POST /oran/h3/v2/videos`，查询 `GET /oran/h3/v2/videos/:task_id`，下载 `GET /oran/h3/v2/videos/:task_id/content`。
- 使用现有 UniArt token、公开 H3 SKU 和统一任务响应；不新增模型、不升级其他视频模型 API。V2 专用入口只允许 `minimax-h3` family，执行候选必须为 `video/h3/v2 + oran`。
- 现有 V1 创建入口对 H3 排除 Oran V2 候选，但保留其他供应商原行为；存量任务仍按创建时协议查询、下载。
- 版本要求写入路由 requirements 快照，重选、异步恢复不丢失。V2 无可用候选时拒绝，不转投 V1。
- V2 查询/下载拒绝其他协议/供应商任务；认证和任务归属校验沿用现有边界。
- 本切片沿用已实现的生成参数，不开放 callback、文件库、再生等能力。明确拒绝未支持字段，避免静默丢弃。
- 生产配置经 managed aggregate 发布，保留其他候选/售价/容量。V1 本轮不关闭。

## 用户调用

保持现有 UniArt API 域名和 `Authorization: Bearer <token>`，以 JSON 提交。此次启用的公开 SKU 为 `minimax-h3-discount`；VIP 不在本次配置变更范围。

```python
import requests

base_url = "https://你的UniArt域名"
headers = {"Authorization": "Bearer 你的token"}
payload = {
    "model": "minimax-h3-discount",
    "mode": "text_to_video",
    "content": [{"type": "text", "text": "暖阳下，一只橙色茶壶，镜头缓慢移动"}],
    "duration": 4,
    "resolution": "720p",
    "ratio": "1:1",
}
response = requests.post(base_url + "/oran/h3/v2/videos", headers=headers,
                         json=payload, timeout=60)
response.raise_for_status()
task_id = response.json()["id"]
result = requests.get(base_url + f"/oran/h3/v2/videos/{task_id}",
                      headers=headers, timeout=60)
result.raise_for_status()
# 轮询直至 status=completed 后，以相同认证 GET 下列路径下载：
# /oran/h3/v2/videos/{task_id}/content
```

参考素材可放入 `content`，例如 `{"type":"image_url","image_url":{"url":"https://..."},"role":"reference_image"}`。图/视频/音频 role 分别为 `reference_image`、`reference_video`、`reference_audio`；首尾帧为 `first_frame`、`last_frame`，尾帧不能单独提交，帧模式不能混用参考模式。使用参考素材时设置 `mode: "omni_reference"`，首尾帧模式设置 `mode: "first_last_frame"`；单首帧使用 content 的 first_frame role、`mode: "image2video"`。也支持 `prompt`、`reference_image_urls`、`reference_videos`、`reference_audios`、`first_image_url`、`last_image_url` 的简写形式；content 与这些旧式媒体字段不能混用，content 内已有 text 时也不能另传 prompt。

- prompt 为 1–7000 Unicode 字符；duration 为 4–15 整数秒，也可传字符串 seconds，避免同时传入冲突值。
- 720p/768p 映射上游 768P；2k/1440p 映射 2K。比例支持 21:9、16:9、4:3、1:1、3:4、9:16、auto/adaptive，仍受公开 SKU 能力限制。
- 参考素材数量上限：9 图、3 视频、3 音频，合计 15；上游契约要求参考视频总时长不超过 15 秒，不将能力声明等同于网关已探测所有媒体时长。
- 不需要 `routef` 或 `contentForm`。V2 顶层白名单明确拒绝未知字段，也暂不开放 metadata、seed、callback_url、文件库和再生接口。
- 响应保持 UniArt 公共任务格式：以 `id` 查询，`status` 为 queued/in_progress/completed/failed；返回的结果链接可沿用公共交付路径，不保证全部链接都使用 V2 前缀。
