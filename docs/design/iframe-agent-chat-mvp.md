# 创作台 Chat MVP

- 入口：创作台“创作 / Chat”，创作组件保持挂载；Chat 使用独立持久化会话，避免污染生成历史。
- 模型：按当前用户凭据获取 UniArt /models，严格筛选 chat capability；前端遵循已选 SKU。请求使用该用户 UniArt base URL/key，不使用默认 DashScope。
- 持久化：SQLite 会话记录，owner profile + session id 隔离；数据库原子更新与 180 秒发送租约阻止并发覆盖。上游超时 120 秒。失败不追加半轮消息。
- 上下文：最近 30 条消息和本次参考素材名称、当前创作提示词作为只读文本上下文；第一版不宣称模型已看见图像像素。
- 确认：回复可由用户明确复制到创作提示词，再点击原有生成按钮；Chat 无生成工具调用。
- 验收：会话增删改、多轮历史、用户隔离、模型校验、错误重试、前端类型检查及生产构建；线上检测 JSON Content-Type，保留原数据卷及凭据环境。
- 部署：以现有线上容器配置为准克隆环境/挂载（不输出密钥）；保留回滚容器。不得用仓库默认 Compose 替代生产配置。
- 尚不包含 SSE、持久任务队列、分布式数据库或高并发承诺。
