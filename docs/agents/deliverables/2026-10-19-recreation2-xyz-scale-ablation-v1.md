# recreation2 XYZ 边界拆分：轴尺度隔离

2026-10-19。**确认轴尺度补偿会改变结果，但单独补偿不能通过前段验收，也没有消除脚部异常位移。** 本轮没有修改主builder、源XYZ、rig或服务。

## Observed

### Code fact：拆分三个使用边界

| 边界 | 本轮处理 | 证据边界 |
|---|---|---|
| 归一化图像XYZ→方向目标 | 对照Y原值与Y×792/1394 | 只统一图像轴尺度，不是相机反投影 |
| 髋相对Z→root绝对前后位移 | 固定原root/yaw，不与尺度混改 | 契约不充分；2秒髋均值Z使该root深度项仅约−0.000133至+0.000006 units，尚未做独立因果消融 |
| 方向目标→rig局部旋转 | 固定no_pelvis_root基线的混合旋转基底；骨盆/IK均关闭 | 已知自身/父基底问题没有在本轮顺手修复；本次结论以这条映射为条件 |

### Runtime observation：工程控制通过

使用Blender4.5.9和pinned rig SHA-256 `95eeb19c8abce2325479804b3dda429ebddfa6e8d07a2688541cc990fb676855`，沿用原PTS anchors与640×360镜头。两组对全部子骨重新求解，不是删除旧旋转。

- raw的29个key及root位置、yaw、骨盆/子骨四元数与既有no_pelvis_root bundle逐值相等。
- 补偿组与raw的root位置、yaw、时间key逐值相等，源track运行前后哈希相同。
- 两组独立renderer重导入相对求解内存姿态最大投影差均 **0px**。
- 28个独立源采样×12关节=336项误差；重复的hold key不加权；连续指标来自48个输出帧。

### Runtime observation：按关节拆开

源23并非所有关节一起变差：left_knee **21.68→10.36px**，但left_ankle **7.37→25.52px**、right_ankle **0.54→24.52px**。源29则left_ankle **23.70→4.41px**、right_ankle **26.76→5.66px**。两髋在各帧投影保持不变。

源1也出现膝与踝分化：right_knee **21.07→9.56px**，right_ankle **2.50→29.15px**。不能由膝点改善推断整条腿接触改善，不能只用全身均值接受该修改。

## Direct implication

1. 轴尺度与结果之间有受控运行证据，但“补偿尺度就是最终修复”的结论不成立。当前映射下，部分膝点改善、踝点变差，需将方向目标、串联骨链端点和投影分开验收。
2. 右腕异常略降而最大步长转移到右踝，脚patch位移也上升；这一类异常不能只靠aspect补偿或平均指标吸收。
3. 原XYZ无需加深度；轴单位、髋相对原点、rig旋转空间是三个不同契约。此轮固定后两者，只量到第一项在现有链路中的条件效果。

## Not yet proven

未分别量出源Z估计、相机投影、目标骨长/关节中心、父空间和root/yaw的剩余贡献；没有证明哪一项最大。单一宽高因子不是世界三维重建，不可能据此次结果证明MediaPipe原生world landmarks一定更准。原有混合基底可能与尺度补偿存在交互，本轮未测其交互。未通过脚接触、转身或H3验收。

## Hypotheses

把归一化图像坐标当欧氏方向，再用固定目标骨长和独立镜头投影，可能在不同姿态产生相反端点残差；源图像坐标中的透视与proxy Z未必足以给出目标rig所需的准确三维方向。这是下一边界的候选解释，不能由本次投影表直接定为根因。

## What would verify it

下一项应保留本次两组完整结果，先量目标方向相对源骨段的二维倾角、投影长度与端点残差，再在相同方向输入下比较原混合基底与已验证的自身基底，形成预先固定的2×2对照，量出尺度与旋转基底的交互。root/yaw与相机继续固定。若转而测试原生world landmarks，应重新提取并核对相同源帧/人物身份，单列与图像XYZ的契约，不能直接更换字段后宣布修复。支持脚地面/鞋缘约束仍独立验收。
