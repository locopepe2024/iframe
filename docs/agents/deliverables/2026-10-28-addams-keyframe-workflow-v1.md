# 关键姿势优先人工入口

人工入口从原99帧风险队列、81帧保守去重队列，调整为23个初始关键姿势候选。它们按已知分镜、接触事件及诊断选取，不是已经验证的全部动作峰值；后续由动画偏差决定增补位置。

新入口：addams-keyframe-review-v1/review.html。只修错点即可保存关键帧，隐藏点和脚掌点可留空待审；不再要求逐项确认16点。模型建议未被明确确认的，导入时清空测量坐标、保留待审状态，不升级为人工约束。脚掌代理使用foot_surface语义，与骨关节点区分。

已完成49–58帧的10帧人工结果独立保存在preserved-human-review.json，即使不在23帧队列仍保留供后续求解。46帧身份/接触事件独立保存在preserved-events.json，页面可展开查看完整事件时间线。原页面与暂存版本保持可恢复，新版可导入旧v1全身JSON，新增任务外的旧帧已在上述存档保留。

导出文件名：addams-keyframe-review.json。导入：

