# 源视频到 Blender 的三层映射边界

## Observed

当前实验把源鞋底代理点直接与白模脚骨投影比较，右脚脚尖方向可校正，但端点误差仍为43–53px。目标 rig 审计显示白模已有 `ankle_*`、`foot_*`、`toe_*` 骨骼和可变形 mesh；mesh 可从每帧姿态中导出脚部最低点、脚跟和前掌候选。源视频没有提供目标 rig 的鞋底几何或世界地面。

## Direct implication

正式管线应拆成三层：

1. **场景资产层**：源镜头、裁剪、有效内参候选、世界地面、灯光和场景几何。
2. **人物资产层**：目标 mesh、骨架 rest pose、骨长、脚掌/鞋底代理、父子空间和人物比例。
3. **动作迁移层**：源视频恢复的姿态/根轨迹 → 目标骨架重定向 → 支持脚时段的局部IK/脚锁定 → 镜头重投影和渲染。

源帧只能约束动作观测、接触事件、脚尖方向和镜头投影；它不能直接规定目标 mesh 的鞋尖像素位置。IK应在目标 rig 自己的脚掌几何和地面坐标中工作，源鞋点只作为事件或方向证据。

## Not yet proven

当前白模尚未形成正式的 canonical ground contract：脚底代理点仍是从当前姿态 mesh 的最低点启发式提取，尚未回写到 rest pose资产；源相机内参、世界地面和根轨迹也未完成联合恢复。现有 Blender 候选只能作为诊断资产。

## Hypotheses

此前把源鞋底点直接作为白模端点目标，可能把“骨骼中心、鞋底代理、网格外轮廓、地面接触”四种语义混在一起，导致局部IK看似无法修正。先固定目标 rig 的脚掌几何和地面，再把源接触标签映射为约束区间，预计比逐像素追鞋尖稳定。

## What would verify it

下一步按此顺序验证：

1. 在目标 rig rest pose 中保存左右脚的 heel/forefoot/toe 代理和 sole plane。
2. 在场景层保存 ground plane 与相机坐标约定。
3. 只把源右脚支撑区间转成 `support_foot=right`、脚尖方向和接触时间窗。
4. 用目标脚底代理做脚锁定和局部IK，检查滑动、穿地、垫脚。
5. 最后才用源画面重投影评价动作与镜头，避免把网格外轮廓当骨骼真值。
