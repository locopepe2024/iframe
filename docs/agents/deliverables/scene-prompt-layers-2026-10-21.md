# 静态场景 Prompt 三层结构

## 范围与验收

本次完善场景首次出图的基础面板：光影、镜头、构图独立选择，初始全部为空。只将实际选择写入可见的图片提示词，再交给现有检查、保存和生成流程。原设计与 AI 优化继续独立保存，明确使用来源。

- 光影：source / direction / quality / fill / contrast。
- 镜头：framing / viewpoint / focal_length / depth_of_field。
- 构图：subject_position / spatial_layers / leading_relation。
- 光源和机位可独立使用三维球的方位角、仰角；Z 向上，前方 -Y，右方 +X。仅表示相对方向，不推断距离。精确角度替代同层方向描述，旋转机位不改变光源。
- 选项再次点击取消；没有选中时不输出该字段。焦距只表达广角/标准/长焦空间观感，不绑定光圈、景深、品牌或虚化。
- 不提供默认相机品牌、奶油虚化、柔肤、磨皮及剪辑连续性规则。不将原研究中的无授权文字直接复制。

## 兼容与边界

`asset_design.prompt_layers` 为版本 1 的有界严格对象，三层文本字段最多 500 字，未知键、错误类型和不完整角度在资产变更前拒绝。保留旧环境光、视角、构图文本作为补充；原主光方向迁入同一光影编辑区域，选新方向时清除旧方向，避免双重来源。已知禁止方向与新方向直接矛盾时阻止应用。

统一前端编译函数供“应用”和 AI 完善依据使用，避免两套拼接。保存/重开/重新编辑保留三层字段及两个提示词。已保存字段不自动重写手工提示词。下游生成快照已有完整 design_draft，保留本字段；本次不把静态基础机位自动强加到分镜。

现有已出图编辑工具继续保留独立的任务参数契约；本次不改旧预设的视觉效果，也不把它们默认导入基础面板。Blender、媒体服务和图片编辑接入不在本次范围。

## 验证

前端：空设置无输出、独立景深、取消选择、三维方向、禁止方向冲突、保存/恢复和原设计/AI 独立性。后端：严格校验、无部分变更、保存重载、生成快照保留。运行相关 UI / Python 测试、类型检查、生产构建；上线后核验版本和健康状态。真实模型遵循程度和 WebGL 触摸交互不由代码测试证明。

## 对焦字段补齐

代码核对发现：旧镜头调整工具具有 focus_x / focus_y / focus_radius，但新基础面板 camera 未定义 focus，不能记录或输出对焦数据。补齐 camera.focus：可选 target 文本（最多 500 字）、可选 x/y 百分比（严格整数 0–100，成对出现）、可选 radius（严格整数 6–42，必须有位置）。null 或无字段不输出对焦限制；空对象不保存为有效选择。

UI 提供对焦目标输入及主动开启的画面位置设置。文字目标与坐标均随面板状态保存、恢复，编译至可见提示词，既有生成快照携带完整结构。坐标以画面左上角为原点、X 向右、Y 向下；不是世界坐标或真实焦平面距离。范围表示期望清晰区域，不替代景深选择。

验收：先复现编译遗漏及后端拒绝，再验证目标单独设置、坐标设置/取消、非法和不完整坐标拒绝、保存重载、原设计与 AI 来源独立、排队快照不被后续编辑覆盖。旧镜头调整工具的参数契约保持兼容。

## 光源与氛围扩充

扩充首次出图基础面板的光源覆盖：自然光、火焰、古代灯具、现代实景灯具和拍摄灯具。保留已存七项原值，新增独立选项，不自动添加方向、软硬、补光、反差或色调。

在现有光影层增加 mood（氛围）、air（空气介质）、color（光色关系）三个可选文本字段（各最多 500 字）。氛围描述静态观感，不引入人物/时序；空气介质只描述雾、尘、烟、水汽等，不推断光源或添加道具；光色关系保持物体固有色。沿用三列按钮、每字段单选、再次取消、初始为空；新字段按“氛围、空气介质、光色关系”标注编译，进入已有保存/恢复/提交快照路径。旧记录不迁移、不自动新增内容。

验收：光源与氛围独立、取消不改变其他设置、空字段不输出、旧值兼容、新字段保存重载、错误类型/超长拒绝；相关 UI/Python、类型检查与生产构建。

- 体积光不设默认；空气介质独立选择，不随氛围自动增加雾气。阴影遵循选定光源和遮挡，不把人物面部的左右阴影硬套给场景。

## 预设收口到面板

删除旧镜头/光影工具的预设按钮，新任务 preset 固定为 null/custom；保留历史参数和原编译器分支以便旧记录可读/审核兼容。将独有的鱼眼观感、倾斜画面、窗格投影、蓝色轮廓光拆成独立字段选项；不把品牌、胶片褪色或高光泛雾作为光源词自动迁入。

工具与首次出图复用同一 SCENE_LAYER_FIELDS 和选择组件。工具的精确方向、颜色、亮度、对焦保持现有控件；新增 panel_settings 仅接受与这些控件不重复的维度，严格校验后保存在 scene_tool 元数据中，前后端使用一致的标签顺序编译。新任务不带旧预设语句，历史任务编译保持不变。补充面板不提供第二套方向/对焦控件。验收需验证共享选择、取消、无预设入口、前后端编译一致、冲突字段拒绝和旧参数兼容。

用户澄清：黄金时刻等完整搭配应保留为氛围 Prompt 模板。八个旧光影方案迁为独立共享模板目录，移除“诺兰”等品牌命名，以可见结构填充光影面板；选择后替换当前光影设置，保留镜头与构图，可逐项调整再应用 Prompt。调光工具使用同一模板，但角度/颜色/亮度映射至现有专属控件，避免两个事实来源。模板是主动选择的完整方案，单项词典不承担完整方案。褪色胶片等风格效果只在主动选模板后加入。

## 季节、时段与冷色天光补齐

目标：可选择秋天 + 傍晚 + 天空环境光 + 冷蓝色；也可选择蓝调时刻完整模板再调整。不自动增加暖阳、落叶、雾气、柔焦或镜头效果。

沿用三层结构，在 lighting 增加可选 season/time_of_day（严格字符串，最长500字）。这是光照的环境上下文，不推导天气或植被。原有 ambient_lighting 补充文本不自动改写。基础面板与光影编辑工具共用原子目录；工具颜色仍由专属颜色控件拥有，模板用显式色值映射。

词元补齐天空环境光、冷蓝色、蓝灰色、冰冷氛围；模板增加蓝调时刻（Blue hour / Twilight）、清晨冷光（Crisp dawn / Early morning cool light）、冰冷低饱和。Pre-dawn mist 必须显式选薄雾，不捆绑到清晨冷光。Cinematic lighting 是宽泛风格，不据此推断具体光位或镜头。模板关键词可搜索，中英文别名属于检索元数据，不默认加入出图文本。

验收：空值无指令；只编译选中项；秋天傍晚组合无隐含暖光或雾气；保存重载及工具队列重解析保留新字段；工具前后端编译一致。涉及共享目录、面板、模板、Pydantic模型及相关行为测试。

用户后续示例收为蓝橙暮光·薄雾、通透冷光、丁达尔冷光束；蓝橙、薄雾、低饱和均仅在显式选择时生效。光影工具保留模板完整光色关系到可编辑补充提示词；主光HEX不承载多光色关系。该遗漏以失败测试复现后修复。8K不作为照明属性，也不承诺Prompt能改变输出分辨率。
