# GVHMR 姿势能力验证进度与下一步计划

日期：2026-10-08。范围：iframe 动作复刻的独立研究测试；版本合并交由管理员。

## Observed（已观察）

- media 主机为 4 CPU 核、15 GiB RAM、无 GPU。实验使用 GVHMR 上游版本 `ee960bb6e2ea2d381aa97f08e9b71ef320b624b1`，不属于 iframe 运行时。
- 测试输入为原片前 3 秒，90 帧、30 fps、720×854；源文件 SHA-256 为 `49c73ccaaa2bf36d89c234006417320f7ffd5f9c5d58e6eafd227e38d4fa8602`。原片共 18.53 秒、556 帧。
- YOLO 追踪、ViTPose 2D 关键点、HMR2 图像特征均完成。2D 输出为 `(90, 17, 3)`，置信度中位数约 0.915，1530 个点中 16 个低于 0.5；特征输出为 `(90, 1024)`。两者均无非有限值。0、1、2 秒抽帧的骨架叠加大体贴合人物。
- GVHMR 主网络严格加载 247 个 checkpoint 键，CPU 前向计算完成。四个推理 checkpoint 来自 Hugging Face 镜像，其文件哈希与镜像 LFS 声明一致；尚未独立证明与官方 Google Drive 文件相同。
- 用户提供的 `models_smplx_v1_1.zip` 内含 `SMPLX_NEUTRAL.npz`；包内 `version.txt` 标示 `Version 1.0`。neutral 模型 SHA-256 为 `376021446ddc86e99acacd795182bbef903e61d33b76b9d8b359c2b0865bd992`，仅安装于 media 实验目录，未进入 iframe 仓库。
- 使用**假设静态相机**的诊断运行完成 90 帧 SMPL-X 解码，耗时 1.71 秒、峰值 RSS 1,048,772 KiB。`global` 与 `incam` 均产生有限值的 `(90, 22, 3)` 关节轨迹。产物声明 `static_camera_assumed_for_diagnostic=true`、`world_trajectory_validated=false`。
- SimpleVO 在该素材上的 `scale=0.5/step=8` 和 `scale=1/step=1` 两次尝试均未完成相机轨迹恢复。PR #57 截至本记录仍为 OPEN，目标分支为 `integration/iframe-director-current-20261004`；合并由管理员处理。
- 已固定 12 个跨动作阶段的源帧索引：`0,45,89,112,135,150,165,300,352,368,383,420`，源文件 SHA-256 为 `ba4a4dc38a7fbaad1ab3e3b1aa8bf9d1c5b8123659423128393b6a2a5f1f6671`。这些阶段标签是临时视觉采样，尚未由人工逐帧标注确认。
- 对前 3 秒 `incam` 关节做了 90 帧相机内重投影诊断：1514/1530 个关节对满足置信度和正深度条件；GVHMR COCO-17 回归关节与 ViTPose 的中位像素差约 7.58 px，P90 约 18.00 px。该比较是两个模型输出之间的一致性，不是人工真值。
- SimpleVO pair diagnostic 显示 71→72 帧有 340 个 ratio-test 匹配、324 个 essential 内点，但 pycolmap 配置为 `WATERMARK`（码 7）且没有相对位姿。关闭水印检测后同一对变为 `PLANAR`（码 4）并返回相对位姿；这定位了一个求解器拒绝条件，但平面解尚未证明可用于世界轨迹。

## Direct implication（直接含义）

- CPU 预处理、模型前向、SMPL-X 参数解码及骨架导出这条**执行链路**已打通。模型输出的存在和有限值不等于动作准确。
- 此次静态相机诊断不能作为真实世界 root 轨迹或转身方向的证据。相机内姿态可单独与源帧比较，但需要明确投影口径与人工复核。
- `SMPLX_NEUTRAL.npz` 不再是实验阻塞项；当前主要验证边界是相机观测、源帧对齐、动作质量与白模骨架映射。

## Not yet proven（尚未证明）

- 22 关节的左右、深度、躯干朝向、快速转身、跳跃和脚部接触与原片一致。
- `global` 坐标中的相机运动与人体位移已正确分离；当前没有有效的相机轨迹。
- 前 3 秒冒烟测试能代表完整 18.53 秒素材的动作质量；旋转动作的精确源时间段尚未记录和测试。
- GVHMR 局部旋转能正确映射到现有 Blender 白模 rig；尚无连续白模动画或源帧对照验收。
- HMR2 的 439.5 秒记录曾受重复并发进程影响，不能直接用作稳定性能基准。

## Hypotheses（待检验假设）

- SimpleVO 失败可能与暗光、运动模糊、人物占画面比例、动态前景或背景特征不足有关；现有失败日志尚不能确定单一原因。
- 即使世界轨迹不可用，相机内关节轨迹仍可能足以评估短片段的人体姿态与白模局部动作；需由源帧投影和人工标注检验。

## What would verify it（下一步计划）

1. **固定对照素材与评价口径。** 已完成源文件 hash、尺寸、FPS 和 12 个候选帧索引固定；下一步由人工确认每帧的动作阶段、左右标签、可见性和遮挡。复用现有 `motion-track.v1` 及 review overlay，源轨迹保持只读。验收：关键帧可回溯到同一源文件与帧号，人工修正和原始估计可并列查看。
2. **核对相机内 3D 姿态。** 明确 GVHMR 坐标、关节顺序、相机内参及投影公式；将 `incam` 关节投影到对应源帧，与 ViTPose 和人工审核点对照。分别记录左右错误、角度/长度残差、低置信度及遮挡，不用拟合后的二维误差代替 3D 朝向判断。验收：关键帧均有源图、自动骨架、审核点、投影及逐项偏差；异常能定位到模型估计或坐标转换。
3. **定位相机恢复失败边界。** 已保存失败帧对、匹配数量、内点率和求解器配置；71→72 帧的默认 `WATERMARK` 判定已被隔离，关闭该检测后得到 `PLANAR` 对照结果。下一步测试完整片段的禁用水印方案和逐对配置稳定性；不能直接把平面解写入主轨迹。验收：产生完整且时间对齐的相机旋转/轨迹并通过抽帧检查；未通过时保持 `world_trajectory_validated=false`，不把静态相机诊断提升为世界轨迹。
4. **扩展动作片段。** 在前两项通过或明确隔离未通过边界后，按精确时间戳处理完整转身及跳跃/落地片段；分阶段记录耗时、峰值 RSS、掉帧、关节连续性和失败帧。验收：关键动作的起止与源片一致，所有不可信帧显式标记，人工复核结论不由置信度代替。
5. **白模重定向对照。** 先用已知正确的标准骨架动作隔离 rig 映射问题，再将通过审核的 GVHMR 局部旋转映射到现有白模；检查 rest pose、父骨骼空间、左右、root、脚部接触和连续帧投影。验收：产出源帧/白模并排预览、映射清单与失败报告；只有通过连续动作复核的结果才作为复刻参考。
