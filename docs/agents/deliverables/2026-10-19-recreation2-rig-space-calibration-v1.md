# recreation2 身体轴、骨盆和 root 空间隔离

2026-10-19。结论：已定位并量出 root 求解/渲染空间不一致及局部旋转基底问题；身体参考架校准能正确执行目标骨盆旋转，但没有通过前段投影验收。**本轮为隔离实验，不是最终动作修复，不进入 H3。**

## Observed

代码事实：旧 builder 在没有渲染 root 的 armature 上求各局部旋转，同时把 `rootYaw` 写入 bundle；renderer 随后对整个骨架施加这个 yaw。旧脚本仅 upper arm/upper leg 使用自身骨头基底，其余骨头使用父骨基底。

运行观察：使用相同 `track-2s.json`、既有 29 个 PTS 锚点、Blender 4.5.9、640×360 相机及 pinned rig，七组实验重算所有子骨骼。rig SHA-256 `95eeb19c8abce2325479804b3dda429ebddfa6e8d07a2688541cc990fb676855`。无骨盆基线的 29 个 key，其 rootPosition/rootYaw/pelvisQuaternion/localQuaternions 与上轮结果逐值一致。

逐轴运行观察（下列为世界坐标中的向量）：

|---|---|---|
| X / 解剖学左→右 | (1.000, 0.000, 0.000) | (−1.000, 0.000, 0.000) |
| Y / 构造前轴 | (0.000, −0.242, 0.970) | (0.000, −1.000, 0.005) |
| Z / 髋→肩上轴 | (0.000, −0.970, −0.242) | (0.000, 0.005, 1.000) |

“构造前轴”采用 `up × right`，属于坐标约定，不独立证明人物真实面向。身体坐标架用双髋骨头头部与双肩骨头头部构造；不能将其直接用作骨盆骨轴矩阵。新诊断采用 `target_body @ inverse(rest_body) @ rest_pelvis`，再用当前骨头自身世界旋转将世界 delta 共轭回局部。所有目标身体参考架行列式约 +1；所测骨盆执行目标角差为 0°。

全七组 bundle 均通过现有 renderer 的独立重导入检查：所选六帧各 12 关节，与求解内存姿态的最大投影差为 **0.0 px**。在全部使用自身基底的组，求解时各目标肢段方向残差 <0.1°。同时纳入 root 的组，渲染后测得肢段方向残差也均 <0.1°；旧无骨盆基线源55帧渲染后最大肢段方向残差为 **104.63°**，该帧写出的 root yaw 为 **103.69°**。这些方向目标均来自同一输入 proxy，方向对齐不能证明源动作准确。

足部单独观察：仅纳入 root 的源29帧平均误差虽然降至 18.46 px，左右踝误差仍为 **23.70 / 26.76 px**；完整身体校准在源55帧平均误差降至 19.35 px，左右踝仍为 **18.00 / 18.27 px**。报告记录足骨头尾世界坐标，但这些点不是鞋底，也没有已验证的物理地面，不能把它们的 Z 值当成离地高度或接触证据。

## Direct implication

- 算法推论及运行验证：在最终 root 变换下求解，可避免后续 root 旋转再次偏转已经对齐的世界方向。该不一致对本样本后段方向残差有可测贡献。
- 算法推论及运行验证：本 rig 重置姿态下，用当前骨头自身基底转换世界 delta，能够正确执行所要求的局部旋转；父骨基底不能普遍替代自身静止骨轴。
- 运行观察：方向残差下降没有保证关节投影下降。目标身体参考架校准在前四个验收帧没有全面胜过无骨盆基线，故不满足 spec 的候选提升条件。

## Not yet proven

- 未证明 proxy 深度给出的身体朝向真实，未证明 19.35 px 的后段结果正确恢复转身。固定相机在后段仍混有已观测的背景重构图项。
- 没有验收鞋底接触、支持脚锁定、身体比例/骨长、网格轮廓或遮挡处动作。首段平均误差改善不能替代这些验收。
- 未修改主 builder、服务部署或 rig。没有把按帧挑选误差最低的实验拼接成最终动作，亦未把数值最小当成正确三维解。

## Hypotheses

- 修正旋转空间后剩余关节位置失配，可能含身体比例、髋/肩关节中心偏移、根位置映射、proxy 深度与固定镜头误差；本轮未分别估计贡献。
- 校准骨盆前段更差，可能与髋横向信号和 proxy 深度接近量级有关；骨盆达到计算目标，仅证明变换实现，不证明目标正确。

## What would verify it

1. 对正确转换后的姿态，分别量肩宽/髋宽、肢段长度、根位置及相机项的投影残差；固定相同源帧，不用 yaw 扫描或逐帧挑选掩盖剩余错误。
2. 根据源可见鞋底/舞台关系，独立标支持、摆动和不确定帧；校准鞋底局部点及地面，再只在有证据的支持期约束接触，重点检查源29–33及43–51帧。
3. 在源1/17/23/29帧均胜过既有基线、后段朝向与全段接触/画面验收通过后，才讨论将诊断公式提升到主脚本和 H3 参考链路。
