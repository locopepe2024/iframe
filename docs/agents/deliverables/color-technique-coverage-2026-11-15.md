# 色彩技法补齐与来源复核

## 目标与边界

沿用用户此前给出的八站来源及后续优先级 Screenweaver；先核对已有
iFrame 能力，避免把来源登记或 IYIShow 的审核草稿表述为 iFrame 已上线。
本批补齐三个独立色彩方向：跳漂、暖褐单色、反冲洗。定义与提示词由
iFrame 独立编写，引用 Screenweaver 的术语和详情地址，不复制网站示例
提示词、文章、剧本或媒体。

不重做已有八条胶片色彩，不重做综合题材风格、基础布光和运镜；
日拍夜、灯光色片和白平衡需要场景/相机作用域，不塞入人物色彩条目。
组合提醒属于创作建议，不建立设备 × 景别 × 焦段 × 输出画质的自动校验器。

## 执行和验收

1. 用九站来源表记录登记、快照、结构化内容及 iFrame 本地入口的证据，
   对 Screenweaver 的 15 个色彩术语逐项标注现有覆盖与缺口。
2. 三条新增内容进入已有 `Prompt 模板 → 视觉风格`，分类为 `色彩技法`。
   每条保存定义、适用场景、不宜并列的要求、独立提示词及来源位置。
   提醒显示在预览中；最终仅追加用户确认的可编辑提示词。
3. 通过现有 UI 验证分类、中英检索、预览、编辑、取消和显式追加；
   保留现有 45 条综合风格、8 条胶片色彩、33 条运镜及 9 条多视图。
4. 运行相关目录及 UI 测试、TypeScript 和构建；检查 diff 后原子提交。
