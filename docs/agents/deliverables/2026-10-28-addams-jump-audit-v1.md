# 第一镜头突跳来源核查

## Observed

连续v2最大相邻帧腿部方向变化出现在55→56帧：右小腿97.46度，左小腿96.67度；48→49帧左小腿93.35度。该指标是候选骨架方向变化，不是源人物真实角速度。

逐帧源图与MP投影叠加目视检查发现，第49、52–56帧下肢点明显跑到上半身区域。第55帧MP双踝在审阅图y=123.2/127.4，visibility=0.87/0.89；独立RTMPose双踝y=400.3/461.3，score=0.51/0.44。第57帧MP双踝恢复到y约465。两模型置信度不可直接横向比较；独立模型点位也未成为人工真值。

## Code facts

continuous_candidate按单点可见性阈值0.35接收数据，没有整个人体结构或跨模型一致性校验。因此高visibility的错误点仍可能进入候选。低可见性的点会插值，不同关节的可信区间又不同，不能保证拼成一致姿态。

continuous_fit优化目标正则化correction=params-initial的二阶差分，而不是实际动作方向的差分。在初始解correction=0时，即使初始动作存在突跳，这项惩罚仍为0。该实现原本是限制修正量，却不足以实现实际动作连续性。

## Direct implication

当前突跳至少已经存在于上游输入/候选中；此前Blender重放的微小数值误差不能解释约97度跳变。改善20–24帧拟合误差没有覆盖49、52–56帧的输入异常。需要同时处理不可信整段姿态和实际动作的时序约束，不能依靠旧修正量平滑消除错误先验。

## Not yet proven

尚未证明上游错误具体由倒置、卡通体型、模糊或其他输入预处理引起；亦未证明独立模型能正确恢复这些帧。没有新3D动画或鞋底接触通过验收。

## What would verify it

下一轮同源/同rig/同投影对照：将上述异常帧作为显式诊断区间，保留原始点与排除原因；比较输入筛选和实际方向连续性约束各自效果。以人工27点误差、全镜头方向变化、关键动作时序和侧视姿态联合检查，避免用平滑抹掉真实踢腿。必要时仅补标异常区间关键关节点，不要求重标全片。

证据：addams-jump-audit-v1/report.json、source-mp-contact.jpg。诊断脚本复算最大变化并断言为55→56帧。
