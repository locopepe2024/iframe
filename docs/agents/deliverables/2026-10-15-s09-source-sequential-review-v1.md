# s09 源片连续帧复核：深俯身与两次高举

日期：2026-10-15。素材：`s09-motion.mp4`，局部帧 `n` 对应原片帧 `1085+n`；30 fps。查看局部帧 24–111 的逐帧联系表，另以较大尺寸复核 66–89。此记录修正此前把帧 87 当成**首次**高斜举的时间线解释；不改写旧试验结果。

## Observed

| 可见阶段 | 源片局部帧 / 播放时间 | 证据与限制 |
|---|---|---|
| 俯身加深 | 约 27–33 / 0.900–1.100 s | 身体从前倾进入更低姿态；部分帧枪杆和头发运动模糊。不是精确动作起点。 |
| 深俯身 | 约 34–60 / 1.133–2.000 s | 躯干明显压低，杆大体横跨身体上方/后方；中段先朝侧前、后转背向镜头。至少帧 40–55 明确深俯。因头部/手部遮挡、视角变化，不把所有帧判成同一关节角或静止保持。 |
| 回升 | 约 61–65 / 2.033–2.167 s | 帧 61–63 逐步升起，帧 65 接近直立且红缨在画面左。手部接点和杆端中途轨迹未定。 |
| 第一次高斜举 | 约 69–73 / 2.300–2.433 s | 帧 69 红缨端高向画面左上；帧 70–73 杆转为向右上高斜。红缨方向在短窗中变化，不应合并为固定单侧。 |
| 回落/转背 | 约 74–81 / 2.467–2.700 s | 杆降至近横向，身体背部朝镜头；这是两次高举之间的可见阶段。 |
| 第二次高举 | 约 82–87 / 2.733–2.900 s | 红缨端从左侧横向上抬，帧 83–84 近竖直，帧 87 向画面右上高斜。帧 87 是第二次高举中的锚点，非第一次。 |
| 前方展开 | 约 88–111 / 2.933–3.700 s | 杆由斜向右上转为较横向的前方展开，视角/距离变化；帧 99–111 的杆更贴近镜头。不能用像素长度推断物理枪长。 |

源片局部帧 112 为硬切，以上连续帧复核只覆盖切前镜头。联系表是逐帧解码的视觉复核；上述宽范围仍是**可见状态窗口**，不是动作力学上的精确起止。慢放、运动模糊和画面裁切限制握点及枪尖路径判断。

## Direct implication

两个相似姿态必须分别编号、分别对齐，不能把生成片第一次举杆与源片第二次高举作时差。此前以帧 87（2.90 s）作为首次高斜举、由此认定 v2 约 2.13–2.25 s 举杆“提前约 0.7 s”的比较无效。v2 举杆相对源片第一次高举的时间差可能小得多；但还需确认输出是否表现出**高举 → 回落/转背 → 再高举**的事件顺序及等价姿态。v3 约 1.75–2.00 s 已举杆，仍只是较早的候选，未做完整逐帧事件配对。

## Not yet proven / Hypotheses

- 两次高举在 v2/v3 中各自有可等价事件，或只合并成一次：须逐帧复核输出及正常速播放。
- 深俯身、两次高举的精确动作起止；可见姿态范围不等于不可见的关节变化范围。
- 源片是否使用变速；逐帧姿态变化只能提出异常候选，不能反推出剪辑前时间轴。

## What would verify it

逐帧标记 v2/v3 的第一次高举、回落和第二次高举；每项先判语义等价/缺失，再比时点和持续时间。没有对应事件时保持 `absent`，不拟合时间倍率。下一版提示词应引用源片帧 69–81 与 82–87 两组事件及两者之间的回落，而不是只写“约 2.9 秒高举”。
