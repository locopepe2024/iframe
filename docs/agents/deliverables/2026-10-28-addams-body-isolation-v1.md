Code fact：骨盆swing读取髋轴，三段脊柱读取肩中心至髋中心方向，腿部读取各自关节方向。控制组该流程会使错误肩髋向量进入脊柱旋转。胸廓与骨盆是不同控制入口。此次冻结相机与根节点以隔离体态影响，没有重新拟合相机。

Direct implication：在固定本次其他输入的条件下，替换胸廓输入显著减少躯干翻倒，单独替换骨盆不足。第55帧渲染同时显示：躯干变直后腿仍朝上，说明保持不动的错误腿部输入不能靠胸廓修补恢复。该结论支持分开约束胸廓、骨盆和肢体；不支持把整个错误归结成单一坐标轴或朝向。

Not yet proven：肩髋中心向量不是完整胸廓姿态，低偏角不代表头部/脊柱/腿部全身正确；表中度数不是骨盆欧拉角、重力真值或验收阈值。邻帧插值可能抹掉踢腿与转身细节。未把先前人工27点求解合入本隔离版本，未进行接触和光影验收。没有新的通过验收动画。
