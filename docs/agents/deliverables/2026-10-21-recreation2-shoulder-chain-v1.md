# 骨盆到肩端点传递：方向目标依赖与轴向旋转

2026-10-21。**确认脊柱目标随骨盆变化，冻结目标能减少部分前段误差，但剩余偏移已出现在第一节脊柱头和锁骨头；只对齐骨轴方向不够。** 主链路、rig、服务未改，未通过H3/接触。

## Observed

### Code fact

`spine_target`将当前世界骨轴方向与源torso方向按0.35/0.65/1混合。调用传入的`rest_direction`是已经受骨盆与先前父骨旋转影响的当前方向，并非固定静止方向。开启骨盆后，重算子骨也会改变其世界目标。

### Runtime observation：四组单变量对照

固定fixed_temporal输入、root/yaw、镜头、Y尺度、骨长、自身基底、PTS及IK关闭。预设四组：骨盆关闭、骨盆开启、骨盆开启且三节脊柱使用关闭组world方向目标、骨盆关闭且冻结同目标的零效应控制。冻结的是world目标，不是局部四元数，不改变权重。

关闭/开启两组逐值复现前轮bundle，冻结关闭控制与关闭组完全相等；输入哈希/root/key不变。28独立源采样×12关节、48输出帧，四组独立renderer重导入差均0px。第17帧原开启组下/中/上脊柱目标相对关闭组改变14.79°/3.82°/0°；冻结组三者均0°。

### Runtime observation：肩端点精确分解

实际父链确认为`pelvis → spine_lower → spine_mid → spine_chest → clavicle_l/r → upper_arm_l/r`。记录reset、骨盆后、逐节脊柱后、锁骨后全部端点。最终把肩头位置拆为骨盆头绝对位置与各级head→head向量；world差值和逐点投影差分别相加重建肩头总位移，所有样本残差<1e−9。该分解不是各骨的独立因果贡献，屏幕各段处于不同深度。

第17帧冻结组各脊柱world方向与关闭组目标一致，但下/中/胸脊柱完整world旋转仍相差约38.03°/38.06°/38.31°。相同轴方向而完整旋转不同，说明存在绕该轴的旋转差异；单一方向求解没有固定这项自由度。胸骨tail到左右锁骨head间距约0.054533units，两组长度基本相同，但旋转不同使偏置向量投影不同。这个静止结构间距不等于错误，也不应随意删除。下脊柱head到骨盆tail间距约0.014312units，同样未因求解消失。

## Direct implication

- **前段恶化不是单纯“子骨未重算”或方向未对齐。** 目标参考依赖、关节头偏置及方向求解未固定的轴向旋转分别需要处理。
- 本轮冻结world方向是有效诊断干预，但没有同时约束肩中心/胸廓朝向；不能成为生产校准。
- 目前最具体的下一边界是骨盆到下脊柱的head位置，以及胸廓完整朝向到锁骨head的传递。继续只调骨盆或脊柱混合权重会混淆这些项。

## Not yet proven

没有源三维/地面真值；相同方向不同完整旋转是rig内部事实，不证明源真实胸廓应采用哪个轴向角。固定脊柱目标来自旧关闭组，也可能保留旧误差抵消。第17帧的分解不能证明全片最大根因或单个骨的因果百分比。尚未对骨盆到下脊柱偏置做独立位置约束，也未校准胸廓完整旋转。鞋底接触仍未通过。

## Hypotheses

用肩横轴与躯干轴构成胸廓完整朝向、用源髋/肩中心联合约束端点，可能优于当前逐骨方向对齐。源深度、rig比例及透视失配仍可能参与，需分开实验，不能直接将完整旋转复制或压平深度。

## What would verify it

保留四组对照，下一步分别验证：①仅固定胸脊柱完整world朝向到关闭组（方向和轴向角），观察锁骨头偏移；②在保持骨盆方向与骨长条件下独立约束躯干端点/下脊柱起点，确认几何是否可行及对双髋的影响。先用零效应、rig骨长和重导入检查，再看前五事件及55；不把两项同时合并追分。若源证据无法确定胸廓轴向角，保留不确定性。
