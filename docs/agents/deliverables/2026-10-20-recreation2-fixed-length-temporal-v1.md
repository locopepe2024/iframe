# 固定输入肢段长度与跨帧深度约束对照

2026-10-20。**本轮小范围实验有效改善二维贴合与跳动，但尚未证明真实三维或脚接触正确；保留为诊断候选，不改主链路。**

## Observed

### Algorithm / code facts

目标rig原本已经固定骨长。本轮约束的是源输入proxy：固定原始XY、肩/髋Z，双侧上臂/前臂/大腿/小腿各用一个全段共享长度，调整肘/腕/膝/踝Z。每条两节链每帧枚举四种深度正负分支。长度取当前片段双侧三维长度中位数，四类都不需要二维可行性截断。

三组预先固定：原始XYZ、逐帧固定长度、固定长度加跨帧深度分支。跨帧用真实PTS下的二阶动态规划，联合最小化源Z偏差和速度变化；尺度0.05/0.03预先声明，没有按输出误差扫参。时间窗口含28独立源采样、29个输出key、48输出帧。没有修改原始输入或评分XY。

相机轴、Y=792/1394、own-bone基底、原root/yaw、rig/镜头/PTS固定；骨盆和IK关闭。脚heel→toe方向输入不改。基线逐值复现scaled_camera，三组root/yaw/key完全相同，renderer重导入差均0px，输入track哈希运行前后相同。固定长度最大残差2.78e−17 proxy units；合成DP与1024条穷举路径最优值一致。

### Runtime observation：分支、脚部与动作幅度

相较逐帧解，跨帧组分别改变左臂1、右臂7、左腿4、右腿2个采样的深度分支。逐帧组虽然投影更好，左右鞋底patch最大水平速度却从4.76/6.18升到17.55/17.02 units/s；跨帧组为1.33/3.85 units/s。输出28右patch仍3.85，输出33左patch仍0.93 units/s，不能声称支持脚已锁住。单位是未公制标定的Blender units，且含摆动期，不能直接当脚滑或接触误差。

## Direct implication

- **固定输入长度与时间分支约束是当前有实测收益的优化方向。** 在同一rig、root和镜头下改善，说明无需先换模型或丢弃Z，也能减少部分输出误差。
- 本轮证明的是这些约束对本片段输出有作用；不是证明原Z噪声是最大根因。双侧共享长度也改变了比例先验，长度/比例与Z贡献尚未独立拆分。
- 逐帧固定长度不是充分修复：端点更贴合仍可伴随严重三维分支跳变。

## Not yet proven

这是弱透视输入proxy长度假设，不是人体公制骨长，也不是完整透视重建。单目远近变化可改变proxy尺度；不能把这些变化全部判成错误。本轮没有三维真值、人工XY复标、关节角限位、源地面或接触验收；左右肢体独立分支可能违背真实朝向/遮挡关系。长度统计使用整段，方法是离线的；没有独立片段泛化验证。骨盆关闭，后段朝向边界仍未解决。

## Hypotheses

原proxy的帧间尺度与前后分支不一致可能贡献部分局部缩短和跳动；固定长度也可能补偿现有rig比例/透视失配。上述解释尚未单独归因。

## What would verify it

下一风险切片应保留当前候选与原始组，先独立复标遮挡/深度分支和抬脚/落脚事件，再在已确认的支持段加入固定鞋底patch的局部IK。另行做正确静止轴/父空间的骨盆对照，重算子骨，不恢复旧反射矩阵。支持段检查滑动、穿地、摆动高度和投影误差，未标定段不硬锁；不能用全局中位数覆盖源55或左右欠幅。尚不得作为H3参考。
