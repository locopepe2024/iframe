# recreation2 相机坐标与 BASIS 边界

2026-10-20。只读评估既有四组bundle；没有输出新动作或修改主链路。**当前BASIS与renderer相机轴未对齐，源Z会混入相机竖向方向；受控几何对照显示该边界能解释部分屏幕骨段方向失配。**

## Observed

### Code fact / runtime observation

现有BASIS约为 `(dx,dy,dz) → (dx,dz,−dy)`。已求值相机为透视镜头，位置 `(0,−5.2,2.6)`，55mm、36mm sensor width、AUTO fit、方像素、640×360：

| 相机轴 | 世界向量 |
|---|---|
| right | (1,0,0) |
| up | (0,0.294086,0.955779) |
| forward（朝场景） | (0,0.955779,−0.294086) |

镜头向下俯视约17.103°。此为renderer镜头参数，不是恢复的源镜头。六个事件帧和四个bundle的求值相机参数逐值相同。

算法直接推论：BASIS后的向量投到相机right/down/forward基底，分别为：

```text
right   = dx
down    = 0.955779·dy − 0.294086·dz
forward = 0.294086·dy + 0.955779·dz
```

若Y已乘尺度因子，公式中的dy取补偿后值。上述是相机坐标向量关系，不是完整透视屏幕位移公式；透视还依赖起点的相机坐标与深度。

### Runtime observation：固定起点、骨长的方向对照

使用源1/17/23/29/41/55、双臂双腿8个骨段，共48段/组。在原bundle求值的实际骨head起点，按同一世界骨长比较三个目标：

1. 现有BASIS目标；
2. 相同输入差值转为 `camera_right·dx − camera_up·dy + camera_forward·dz`；
3. 相机轴解释并将原始dy乘输出图像比360/640。

方向目标已经是世界目标，未额外乘root yaw。保持真实源XYZ不变；第二/第三项仅是几何射线对照，未求解新骨架、未用作IK目标。

| 组 | 现有方向误差中位数 ° | 相同输入改用相机轴 ° | 相机轴+输出图像尺度 ° |
|---|---:|---:|---:|
| 原尺度/混合起点 | 6.12 | 6.07 | 2.65 |
| 补偿Y/混合起点 | 10.03 | 2.64 | 2.69 |
| 原尺度/自身起点 | 6.25 | 6.06 | 2.69 |
| 补偿Y/自身起点 | 10.03 | 2.64 | 2.69 |

这些是48个预选骨段的屏幕**方向夹角**，不是全身关节位置误差。相机轴解释并非每段都更好，且有剩余透视项。源画幅792/1394=0.568149，而评分画幅360/640=0.5625，两者略不同；不能把图像resize造成的尺度差异与真实相机标定混为一谈。

源23右大腿（两种基底的起点相同）：原BASIS屏幕误差 **42.53°**；相同原始输入改用相机轴为18.37°，再使用输出图像尺度为 **4.60°**。在已补偿输入下，现有BASIS39.95°，相机轴4.81°。这单独展示轴关系与轴尺度的区别。

源23左前臂、自身基底：原尺度现有BASIS10.93°，相机轴同输入3.47°；补偿尺度现有50.93°，相机轴5.93°。但输出图像尺度版本分别6.43°/6.13°，并非每段单调改善。

局部投影Jacobian采用起点处±1e-4units中心差分，报告记录世界XYZ对屏幕XY的响应。各方向的Jacobian与直接方向差分夹角最大0.538°，有浮点差分误差；不据此报告亚度级因果精度。几何对照方向指标直接投影完整骨长端点计算，不依赖差分近似。

## Direct implication

- 输入Z已经存在；问题之一是它在renderer相机中如何被解释。当前世界轴BASIS未与俯视相机匹配，所以proxy Z会参与相机竖向分量。
- 相机轴和图像尺度共同影响屏幕方向；源23右大腿的受控对照提供了直接几何证据。自身骨基底能准确执行世界方向，仍可能准确执行一个与源投影不匹配的目标。
- 不能只补Y轴尺度并假设镜头契约已成立，也不能将相机轴对照的角度改善当作源关节位置/脚接触改善。

## Not yet proven

未恢复源相机，也未验证源Z的相机坐标尺度与准确性。相机轴目标来自近似归一化proxy，未通过相机反投影；不能保证其投影方向完全保留源XY。未测试新bundle、全身位置误差、时间连续性或接触；尚不能宣称这是最大根因。

## Hypotheses

镜头俯视与世界轴映射不匹配可能共同放大高深度分量骨段的屏幕倾角或缩短其屏幕长度，参与前段膝腕端点失配；其对全身误差的量化贡献须由下一步同rig重算对照验证。

## What would verify it

固定自身骨基底、原root/yaw和源PTS，预先比较现有世界BASIS与相机轴解释的完整重算bundle；评分仍用原始XY，并列六帧、全段分位数、异常步长和固定patch。相机方向统一应用于躯干/锁骨/手臂/腿，不能只挑改善骨段。保留剩余透视和骨长问题；不以重新拟合镜头或IK补偿掩盖变换影响。
