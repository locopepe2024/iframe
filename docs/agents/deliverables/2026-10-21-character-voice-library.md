# 角色工作台音色库

目标：角色设计工作台可直接打开现有音色库、试听并明确应用；绑定保存到角色资产，不写入图片提示词或角色视觉设计版本。

范围：复用 `VoicePickerModal` 的系统音色、系列复刻与设计音色。使用已有 `onUpdateAttributes` 及资产所属容器解析，字段为 `voice_id/voice_name`。系列关联提供复刻/设计音色的存储边界；无系列仍可选系统音色。

交互：顶部紧凑「音色库」入口，桌面显示当前绑定名，移动端缩减为入口。弹窗通过 portal 挂到 body，避免工作台动画容器裁切。选择不立即保存，应用等待写入成功再关闭；失败保留旧绑定与新选择，允许重试；保存中防重复提交。关闭时停止试听并丢弃迟到的试听结果。

验证：工作台真实入口、仅更新音色、取消、失败重试、重复应用与关闭后迟到试听；后端已有资产更新路径对项目、系列及全局角色均测试写入所属容器。外部 TTS 服务试听质量、付费复刻/设计及真实对白生成仍需用户运行验证，本次不自动触发。
