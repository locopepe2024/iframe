# 三维方向球首版

以可旋转观察的 WebGL 三维球替换光影/镜头的 CSS 示意。拖动球面选取方向，距离独立；三轴 Z 向上，与导演台坐标相同，原点为场景中心，方位 0 位于 -Y，正方位朝 +X，正仰角向 +Z。归一化方向 x=cos(elevation)*sin(azimuth), y=-cos(elevation)*cos(azimuth), z=sin(elevation)。坐标为用户指定的相对方向，不是从来源图片恢复的真实世界位置；此版不宣称米制距离。

光源位置与相机位置分别保存，观察球体的旋转不修改方向。相机仍沿用 yaw/pitch；已有 pitch 为向下取景的负角，因此 elevation=-pitch。新增光影球面角字段只在用户操作后发送，历史六向参数继续兼容。主光方向从球面角编译成自然语言，前后端文本保持相同。主光坐标仅在当前固定场景参考系解释，不随相机球体变化。

成功标准：球面角/坐标往返、六个基准方向、角度边界/极点；拖动/键盘/数值控件同步；生成审核与后端参数和 Prompt 一致；无 WebGL 时显示明确提示且保留角度输入。保存新参数到候选的现有 scene_tool，不引入 media、图片编辑或新的 AI 调用。真实模型方向遵循度和浏览器像素验收独立验证。

影响：共享方向计算/三维控件、SceneImageTools、后端 scene_image_tools、相关行为测试与预览。后续 Prompt 词库、镜头/构图丰富参数在本基础上继续。

验证：2 项方向数学测试（包含六向、多组往返及极点）、35 项工具/工作台交互测试、50 项后端参数/审核/持久化测试通过，类型检查和生产构建通过。三维控件交互回调在 UI 测试中使用替身，真实 WebGL 拖拽、移动端触控和成图方向遵循度尚未实测。此版使用单位球，不支持米制距离恢复。
