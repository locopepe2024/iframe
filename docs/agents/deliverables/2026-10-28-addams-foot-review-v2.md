# 脚掌标注 v2

用户指出多帧存在垫脚，原左右支撑分类与踝点不足以区分脚掌朝向和实际支撑面。新增左右脚跟底、前掌底共4个表面代理点，保留原12个关节；前掌底指脚趾根部附近鞋底，不是脚尖。脚部代理点不作为骨关节或自动接触真值。

每只脚独立选择：全掌、前掌支撑/垫脚、脚跟支撑、离地、不确定。既有左右支撑事件不自动转换成脚掌接触类型。隐藏点允许留空。

入口：addams-foot-review-v2/review.html。复用v1原PNG目录，未覆盖旧页面、旧任务和旧哈希。新版尝试迁移同浏览器v1暂存，也支持导入v1已下载JSON；旧点与事件保留，新增脚点待审，帧不自动确认。使用新版后下载addams-foot-review.json。

验证：模拟DOM运行确认16点、独立前掌支撑状态、隐藏点空坐标和v2导出。尚未做实际浏览器视觉检查，新增字段尚未接入3D鞋底求解，不能声称垫脚恢复已完成。
