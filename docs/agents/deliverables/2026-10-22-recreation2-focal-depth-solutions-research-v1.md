# 单目焦距与绝对深度：公开方案核对

## Observed

**用户确认的输入边界**：没有源相机参数及裁剪记录；后续实验不以取得这些记录为前置条件。当前只使用现有视频的最终画幅，原始拍摄内参与图像变换历史保持 unknown。

**本地运行观察**：现有 source world→image 条件拟合的近优焦距为 1058–2205 px（训练 RMSE 距最优≤1%，不是统计置信区间），对应中值髋深度 3.36–6.90 模型单位。说明当前观测和假设下存在明显焦距/深度耦合，不能把最优点 1449 px 当标定值。输入 world 尺度来自模型，不是独立测量。

## Direct implication

**算法推论**：针孔模型为 `u-cx=fx*X/Z, v-cy=fy*Y/Z`。

1. 所有相机空间点同时乘正数 s，投影严格不变。因此缺少物理尺度时，即使焦距已知，绝对米制深度仍不能仅靠投影唯一确定。
2. 对深度变化相对整体距离较小的人体，投影近似主要约束 `f/Zroot`。焦距与根深度一起变化可产生近等价投影；已知非共面公制几何和足够透视变化可以改善辨识，故不能宣称所有单目问题的焦距都在数学上不可识别。
3. 所以要分开处理“相机内参”与“公制尺度”。传统多视角标定板标定、已知内参加已知公制三维点的位姿求解，是成熟几何路线；它们需要实际额外观测，不能从这段已有视频凭空补齐。
4. 身高/骨长约束可固定尺度，但姿态、缩短效应和骨长误差会影响深度。目标 rig 的身高是输出尺度选择，不能当作源演员身高的测量。
5. 接触约束（落在平面、支持阶段速度接近零）在全局几何一起缩放时仍可成立；未知地面距离和未知身高下，单靠这些约束一般不能恢复公制尺度。已知相机离地高度、场景尺寸或其他物理尺度才提供额外锚点。
6. 裁剪/缩放必须同步变换内参：对纯二维像素坐标变换 A，`K'=A K`。OpenCV 官方文档也明确要求缩放图像时同步缩放内参。仅知道镜头毫米焦距不够，还需有效传感器尺寸和裁剪/缩放链；生成视频可能不存在统一物理相机，需保留失配可能。

## Not yet proven

- CameraHMR/HumanFoV 或 GeoCalib 能否在当前风格、遮挡和背景下稳定估计焦距；目前没有同片推理。
- 本片是否真的固定内参、是否发生数字变焦/裁切，尤其源帧 55 附近已有背景位移证据。背景移动本身不证明焦距改变，也可能是外参变化。
- 相机估计改善能否消除目标 rig 最大误差；比例、姿态、鞋底代理点和父链仍有独立待验项。
- 平滑、接触、人体先验可以让解稳定，但稳定不等于恢复真实焦距或真实绝对距离。

## Hypotheses

建议优先验证“用整幅背景提供相机证据，再与人体专用估计交叉核对”，而不是继续仅用同源 MediaPipe image/world 残差细搜焦距。GeoCalib 与 HumanFoV 的线索不同，但都是学习方法，并非独立真值。风格化或缺乏场景结构时，两者都可能偏置。

## What would verify it

下一隔离切片建议：

1. 源相机参数及裁剪记录已确认不可用，直接以现有视频最终画幅建立有效内参候选。对一致的裁剪/缩放，最终有效 K 可包含这些变换，无需先分别恢复原 K 和裁剪历史；但偏心裁剪可能让主点偏离画幅中心，因此默认中心仍是待验假设。逐帧变换或非透视形变则可能无法由一个固定 K 表达。
2. 用未裁人像的完整源帧 1/17/23/29/41/55，分别得到 GeoCalib 与 HumanFoV 的 FoV/像素焦距。记录模型版本、输入变换、主点假设和置信信息（如实际提供），不把两个值取平均就当真值。
3. 将前段共享有效 K 作为待验假设，检查跨帧一致性；前段和帧 55 附近分开检查，不把无记录解释为已知无变焦。不同来源不一致时保留候选范围，检查背景/主点/域偏移；禁止由人体 root 自由漂移掩盖问题。先固定候选 K，再单独扰动主点，避免一次放开焦距、主点、人体尺度及逐帧深度造成更多耦合。
4. 固定外部候选 K，重跑现有源人体层拟合；人体尺度单列已知值或声明的假设及敏感性。比较各关键帧、全段误差分位数、深度稳定性和人体形状，不仅比较同帧平均重投影。
5. 尺度缺失时报告明确约定单位下的相对轨迹；不宣称米制真值。若必须真实距离，补充已知身高/场景标尺/相机高度，或具有已知基线的多视角、深度传感器等证据。
6. 相机/人体层之后再验证目标 rig 比例、骨盆和局部鞋底 IK。接触作为独立指标，不通过增加接触权重替代相机标定。

本次是方案研究，不包含模型效果验收或生产替换。原透视报告文字中全段最大单点值更正为最终 JSON 的 48.67 / 47.33 px（透视/弱透视）；此前 49.35 / 47.39 是旧文案值，不改变焦距/深度耦合结论。
