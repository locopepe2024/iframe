# 镜头与成像组合建议

## 现状与目标

源码审计确认 `ScenePromptLayers` 已有景别、机位、焦距观感、景深与构图，
并可编译进场景描述和场景图编辑任务；未见拍摄设备或成像质感字段。
视频生成参数里的 `resolution` 是模型输出参数，不等同于拍摄/胶片质感，
本功能不修改模型画幅、分辨率、生成参数或相机真实物理模拟。

在现有场景镜头字段增加显式的拍摄设备和成像质感文本选项。具体焦段
按全画幅等效视角标注，保留原来的广角/标准/长焦/鱼眼选项及旧保存数据。
新字段继续使用 `scene_prompt_layers.v1`，由后端现有 Pydantic 镜头类型
校验，按 `镜头：` 区块编译；没有设置时不注入任何默认值。

## 兼容建议

| 组合线索 | 建议 |
| --- | --- |
| 14/24mm 广角或鱼眼 + 近景/特写 | 近距离会强化透视与边缘形变；若要自然比例，退远后裁切。夸张透视仍可保留 |
| 高机位/俯视 + 近景/特写 | 核实人脸或物体的关键可见特征；有意俯拍特写仍然允许 |
| 低机位仰视 + 14/24mm 广角 | 垂直线和近处透视会更夸张；建筑线条需端正时考虑透视校正 |
| 135/200mm 长焦 + 全景/大全景 | 需要更远拍摄距离和空间；核实场地，或缩短焦段 |
| 135/200mm 长焦 + 细节特写 | 核实最近对焦距离、机位空间和稳定性；必要时使用微距或较短焦段 |
| 背视 + 近景/特写 | 主体正面表情不可见；需要身份/表情时换侧前方机位 |
| 手机 + 85/135/200mm 等效焦段 | 说明使用长焦模组或裁切模拟；焦段是视角等效值，不是手机镜头实际毫米数 |
| 常见运动相机 + 长焦 | 默认固定超广角与长焦意图有张力；注明可换镜头型号或裁切方案 |
| 常见运动相机 + 浅景深 | 小传感器画面通常更接近深景深；说明设备或后期模拟方式 |
| 手机 + 浅景深 | 说明是长焦模组或计算虚化；需要自然遮挡边缘时优先写明光学虚化 |
| 监控机位 + 浅景深 | 多数固定监控画面偏深景深；若是刻意的电影化效果可保留 |
| 粗颗粒低保真 + 细节特写 | 颗粒可能遮住纹理；降低颗粒或改自然成像 |
| 柔焦低反差 + 细节特写 | 细节边缘会变弱；展示材质时降低柔化并保留局部清晰 |

建议是可见状态，不阻止应用、不清除选项、不改写用户文本。其他有意
违反常规的创作组合照常允许。输出分辨率和生成清晰度仍由任务模型控件
负责；高分辨率扫描与胶片颗粒可以同时成立。

## 修改面

- `frontend/src/lib/scenePromptLayers.ts`：设备/成像质感词条、等效焦段和
  纯函数组合建议。规则只依赖当前显式字段，不调用模型或外部服务。
- `frontend/src/components/shared/ScenePromptLayersPanel.tsx`：镜头选项下
  显示上下文建议，并标明模型输出分辨率为独立参数。
- `frontend/src/components/modules/SceneImageTools.tsx`：场景镜头工具开放
  焦段、拍摄设备、景深和成像质感字段。
- `src/apps/comic_gen/scene_prompt_layers.py`：增加有界文本字段，并允许
  当前场景镜头面板编译这两项。

## 已知边界

景别、机位、焦段和输出尺寸的完整矩阵尚未建立；本批完成了焦段/景别和
设备/成像质感的首批说明性规则。数值球体机位尚无条件式建议。规则是合理性提示，
不构成物理成像模拟，也没有经过专家摄影样片评估。超出列表的自定义文本
可以进入现有设计文本，但不保证被规则识别。
