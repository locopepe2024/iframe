# recreation2 共同投影尺度与局部长度分歧

2026-10-20。只读分析完整Z相机轴候选，不生成新bundle。**不同部位投影长度偏差方向不同，单一共同缩放不能充分解释剩余误差；还不能将这种分歧认定为rig物理比例错误。**

## Observed

使用固定z_full报告的28个独立源样本、每帧11条二维长度：肩宽、髋宽、二维肩/髋中点间躯干代理、双侧四肢8段，总计308项。中点为投影后平均，不等于三维中点投影。逐关节核对读取的源XY可重现报告全部评分误差，差<1e-6px；hold key未重复计权。

| 部位 | rig/source投影长度比中位数 | rig−source长度差中位数 px |
|---|---:|---:|
| 肩宽 | 1.138 | +6.43 |
| 髋宽 | 1.450 | +12.13 |
| 躯干中点代理 | 1.141 | +9.98 |
| 上臂 | 0.945 | −1.75 |
| 前臂 | 0.744 | −8.34 |
| 大腿 | 0.797 | −9.83 |
| 小腿 | 0.867 | −7.04 |

这组分位数不是一具可直接恢复的人体比例；不同帧投影方向、深度和转身会改变长度。上臂长度比离散，不能仅依据0.945称上臂已通过。

### 单帧共同缩放的诊断

每帧拟合一个尺度 `s=sum(rig_length*source_length)/sum(rig_length²)`，使11段长度平方残差最小。它只在二维长度空间计算，不移动关节、不改变原输出，也不是物理相机或人物尺度估计。

- 28帧拟合尺度范围0.887–1.136，中位数0.962。
- 308项绝对长度误差中位数 **10.55→9.34px**，P95 **17.77→16.82px**。
- 这比一个全段固定缩放更灵活，但仍留下明显失配；不能据拟合后长度评分宣称动作得到改善，也不能称其为所有透视模型的误差下界。

### 同帧不一致实例

源23长度比：髋宽1.401、躯干1.159；左前臂0.599、右前臂0.666；左大腿0.701、右大腿0.410。即使同一帧，一个公共乘数也无法同时把全部比值变成1。

源29左右前臂比为0.709/1.880；同一个rig的左右段在此帧出现相反偏差，不能只用固定身体比例解释。源55髋宽比又降至0.563，而躯干仍1.214；此前髋宽总体偏大的结论不能逐帧沿用。

## Direct implication

- 当前不是单纯“整个白模画大了/画小了”；共同二维尺度不能消除所测局部长度分歧。
- 直接扩大四肢或缩窄髋宽没有足够依据。各部位投影同时受rig几何、目标方向/深度、root yaw与透视影响。
- 源29同侧段及左右前臂的差异、源55髋宽反转，要求保留姿态/朝向因素，不能从投影长度比直接反推物理骨长。

## Not yet proven

未测试真实root深度或物理整体尺度的变化。二维公共缩放不等于在透视相机下移动root深度（各点深度不同）；本次不能排除该项。没有确定固定骨长、关节中心、proxy Z或yaw谁是最大剩余原因。没有支持脚/地面真值或H3验收。

## Hypotheses

输入proxy逐段方向/深度与固定rig几何的组合可能造成局部投影尺度分歧；转身时骨盆/双髋朝向也可能影响宽度反转。须单独验证，不据此修改源Z或骨长。

## What would verify it

下一步先对同帧记录相机坐标下的rig段长、方向深度比例与源proxy段长，确认屏幕长度比变化是否与目标深度/朝向变化相对应。尤其检查源23右大腿、源29左右前臂和源55髋宽。再决定做固定root深度的单变量对照或骨盆朝向诊断；不逐帧拟合rig比例或相机参数。
