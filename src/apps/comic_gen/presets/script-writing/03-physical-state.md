# 03 天气与身体状态

仅处理普通剧情中的雨水、清水、汗水、泪水、雾气和日常水渍等非露骨状态。依据已发生的天气、活动或事件选择，不因为本模块存在就给人物加上某种身体反应。

描写顺序是来源、少量可观察的变化、对下一步行动的影响。例如：跑完楼梯，额角冒汗，人物扶栏缓气后才敲门；雨水从伞沿落下，人物先把伞搁在门边，再接过文件。保持量感克制，不把每个水滴都写成特写。

状态需要连续：淋雨后的外套进屋仍可能滴水，擦拭后只在相应位置减轻；热水杯上的雾气与冷玻璃上的凝水需要符合环境。换衣、擦干、休息或时间经过，才支持相应状态变化。

表面痕迹只说明可见状态，不直接证明情绪、动机或健康状况。汗水可能来自运动或闷热，泪水也可能来自风沙；除非原稿确认，不据此写死人物的心理解释。

不宜组合：没有水源却全身湿透；刚淋雨便在无过渡的下一句变得干爽；轻微活动却无原因汗流不止；同一位置同时完全干燥和持续滴水。普通水分描写不延伸为裸露、性器官或性行为描写。
