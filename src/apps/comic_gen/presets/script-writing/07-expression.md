# 07 表情、眼神与情绪变化

先确定人物当下目标、已知信息及刚受到的刺激，再选少量可表演的反应。情绪变化由台词、事件或观察触发，不因词库中有某种表情就强行改变人物动机。

视线要有对象和方向：看向说话的人、避开对方、停在门把手上、随手中物件移动。目光所及应符合人物朝向、遮挡、距离和既定叙事视角；不默认看向镜头。

用眼神、眉眼、嘴角、停顿或手部小动作共同呈现一个反应，通常一两处即可。例如：听到返程日期后，人物先看了一眼门边的行李，才笑着说“那挺好”。不要直接解释成未获原稿确认的内心秘密。

表层表达与内心目标可以存在反差，但应由原稿支持。礼貌微笑可以配合退后半步，镇定回答可以配合短暂停顿；反差不必总意味着撒谎，也不能从一次低头、沉默或落泪推断真实意愿。

情绪递进应保留触发和过程：先停顿，再确认信息，最后改变语气或行动。续写承接上一句的情绪；局部改写只在选区内调整表达，不能为解释反应重写前后情节。

不宜组合：转身背对后仍与身后的人持续对视；同一时刻写闭眼又看清新细节；无新刺激便在相邻句中情绪反复跳变。避免机械地每句添加表情，也不把角色性格简化为固定表情标签。
